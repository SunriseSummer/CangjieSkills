# 1. 启动参数

[← Cangjie Language Server](index.md)

速查`-V`：生成服务器崩溃日志；`--enable-log=<true|false>`：控制普通日志；省略时默认为 `true`；`--log-path=<path>`：指定普通日志和崩溃日志目录；省略时使用 LSPServer 所在目录；另含更多表项。

| 参数 | 作用 |
|---|---|
| `-V` | 生成服务器崩溃日志 |
| `--enable-log=<true\|false>` | 控制普通日志；省略时默认为 `true` |
| `--log-path=<path>` | 指定普通日志和崩溃日志目录；省略时使用 LSPServer 所在目录 |
| `--disableAutoImport` | 禁用补全时自动导入包 |
| `--test` | 启动测试模式，供 LSPServer 测试使用 |
