# stdx 安装与项目配置

[← 工具链](../index.md)

导入 `stdx.*` 前，使用 Skill 自带脚本选择与当前 `cjc` 兼容的官方发布件，并把正确二进制目录增量写入 `cjpm.toml`；不要手写下载地址、平台名或目标表。

| 任务 | 关键结论 |
|---|---|
| [安装、版本与平台选择](1-安装版本与平台.md) | `setup_stdx.py` 从 `cjc -v` 同时确定编译器版本和 Target，安装到用户级目录，并只配置对应 payload。 |
| [全局缓存与并发安全](2-全局缓存与并发安全.md) | 多项目、多版本和多个并发进程可复用下载与安装；锁、校验、临时文件和原子替换保护共享状态。 |
| [选项、边界与故障定位](3-选项边界与故障定位.md) | 离线、静态链接、预览和自定义缓存都有显式选项；脚本不猜测不受支持的平台或系统依赖。 |
