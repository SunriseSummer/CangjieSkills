# 全局缓存与并发安全

[← stdx 安装与项目配置](index.md)

默认根目录为 `~/.cangjie/stdx/`。安装目录同时包含平台和 stdx 版本，允许多版本并存；官方 ZIP 缓存在 `.cache/`，各项目只把当前选择的版本写入自身 `cjpm.toml`。

并发执行时，下载、安装和项目清单修改分别使用跨平台文件锁。同一资产只由持锁进程下载或安装，等待者在获取锁后重新检查现状并复用完整结果。ZIP 先写入临时文件，验证成功后原子替换缓存；解压先进入临时目录，通过布局与安全检查后才发布安装目录。清单也用同目录临时文件原子替换，第一次修改前保存 `cjpm.toml.stdx.bak`。

脚本拒绝无效 ZIP、绝对路径、目录穿越、符号链接和特殊文件成员。`.locks/` 中的小型锁文件用于跨进程协调，会保留供后续运行复用，不应作为垃圾删除。每个实际安装由首次成功发布者写入 `install.json`；并发复用者不覆盖它。JSON 输出区分本次 ZIP 与已安装 ZIP 的 SHA-256，便于追溯实际使用的发布件。

项目配置具有幂等性：保留非 stdx 路径，替换旧的官方 stdx 路径，重复执行不会重复添加。默认选择发布件的 `_cjnative` 动态 payload；显式指定静态链接时才改用静态库目录。
