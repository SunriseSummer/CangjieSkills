# 2.8 优化

[← 2. 核心选项速查](index.md)

命令：`cjc test.cj --lto=full`。

| 选项 | 说明 |
|------|------|
| `-O0` / `-O1` / `-O2` / `-Os` / `-Oz` | 优化级别 |
| `--lto=[full\|thin]` | 链接时优化（仅 Linux） |
| `-j <N>`, `--jobs <N>` | 并行编译最大线程数 |
| `--int-overflow=[throwing\|wrapping\|saturating]` | 整数溢出策略（默认 `throwing`） |

```bash
cjc test.cj --lto=full         # Full LTO 优化
cjc test.cj -j 4               # 使用 4 线程并行编译
```
