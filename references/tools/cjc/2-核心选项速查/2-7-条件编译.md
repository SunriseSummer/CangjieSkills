# 2.7 条件编译

[← 2. 核心选项速查](index.md)

命令：`cjc main.cj --cfg "env=prod"`。

```bash
cjc main.cj --cfg "env=prod"   # 定义自定义条件编译变量
```

1.1.3 的内置条件变量增加 `env`，用于区分同一 OS 下的 ABI/运行环境，支持 `==`、`!=`；值包括 `ohos`、`gnu`、`simulator`、`android` 与空字符串。它是内置变量，不要用 `--cfg "env=prod"` 覆盖；自定义业务条件应换一个名字。

```cangjie role=signature
@When[os == "Linux" && arch == "aarch64" && env == "android"]
func mobileTarget(): String { "android-aarch64" }
```
