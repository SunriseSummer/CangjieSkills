# 2.10 交叉编译

[← 2. 核心选项速查](index.md)

命令：`cjc hello.cj --target=x86_64-windows-gnu`。

```bash
# 指定目标平台
cjc hello.cj --target=x86_64-windows-gnu

# 使用 sysroot 简化工具链配置
cjc hello.cj --target=arch-os-env --sysroot /usr/sdk/arch-os-env
```

1.1.3 新增 Android/iOS 目标支持：Android 使用 `aarch64-linux-android<API>`（API 26 起）并配套 NDK sysroot；iOS 使用 `aarch64-apple-ios<version>`，仅输出静态库，模拟器另有 `aarch64-apple-ios-simulator` 与 `x86_64-apple-ios-simulator`。必须安装对应交叉 SDK，桌面 SDK 的 `--target` 选项本身不包含目标运行库。
