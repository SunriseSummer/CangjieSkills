# 2.10 交叉编译

[← 2. 核心选项速查](index.md)

命令：`cjc hello.cj --target=x86_64-windows-gnu`。

```bash
# 指定目标平台
cjc hello.cj --target=x86_64-windows-gnu

# 使用 sysroot 简化工具链配置
cjc hello.cj --target=arch-os-env --sysroot /usr/sdk/arch-os-env
```
