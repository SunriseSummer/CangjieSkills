# 2.4 调试与诊断

[← 2. 核心选项速查](index.md)

速查`-g`：生成调试信息（须配合 `-O0`）；`-V`, `--verbose`：打印编译过程详细信息；`-v`, `--version`：打印编译器版本；另含更多表项。

| 选项 | 说明 |
|------|------|
| `-g` | 生成调试信息（须配合 `-O0`） |
| `-V`, `--verbose` | 打印编译过程详细信息 |
| `-v`, `--version` | 打印编译器版本 |
| `-h`, `--help` | 打印帮助信息 |
| `--diagnostic-format=[default\|noColor\|json]` | 错误信息输出格式 |
| `--error-count-limit <N\|all>` | 限制打印错误数量（默认 8） |
