# 2.1 输出控制

[← 2. 核心选项速查](index.md)

命令：`cjc tool.cj --output-type=dylib`。

| 选项 | 说明 |
|------|------|
| `-o <file>` | 指定输出文件路径 |
| `--output-type=[exe\|staticlib\|dylib]` | 稳定输出类型（默认 `exe`） |
| `--output-type=[chir\|obj]` | 1.1.3 实验输出，必须同时指定 `--experimental`；`obj` 还需匹配 `--compile-target` |
| `--compile-target=[exe\|staticlib\|dylib]` | 指定实验性 `obj` 中间文件最终要链接成的产物类型 |
| `--output-dir <dir>` | 中间文件与输出保存目录 |

```bash
cjc tool.cj --output-type=dylib           # 生成动态库 libtool.so
cjc tool.cj --output-type=staticlib       # 生成静态库 libtool.a
cjc tool.cj --experimental --output-type=obj --compile-target=exe -o tool.o
```
