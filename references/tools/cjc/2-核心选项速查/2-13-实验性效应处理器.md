# 2.13 实验性效应处理器

[← 2. 核心选项速查](index.md)

仓颉 1.1.3 使用 `--experimental --enable-eh` 启用 Effect Handlers；只给出其中一个选项不能完整解析 `perform`、`handle` 和 `resume`。

```shell
cjc --experimental --enable-eh main.cj
```

cjpm 清单使用 `compile-option = "--experimental --enable-eh"`，代码同时依赖 stdx 1.1.3.1 的 `stdx.effect.Command`。修改选项或 stdx 路径后执行 `cjpm clean` 再构建。语法、默认处理和单次恢复约束见[效应处理器](../../../language/effect-handler/index.md)。
