# 2.12 警告控制与零警告验收

[← 2. 核心选项速查](index.md)

| 选项 | 说明 |
|------|------|
| `--warn-off <group>` / `-Woff <group>` | 关闭指定警告组；`all` 关闭全部警告 |
| `--warn-on <group>` / `-Won <group>` | 开启指定警告组 |

`-Won` 与 `-Woff` 顺序敏感，同一警告组以后出现的选项为准。编译器诊断后的 note 会给出该警告所属组别。

警告开关是项目策略，不是修复代码的替代品：

- 不要为了让构建日志看起来“零警告”，临时在 `cjpm.toml` 添加 `compile-option = "-Woff unused"` 或 `-Woff all`。
- 生产源码的警告应修复根因；允许改变签名时，完全不使用的绑定可改为通配符 `_`。`_name` 仍是普通标识符，不会抑制未使用警告。
- 警告来自不可修改测试、生成代码或依赖时，保留输入并记录诊断来源；是否屏蔽应由项目既有策略决定，不能据“没有输出”断言代码天然无警告。
