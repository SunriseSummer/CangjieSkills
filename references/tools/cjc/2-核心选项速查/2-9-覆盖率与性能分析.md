# 2.9 覆盖率与性能分析

[← 2. 核心选项速查](index.md)

命令：`cjc --coverage main.cj`。

```bash
cjc --coverage main.cj         # 编译支持覆盖率统计（须 -O0）
cjc test.cj --pgo-instr-gen    # PGO 插桩编译
cjc test.cj --pgo-instr-use=default.profdata  # 使用 profile 指导优化
```
