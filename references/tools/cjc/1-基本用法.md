# 1. 基本用法

[← cjc 编译器](index.md)

```bash
cjc [option] file...          # 编译 .cj 文件，默认生成可执行文件 main
cjc hello.cj                  # 最简编译
cjc hello.cj -o hello         # 指定输出文件名
```

- `cjc-frontend`：仅前端编译器，输出 LLVM IR（`.bc`）
- `cjc`：自动完成 前端 + 后端 + 链接
