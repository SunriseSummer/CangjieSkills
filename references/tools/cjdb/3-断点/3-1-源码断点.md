# 3.1 源码断点

[← 3. 断点](index.md)

代码展示 `(cjdb) b test.cj:4                                  # 简写` 的典型用法。

```text
(cjdb) b test.cj:4                                  # 简写
(cjdb) breakpoint set --file test.cj --line 4        # 完整写法
```
