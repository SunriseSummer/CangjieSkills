# 9. 日志

[← cjdb 调试器](index.md)

```text
(cjdb) log list                   # 列出可用 channel 和 category
(cjdb) help log enable            # 查看当前版本的完整启用语法
```

启用日志时必须同时指定一个 channel 和至少一个 category：

```text
(cjdb) log enable <channel> <category>...
(cjdb) log enable lldb commands             # 1.1.3 可用示例
```

先用 `log list` 取得当前版本支持的名称，不要执行缺少参数的裸 `log enable`。
