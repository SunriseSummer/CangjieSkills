# 7. 观察点

[← cjdb 调试器](index.md)

```text
(cjdb) watchpoint set variable -w read a     # 读观察点（简写 wa s v）
(cjdb) wa s v -w write a                     # 写观察点
(cjdb) wa s v -w read_write a                # 读写观察点
```

仅支持基础类型。Windows 上设置条件时程序最多只会暂停一次。
