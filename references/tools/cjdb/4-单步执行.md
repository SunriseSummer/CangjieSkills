# 4. 单步执行

[← cjdb 调试器](index.md)

速查`thread step-over`：`n` / `next`；`thread step-in`：`s` / `step`；`finish`：—。

| 命令 | 简写 | 说明 |
|------|------|------|
| `thread step-over` | `n` / `next` | 单步跳过（不进入函数） |
| `thread step-in` | `s` / `step` | 单步进入（进入有调试信息的函数） |
| `finish` | — | 执行完当前函数并返回上层 |
