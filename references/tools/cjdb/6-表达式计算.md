# 6. 表达式计算

[← cjdb 调试器](index.md)

```text
(cjdb) expr 3              # 字面量
(cjdb) expr a + b          # 算术表达式
(cjdb) expr a > b          # 关系表达式
(cjdb) expr value.member   # 成员访问
(cjdb) expr array[2]       # 索引访问
```

> **注意**：不支持带命名参数的函数调用、互操作、扩展、属性、别名、插值字符串、函数名。Windows 不支持 Float16 类型和异常抛出。macOS 平台暂不支持表达式计算。
