# 5.1 查看变量

[← 5. 变量查看与修改](index.md)

```text
(cjdb) locals              # 查看所有局部变量
(cjdb) globals             # 查看所有全局变量
(cjdb) p variableName      # 查看单个变量（简写 print）
(cjdb) p array[1..3]       # 查看数组区间（左闭右开）
```

支持类型：基础类型、String、struct/class、Array、CString、Enum。
