# 5.2 修改变量

[← 5. 变量查看与修改](index.md)

代码展示 `(cjdb) set a=30            # 仅支持基础数值类型` 的典型用法。

```text
(cjdb) set a=30            # 仅支持基础数值类型
(cjdb) set b=0             # Bool: 0=false, 非0=true
(cjdb) set c=0x41          # Rune: 使用 ASCII 码
```
