# cjfmt 格式化

[← 工具链](../index.md)

文件、目录和片段格式化，配置文件与格式规则。

| 规则/任务 | 摘要 |
|---|---|
| [1. 概述](1-概述.md) | `cjfmt`（Cangjie Formatter）是基于仓颉语言编程规范的代码自动格式化工具。 |
| [2. 基本用法](2-基本用法/index.md) | `-l` 仅适用于单文件（`-f`），与 `-d` 搭配时无效。 |
| [3. 命令选项](3-命令选项.md) | 速查`-h`：显示帮助信息；`-v`：显示版本号；`-f <file>`：指定格式化文件（支持相对/绝对路径）；另含更多表项。 |
| [4. 配置文件](4-配置文件.md) | 通过 `-c` 指定自定义配置文件，或使用 `CANGJIE_HOME/tools/config/cangjie-format.toml` 默认配置。 |
| [5. 格式化规则摘要](5-格式化规则摘要/index.md) | 统一使用 4 个空格缩进 |
| [6. 注意事项](6-注意事项.md) | 暂不支持语法错误代码的格式化 |
