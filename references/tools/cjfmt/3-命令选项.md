# 3. 命令选项

[← cjfmt 格式化](index.md)

速查`-h`：显示帮助信息；`-v`：显示版本号；`-f <file>`：指定格式化文件（支持相对/绝对路径）；另含更多表项。

| 选项 | 说明 |
|------|------|
| `-h` | 显示帮助信息 |
| `-v` | 显示版本号 |
| `-f <file>` | 指定格式化文件（支持相对/绝对路径） |
| `-d <dir>` | 指定格式化目录 |
| `-o <value>` | 输出文件或目录 |
| `-c <value>` | 指定格式化配置文件 |
| `-l <start:end>` | 指定格式化行范围（仅 `-f`） |
