# 6. 注意事项

[← cjfmt 格式化](index.md)

- 暂不支持语法错误代码的格式化
- 暂不支持元编程（宏）代码的格式化
- Windows cjnative 1.0.5 实测中，带 UTF-8 BOM 的 `.cj` 文件会打印 `unknown start of token` 并被跳过，但进程仍可能返回 0。自动化门禁应同时捕获诊断输出，并确认输出目录中的 `.cj` 数量与输入一致；不能只检查退出码
- 需要保证源文件不被改写时，把结果输出到独立目录，并在运行前后比较源文件哈希
