# 6. 注意事项

[← cjfmt 格式化](index.md)

- 暂不支持语法错误代码的格式化
- 暂不支持元编程（宏）代码的格式化
- Windows cjnative 1.1.3 实测中，带 UTF-8 BOM 的 `.cj` 文件会打印 `unknown start of token` 并被跳过，但进程仍可能返回 0。自动化门禁应同时捕获诊断输出，并确认输出目录中的 `.cj` 数量与输入一致；不能只检查退出码
- 1.1.3 的 `cjfmt` 尚不能解析以 `--experimental --enable-eh` 编译的 Effect Handler 语法；遇到 `perform`、`handle`、`resume` 会打印语法错误，却仍可能返回 0。格式化门禁应拒绝这类诊断，并在 formatter 支持前排除相应源文件，不能把原文件未变化当作格式化成功。
- 需要保证源文件不被改写时，把结果输出到独立目录，并在运行前后比较源文件哈希
