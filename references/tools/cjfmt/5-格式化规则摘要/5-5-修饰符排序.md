# 5.5 修饰符排序

[← 5. 格式化规则摘要](index.md)

- 顶层：`public` → `open`/`abstract`
- 成员函数：`public`/`protected`/`private` → `open` → `override`
- 静态函数：`public`/`protected`/`private` → `static` → `redef`
- 成员变量：`public`/`protected`/`private` → `static`
