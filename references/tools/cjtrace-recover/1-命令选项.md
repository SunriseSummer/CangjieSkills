# 1. 命令选项

[← cjtrace-recover 异常堆栈还原](index.md)

代码展示 `cjtrace-recover -f <stacktrace-file> -m <map-file,...>` 的典型用法。

```text
cjtrace-recover -f <stacktrace-file> -m <map-file,...>
```

| 选项 | 作用 |
|---|---|
| `-f <file>` | 保存混淆异常堆栈的文件 |
| `-m <file,...>` | 一个或多个符号映射文件，多个路径用逗号分隔 |
| `-h` | 显示帮助 |
| `-v` | 显示版本 |
