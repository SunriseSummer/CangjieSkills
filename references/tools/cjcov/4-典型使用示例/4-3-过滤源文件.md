# 4.3 过滤源文件

[← 4. 典型使用示例](index.md)

命令：`cjcov --root=./ -e "/path/to/tests" --html-details -o output`。

```bash
# 排除测试目录
cjcov --root=./ -e "/path/to/tests" --html-details -o output

# 仅包含指定文件
cjcov --root=./ -i "/path/to/src/main.cj /path/to/src/utils" --html-details -o output
```
