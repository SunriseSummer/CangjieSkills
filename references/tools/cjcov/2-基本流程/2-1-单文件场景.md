# 2.1 单文件场景

[← 2. 基本流程](index.md)

命令：`cjc --coverage main.cj`。

```bash
# 1. 使用 --coverage 编译
cjc --coverage main.cj

# 2. 运行生成 .gcda 数据
./main

# 3. 生成 HTML 覆盖率报告
cjcov -o output --html-details
```
