# 3.2 分析对象信息

[← 3. 堆内存分析](index.md)

```bash
cjprof heap -i heap.data
```
输出各对象类型的实例数、浅堆大小、深堆大小：
```text
Object Type           Objects        Shallow Heap   Retained Heap
====================  =============  =============  =============
AAA                               1            80             400
BBB                               4            32             196
```
