# 1. 安装依赖与公共选项

[← HLE](index.md)

ArkTS 模式建议 Node.js 18.14.1 以上，并在 `${CANGJIE_HOME}/tools/dtsparser/` 执行 `npm install` 安装 TypeScript 与 cjbind 依赖。C 模式须另行提供匹配平台的 cjbind 可执行文件。

`-i <file>` 与 `-d <directory>` 至少给出一个；`-o <directory>` 指定输出目录，`--module-name <name>` 指定生成包名。Windows 路径参数使用 `/`，不要使用反斜杠。先运行 `hle --help` 确认当前 SDK 随附版本的选项。
