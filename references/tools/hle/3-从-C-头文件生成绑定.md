# 3. 从 C 头文件生成绑定

[← HLE](index.md)

C 模式使用 `-c`，并以 `-b` 指定 cjbind。系统 include 路径默认自动探测；自定义头文件目录用 `--clang-args="-I<path>"`，只有确有需要时才用 `--no-detect-include-path` 禁用探测。

```bash
hle -c -b /tools/cjbind -d /work/include -o /work/generated \
  --module-name=native_api --clang-args="-I/work/vendor/include"
```

生成结果仍需在目标平台上编译和链接；HLE 只生成绑定模板，不会提供底层 C 库或替代其 ABI 兼容性检查。
