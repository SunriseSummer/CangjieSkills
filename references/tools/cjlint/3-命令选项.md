# 3. 命令选项

[← cjlint 静态检查](index.md)

速查`-h`：显示帮助信息；`-v`：显示版本号；`-f <dir>`：指定检查目录（多个目录用空格分隔，双引号包裹）；另含更多表项。

| 选项 | 说明 |
|------|------|
| `-h` | 显示帮助信息 |
| `-v` | 显示版本号 |
| `-f <dir>` | 指定检查目录（多个目录用空格分隔，双引号包裹） |
| `-e "<rule1 rule2 ...>"` | 排除文件、目录或 `.cfg`；规则相对 `-f` 目录，支持正则，多项用空格分隔 |
| `-o <path>` | 输出报告路径 |
| `-r [csv\|json]` | 报告格式（默认 json，须配合 `-o`） |
| `-c <path>` | config 目录路径 |
| `-m <path>` | modules 目录路径 |
| `--import-path <dir>` | 添加 `.cjo` 搜索路径 |
