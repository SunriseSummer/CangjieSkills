# 4.1 规则级屏蔽

[← 4. 告警屏蔽](index.md)

编辑 `config/cjlint_rule_list.json`，仅保留需要检查的规则：
```json
{
    "RuleList": ["G.FMT.01", "G.NAM.01", "G.VAR.01"]
}
```

编辑 `config/exclude_lists.json` 屏蔽特定告警：
```json
{
    "G.OTH.01": [
        {"path": "xxx/example.cj", "line": "42"}
    ]
}
```
