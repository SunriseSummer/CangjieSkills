# 4.3 文件级屏蔽

[← 4. 告警屏蔽](index.md)

```bash
cjlint -f src/ -e "dir1/ dir2/a.cj test*.cj"
```

`-e` 的规则相对 `-f` 指定的源码目录。多条规则放在同一个引号参数内并用空格分隔；仓颉 1.1.3 的 Windows 实测如此，尽管该版本 `-h` 的参数占位仍显示冒号分隔。

也可把规则逐行写入 `.cfg` 后由 `-e` 导入；未显式导入其他有效 `.cfg` 时，默认读取源码目录下的 `cjlint_file_exclude.cfg`。
