# 2. 基本用法

[← cjlint 静态检查](index.md)

```bash
cjlint -f src/                              # 检查 src 目录
cjlint -f "dir1 dir2" -c . -m .             # 检查多个目录
cjlint -f src/ -r csv -o ./report           # 输出 CSV 报告
cjlint -f src/ -e "test/ generated/"        # 排除多个目录
```

> **注意**：`-f` 后指定的是 `.cj` 文件所在的 `src` 目录，不是单个文件。

质量门禁不能只检查退出码：还应捕获诊断输出，并断言指定的 CSV/JSON 报告存在且非空。若前置格式化器跳过了源文件，cjlint 也可能没有覆盖预期文件，因此还要核对实际输入文件集合。
