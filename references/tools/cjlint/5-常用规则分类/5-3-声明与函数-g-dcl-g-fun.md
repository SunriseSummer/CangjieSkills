# 5.3 声明与函数（G.DCL/G.FUN）

[← 5. 常用规则分类](index.md)

速查`G.DCL.01`：避免变量遮盖（shadow）；`G.DCL.02`：public 变量/函数显式声明类型；`G.FUN.01`：函数功能单一；另含更多表项。

| 规则 | 说明 |
|------|------|
| G.DCL.01 | 避免变量遮盖（shadow） |
| G.DCL.02 | public 变量/函数显式声明类型 |
| G.FUN.01 | 函数功能单一 |
| G.FUN.02 | 禁止未使用的参数 |
| G.FUN.03 | 避免在无关函数间重用名字构成重载 |
