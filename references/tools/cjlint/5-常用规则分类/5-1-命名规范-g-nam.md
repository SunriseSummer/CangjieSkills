# 5.1 命名规范（G.NAM）

[← 5. 常用规则分类](index.md)

速查`G.NAM.01`：包名全小写，允许数字和下划线；`G.NAM.02`：源文件名全小写加下划线；`G.NAM.03`：类/接口/struct/枚举/类型别名采用大驼峰；另含更多表项。

| 规则 | 说明 |
|------|------|
| G.NAM.01 | 包名全小写，允许数字和下划线 |
| G.NAM.02 | 源文件名全小写加下划线 |
| G.NAM.03 | 类/接口/struct/枚举/类型别名采用大驼峰 |
| G.NAM.04 | 函数名小驼峰 |
| G.NAM.05 | `let` 全局变量和 `static let` 全大写 |
