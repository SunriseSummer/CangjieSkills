# 5.2 格式规范（G.FMT）

[← 5. 常用规则分类](index.md)

速查`G.FMT.01`：源文件编码格式（含注释）必须是 UTF-8；`G.FMT.15`：禁止省略浮点数小数点前的 0。

| 规则 | 说明 |
|------|------|
| G.FMT.01 | 源文件编码格式（含注释）必须是 UTF-8 |
| G.FMT.15 | 禁止省略浮点数小数点前的 0 |
