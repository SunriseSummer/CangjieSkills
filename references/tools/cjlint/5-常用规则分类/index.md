# 5. 常用规则分类

[← cjlint 静态检查](../index.md)

| 细粒度主题 | 摘要 |
|---|---|
| [5.1 命名规范（G.NAM）](5-1-命名规范-g-nam.md) | 速查`G.NAM.01`：包名全小写，允许数字和下划线；`G.NAM.02`：源文件名全小写加下划线；`G.NAM.03`：类/接口/struct/枚举/类型别名采用大驼峰；另含更多表项。 |
| [5.2 格式规范（G.FMT）](5-2-格式规范-g-fmt.md) | 速查`G.FMT.01`：源文件编码格式（含注释）必须是 UTF-8；`G.FMT.15`：禁止省略浮点数小数点前的 0。 |
| [5.3 声明与函数（G.DCL/G.FUN）](5-3-声明与函数-g-dcl-g-fun.md) | 速查`G.DCL.01`：避免变量遮盖（shadow）；`G.DCL.02`：public 变量/函数显式声明类型；`G.FUN.01`：函数功能单一；另含更多表项。 |
| [5.4 类/接口/枚举/变量（G.CLS/G.ITF/G.ENU/G.VAR）](5-4-类-接口-枚举-变量-g-cls-g-itf-g-enu-g-var.md) | 速查`G.CLS.01`：override 父类函数时不要增加可访问性；`G.ITF.01`：需要原地修改对象的抽象函数尽量使用 `mut` 修饰；`G.ITF.02`：尽量在类型定义处实现接口，而非通过扩展；另含更多表项。 |
| [5.5 表达式与类型（G.EXP/G.TYP/G.OPR）](5-5-表达式与类型-g-exp-g-typ-g-opr.md) | 速查`G.EXP.01`：match 表达式同一层避免不同类别 pattern 混用；`G.EXP.02`：不要期望浮点运算得到精确的值；`G.EXP.03`：`&&`/`\|\|`/`?`/`??` 右侧操作数不要包含副作用；另含更多表项。 |
| [5.6 错误处理与包（G.ERR/G.PKG）](5-6-错误处理与包-g-err-g-pkg.md) | 速查`G.ERR.01`：恰当使用异常或错误处理机制；`G.ERR.02`：防止通过异常抛出的内容泄露敏感信息；`G.ERR.03`：避免对 Option 类型使用 `getOrThrow`；另含更多表项。 |
| [5.7 安全相关（G.CHK/G.CON/G.SEC/G.FIO/G.SER/G.OTH/P/FFI）](5-7-安全相关-g-chk-g-con-g-sec-g-fio-g-ser-g-oth-p-ffi.md) | 速查`G.CHK.01`：跨信任边界数据须校验；`G.CHK.02`：禁止直接使用外部数据记录日志；`G.CHK.03`：使用外部数据构造文件路径前须校验，校验前须规范化处理；另含更多表项。 |
| [5.8 默认不启用规则](5-8-默认不启用规则.md) | G.NAM.06（变量名小驼峰）、G.VAR.03（避免全局变量）、G.FMT.13（文件头版权注释） |
