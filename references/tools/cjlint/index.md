# cjlint 静态检查

[← 工具链](../index.md)

检查命令、规则分类、告警屏蔽与语法禁用检查。

| 规则/任务 | 摘要 |
|---|---|
| [1. 概述](1-概述.md) | `cjlint`（Cangjie Lint）是基于仓颉语言编程规范的静态检查工具，帮助识别不符合规范的代码问题和安全漏洞。 |
| [2. 基本用法](2-基本用法.md) | 注意：`-f` 后指定的是 `.cj` 文件所在的 `src` 目录，不是单个文件。 |
| [3. 命令选项](3-命令选项.md) | 速查`-h`：显示帮助信息；`-v`：显示版本号；`-f <dir>`：指定检查目录（多个目录用空格分隔，双引号包裹）；另含更多表项。 |
| [4. 告警屏蔽](4-告警屏蔽/index.md) | `cjlint-ignore`、选项（`-start`/`-end`）和规则名须在同一行。 |
| [5. 常用规则分类](5-常用规则分类/index.md) | G.NAM.06（变量名小驼峰）、G.VAR.03（避免全局变量）、G.FMT.13（文件头版权注释） |
| [6. 语法禁用检查](6-语法禁用检查.md) | 支持的关键字：`Import`、`Let`、`Spawn` 等（共 23 项）。 |
