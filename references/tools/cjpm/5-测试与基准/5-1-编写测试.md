# 5.1 编写测试

[← 5. 测试与基准](index.md)

测试文件以 `_test.cj` 结尾，放在 `src/` 目录下：

```cangjie cjtest=syntax id=syntax-794401a963-1 form=unit
// src/math_test.cj
package myapp

import std.unittest.*
import std.unittest.testmacro.*

@Test
func testAdd(): Unit {
    @Expect(1 + 1, 2)
}

@Test
func testMultiply(): Unit {
    @Expect(3 * 4, 12)
}
```

```bash
cjpm test                              # 运行全部测试
cjpm test --coverage                   # 测试并生成覆盖率
```
