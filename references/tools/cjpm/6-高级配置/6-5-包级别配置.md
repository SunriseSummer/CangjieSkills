# 6.5 包级别配置

[← 6. 高级配置](index.md)

配置入口：`[package]`。

```toml
[package]
  cjc-version = "1.1.3"
  name = "myapp"
  version = "1.0.0"
  output-type = "executable"

[package.package-configuration."myapp.utils"]
  compile-option = "-O2"
```
