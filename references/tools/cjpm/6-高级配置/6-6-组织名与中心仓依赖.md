# 6.6 组织名与中心仓依赖

[← 6. 高级配置](index.md)

`[package] organization = "acme"` 把模块身份设为 `acme::name`；源码中的包声明/导入必须同步使用该前缀。中心仓依赖以带引号的 `"org::name"` 为键：

```toml
[package]
cjc-version = "1.1.3"
name = "app"
organization = "acme"
version = "1.0.0"
output-type = "executable"

[dependencies]
"vendor::codec" = "2.0.0"
```

`cjpm install vendor::codec-2.0.0` 从中心仓安装指定模块。路径/git 依赖若与中心仓模块形成版本冲突，1.1.3 会报错而不是静默选取；用锁文件与 `cjpm tree` 确认最终依赖图。
