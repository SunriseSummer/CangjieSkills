# 2.1 目录结构

[← 2. 项目结构与 cjpm.toml](index.md)

代码展示 `myapp/` 的典型用法。

```
myapp/
├── cjpm.toml              # 项目配置文件
├── src/
│   ├── main.cj            # 主入口（executable 类型）
│   ├── lib_test.cj        # 测试文件（_test.cj 后缀）
│   └── utils/
│       └── helper.cj      # 子包
└── target/                # 构建产物目录（自动生成）
```
