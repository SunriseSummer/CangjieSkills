# 3.6 安装与卸载

[← 3. 常用命令选项表](index.md)

```bash
cjpm install --path .                  # 安装本地 executable 项目
cjpm install --git <url> --tag v1.0.0  # 安装 Git 项目
cjpm install --list                    # 列出已安装产物
cjpm uninstall myapp                   # 卸载一个或多个给定名称
```

`install` 只接受 `executable` 产物。本地 `--path` 与远程 `--git` 至多选择一种；Git 定位选项同时出现时优先级为 `--commit` > `--branch` > `--tag`。用 `--root <path>` 覆盖安装根目录，卸载时也应传相同根目录。
