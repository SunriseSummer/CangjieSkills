# 3.4 依赖检查与锁文件

[← 3. 常用命令选项表](index.md)

| 命令 | 用途 | 常用选项 |
|---|---|---|
| `cjpm check` | 检查依赖并打印有效的包编译顺序；循环或缺失依赖会报错 | `-m/--member`、`--no-tests`、`--skip-script` |
| `cjpm update` | 把 `cjpm.toml` 的依赖解析结果写入或更新 `cjpm.lock` | `--skip-script` |

`cjpm build` 会创建 `cjpm.lock`，后续构建使用其中锁定的传递依赖版本。需要可复现构建时应提交该文件；显式刷新 Git 依赖版本时运行 `cjpm update`。
