# 3.5 查看依赖树

[← 3. 常用命令选项表](index.md)

命令：`cjpm tree`。

```bash
cjpm tree                              # 显示所有包的依赖树
cjpm tree --depth 3 -p myapp           # 以指定包为根，限制深度
cjpm tree --invert mylib               # 查看哪些包依赖 mylib
```

| 选项 | 说明 |
|---|---|
| `-V, --verbose` | 显示包名、版本和路径 |
| `--depth <N>` | 限制最大子节点深度，`N` 为非负整数 |
| `-p, --package <name>` | 以指定包为根展示其依赖 |
| `--invert <name>` | 反转树，展示指定包的被依赖关系 |
| `--target <value>` | 纳入目标平台依赖 |
| `--no-tests` | 排除测试依赖 |
