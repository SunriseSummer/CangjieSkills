# 1. 基本用法

[← cjpm 项目管理](index.md)

新模块优先由 `cjpm init --name <合法包名> --type=executable` 生成完整清单和源码骨架，不要手写不完整的 `cjpm.toml`；程序参数用 `cjpm run --run-args="..."` 传递。

```bash
cjpm init                          # 创建新模块（默认 executable 类型）
cjpm init --workspace              # 创建工作空间
cjpm init --type=static            # 创建静态库模块
cjpm build                         # 编译当前模块
cjpm run                           # 编译并运行
cjpm test                          # 编译并运行单元测试
cjpm bench                         # 编译并运行基准测试
cjpm clean                         # 清理构建产物（target 目录）
cjpm install                       # 安装仓颉可执行文件
cjpm tree                          # 显示依赖树
```

向程序传参使用 `cjpm run --run-args="arg1 arg2"`；仓颉 1.0.5 的 `cjpm run` 不使用其他 CLI 常见的 `-- arg1 arg2` 透传形式。

---

## 包名与目录名

新模块优先交给 `cjpm init` 生成完整的 `cjpm.toml` 和 `src/main.cj`。可执行模块的类型参数是 `--type=executable`（不是 `--output-type`）；它也是默认类型。目录名含 `-` 等不合法的仓颉标识符字符时，显式指定合法包名：

```shell cjtest=syntax id=tools.cjpm.init-name
cjpm init --name my_app --type=executable
```

根包名与源码的 `package my_app` 保持一致。
