# ProtocolType.==

[← ProtocolType](index.md)

## 签名

```cangjie role=signature
public operator func ==(r: ProtocolType): Bool
```

判断两个 ProtocolType 实例是否相等。

## 契约

参数：

- r: ProtocolType - 参与比较的 ProtocolType 实例。

返回值：

- Bool - 当二者代表的 Int32 值相等时，返回 `true`；否则，返回 `false`。
