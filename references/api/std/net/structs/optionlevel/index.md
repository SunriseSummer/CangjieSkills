# OptionLevel

[← std.net](../../index.md)

`OptionLevel`

提供了常用的套接字选项级别。

## 属性与字段

| 签名 | 功能 |
|---|---|
| [`ICMP: Int32 = 1`](field-icmp.md) | 控制 `ICMP` 协议行为的套接字选项级别。 |
| [`IP: Int32 = 0`](field-ip.md) | 控制 IP 协议行为的套接字选项级别。 |
| [`RAW: Int32 = 255`](field-raw.md) | 控制 `RAW` 协议行为的套接字选项级别。 |
| [`SOCKET: Int32`](field-socket.md) | 控制基本套接字行为的套接字选项级别。 |
| [`TCP: Int32 = 6`](field-tcp.md) | 控制 `TCP` 协议行为的套接字选项级别。 |
| [`UDP: Int32 = 17`](field-udp.md) | 控制 `UDP` 协议行为的套接字选项级别。 |
