# OptionLevel.SOCKET

[← OptionLevel](index.md)

## 签名

```cangjie role=signature
public static const SOCKET: Int32
```

控制基本套接字行为的套接字选项级别。

## 契约

功能：控制基本套接字行为的套接字选项级别。不同系统下的值分别为：

- macOS: 0xFFFF
- Windows: 0xFFFF
- 其他情况：1

类型：Int32
