# SocketOptions

[← std.net](../../index.md)

`SocketOptions`

SocketOptions 存储了设置套接字选项的一些参数常量方便后续调用。

## 属性与字段

| 签名 | 功能 |
|---|---|
| [`SO_BINDTODEVICE: Int32`](field-so_bindtodevice.md) | 常数，用于将套接字选项的 `optname` 设为 `SO_BINDTODEVICE`。 |
| [`SO_KEEPALIVE: Int32`](field-so_keepalive.md) | 常数，用于将套接字选项的 `optname` 设为 `SO_KEEPALIVE`。 |
| [`SO_LINGER: Int32`](field-so_linger.md) | 常数，用于将套接字选项的 `optname` 设为 `SO_LINGER`。 |
| [`SO_RCVBUF: Int32`](field-so_rcvbuf.md) | 常数，用于将套接字选项的 `optname` 设为 `SO_RCVBUF`。 |
| [`SO_REUSEADDR: Int32`](field-so_reuseaddr.md) | 常数，用于将套接字选项的 `optname` 设为 `SO_REUSEADDR`。 |
| [`SO_REUSEPORT: Int32`](field-so_reuseport.md) | 常数，用于将套接字选项的 `optname` 设为 `SO_REUSEPORT`。 |
| [`SO_SNDBUF: Int32`](field-so_sndbuf.md) | 常数，用于将套接字选项的 `optname` 设为 `SO_SNDBUF`。 |
| [`TCP_NODELAY: Int32 = 0x0001`](field-tcp_nodelay.md) | 常数，用于将套接字选项的 `optname` 设为 `TCP_NODELAY`。 |
| [`TCP_QUICKACK: Int32`](field-tcp_quickack.md) | 常数，用于将套接字选项的 `optname` 设为 `TCP_QUICKACK`。 |
