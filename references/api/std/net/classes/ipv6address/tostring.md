# IPv6Address.toString

[← IPv6Address](index.md)

## 签名

```cangjie role=signature
public func toString(): String
```

返回当前 IPv6Address 的文本表示字符串。

## 契约

返回值：

- String - 当前 IPv6Address 的文本表示字符串，比如 `2001:db8:1:2:ffff:ffff:ffff:ffff`。
