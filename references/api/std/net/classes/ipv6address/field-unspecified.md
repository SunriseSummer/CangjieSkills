# IPv6Address.unspecified

[← IPv6Address](index.md)

## 签名

```cangjie role=signature
public static let unspecified: IPv6Address = IPv6Address(0u16, 0, 0, 0, 0, 0, 0, 0)
```

返回表示未指定的 IPv6Address 地址：`::`，这对应于其他语言中的常量 `INADDR_ANY`。

## 契约

类型：IPv6Address
