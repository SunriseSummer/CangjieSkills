# IPv6Address.<=

[← IPv6Address](index.md)

## 签名

```cangjie role=signature
public operator func <=(rhs: IPv6Address): Bool
```

判断本 IPv6Address 对象是否小于等于被比较的 IPv6Address 对象。

## 契约

参数：

- rhs: IPv6Address - 参与比较的 IPv6Address 对象。

返回值：

- Bool - 如果本 IPv6Address 对象小于等于被比较的 IPv6Address 对象，则返回 `true`；否则，返回 `false`。
