# IPAddress.isUnspecified

[← IPAddress](index.md)

## 签名

```cangjie role=signature
public open func isUnspecified(): Bool
```

判断此 IPAddress 对象是不是“未指定” IP 地址。

## 契约

返回值：

- Bool - 返回 true 表示是“未指定” IP 地址，否则返回 false。
