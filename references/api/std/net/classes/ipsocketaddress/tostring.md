# IPSocketAddress.toString

[← IPSocketAddress](index.md)

## 签名

```cangjie role=signature
public func toString(): String
```

返回当前 IPSocketAddress 的文本表示字符串。

## 契约

返回值：

- String - 当前 IPSocketAddress 的文本表示字符串，比如 `192.168.1.2:8080` 或 `[fc00::/16]:8080` 。
