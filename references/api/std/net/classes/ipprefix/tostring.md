# IPPrefix.toString

[← IPPrefix](index.md)

## 签名

```cangjie role=signature
public func toString(): String
```

返回当前 IPPrefix 的文本表示字符串。

## 契约

返回值：

- String - 当前 IPPrefix 的文本表示字符串，比如 `192.168.0.0/16` 或 `fc00::/16`。
