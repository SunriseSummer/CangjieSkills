# IPPrefix.overlaps

[← IPPrefix](index.md)

## 签名

```cangjie role=signature
public func overlaps(rhs: IPPrefix): Bool
```

此 IPPrefix 地址是不是和指定的 IPPrefix 地址有重叠。

## 契约

参数：

- rhs: IPPrefix - 指定的 IPPrefix 地址。

返回值：

- Bool - 返回 true 表示和指定的 IPPrefix 地址有重叠，false 表示没有重叠。
