# IPPrefix.!=

[← IPPrefix](index.md)

## 签名

```cangjie role=signature
public operator func !=(rhs: IPPrefix): Bool
```

判断两个 IPPrefix 对象是否不等。

## 契约

参数：

- rhs: IPPrefix - 参与比较的 IPPrefix 对象。

返回值：

- Bool - 如果两个 IPPrefix 对象不等，则返回 `true`；否则，返回 `false`。
