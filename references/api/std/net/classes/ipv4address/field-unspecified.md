# IPv4Address.unspecified

[← IPv4Address](index.md)

## 签名

```cangjie role=signature
public static let unspecified: IPv4Address = IPv4Address(0, 0, 0, 0)
```

返回表示未指定的 IPv4Address 地址：`0.0.0.0`，这对应于其他语言中的常量 `INADDR_ANY`。

## 契约

类型：IPv4Address
