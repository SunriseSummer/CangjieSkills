# IPv4Address.isUnspecified

[← IPv4Address](index.md)

## 签名

```cangjie role=signature
public func isUnspecified(): Bool
```

判断此 IPv4Address 对象是不是“未指定” IP 地址。

## 契约

- Bool - 返回 true 表示是“未指定” IP 地址，否则返回 false。
