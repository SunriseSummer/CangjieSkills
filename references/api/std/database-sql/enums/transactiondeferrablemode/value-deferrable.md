# TransactionDeferrableMode.Deferrable

[← TransactionDeferrableMode](index.md)

## 签名

```cangjie role=signature
Deferrable
```

表示可延迟。

## 契约

> **说明：**
>
> 延迟事务是指在前滚阶段结束时未提交的事务，并且遇到了阻止其回滚的错误。因为事务无法回滚，所以它被延迟。
