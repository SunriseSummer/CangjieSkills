# SqlOption.SSLModePreferred

[← SqlOption](index.md)

## 签名

```cangjie role=signature
public static const SSLModePreferred: String = "ssl.mode.preferred"
```

如果服务器支持加密连接，则建立加密连接；如果无法建立加密连接，则回退到未加密连接，这是 SSLMode 的默认值。

## 契约

类型：String
