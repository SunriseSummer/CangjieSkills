# SqlOption.SSLModeVerifyFull

[← SqlOption](index.md)

## 签名

```cangjie role=signature
public static const SSLModeVerifyFull: String = "ssl.mode.verify_full"
```

SSLModeVerifyFull 和 SSLModeVerifyCA 类似，但通过验证服务器证书中的标识与客户端连接的主机名是否匹配，来执行主机名身份验证。
