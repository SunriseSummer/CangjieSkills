# Statement.parameterColumnInfos

[← Statement](index.md)

## 签名

```cangjie role=signature
prop parameterColumnInfos: Array<ColumnInfo>
```

预执行 sql 语句中，占位参数的列信息，比如列名，列类型，列长度，是否允许数据库 `Null` 值等。

## 契约

类型：Array\<ColumnInfo>
