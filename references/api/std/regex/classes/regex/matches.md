# Regex.matches

[← Regex](index.md)

## 签名

```cangjie role=signature
public func matches(input: String): Bool
```

判断入参 input 与正则表达式是否存在匹配。

## 契约

参数：

- input: String - 要匹配的字符串。

返回值：

- Bool - 如果存在匹配，返回 true，否则返回 false。
