# MockSessionKind

[← std.unittest.mock](../../index.md)

`MockSessionKind`

控制允许在 `MockSession` 使用的桩的类型。

## 枚举值

| 签名 | 功能 |
|---|---|
| [`Forbidden`](value-forbidden.md) | 不允许使用桩。 |
| [`Stateless`](value-stateless.md) | 只允许无状态的桩。 |
| [`Verifiable`](value-verifiable.md) | 允许任意桩。 |
