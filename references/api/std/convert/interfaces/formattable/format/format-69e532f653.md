# Formattable.func format(String)

[← Formattable.format](index.md)

## 签名

```cangjie role=signature
func format(fmt: String): String
```

根据格式化参数将当前实例格式化为对应格式的字符串。

## 契约

参数：

- fmt: String - 格式化参数。

返回值：

- String - 将当前实例格式化后得到的字符串。
