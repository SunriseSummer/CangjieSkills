# extend Float16 <: Formattable

[← Formattable](../index.md)

`extend Float16 <: Formattable`

为 Float16 扩展 Formattable 接口，以实现将 Float16 实例转换为格式化字符串。

## 成员

| 签名 | 功能 |
|---|---|
| [`format(fmt: String): String`](../format/index.md) | 根据格式化参数将当前 Float16 类型实例格式化为对应格式的字符串。 |
