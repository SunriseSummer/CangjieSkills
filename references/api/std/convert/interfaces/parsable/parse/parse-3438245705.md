# Parsable<T>.static func parse(String)

[← Parsable<T>.parse](index.md)

## 签名

```cangjie role=signature
public static func parse(data: String): Bool
```

将 Bool 类型字面量的字符串转换为 Bool 值。

适用扩展：[extend Bool <: Parsable<Bool>](../extensions/extend-bool-parsable-bool.md)。

## 契约

参数：

- data: String - 要转换的字符串。

返回值：

- Bool - 返回转换后 Bool 值。

异常：

- IllegalArgumentException - 当字符串为空或转换失败时，抛出异常。
