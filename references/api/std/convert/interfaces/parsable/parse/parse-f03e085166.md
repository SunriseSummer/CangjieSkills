# Parsable<T>.static func parse(String)

[← Parsable<T>.parse](index.md)

## 签名

```cangjie role=signature
public static func parse(data: String): Float64
```

将 Float64 类型字面量的字符串转换为 Float64 值。

适用扩展：[extend Float64 <: Parsable<Float64>](../extensions/extend-float64-parsable-float64.md)。

## 契约

参数：

- data: String - 要转换的字符串。

返回值：

- Float64 - 返回转换后 Float64 值。

异常：

- IllegalArgumentException - 当字符串不符合浮点数语法时，抛出异常。
