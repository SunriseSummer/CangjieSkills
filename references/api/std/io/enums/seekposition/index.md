# SeekPosition

[← std.io](../../index.md)

`SeekPosition`

该枚举类型表示光标在文件中的位置。

## 枚举值

| 签名 | 功能 |
|---|---|
| [`Begin(Int64)`](value-begin-int64.md) | 表示从起点开始移动指定的长度。 |
| [`Current(Int64)`](value-current-int64.md) | 表示从当前位置开始移动指定的长度。 |
| [`End(Int64)`](value-end-int64.md) | 表示从末尾开始移动指定的长度。 |
