# StackOverflowError

[← std.core](../../index.md)

`StackOverflowError <: Error`

表示堆栈溢出错误的错误类，该类不可被继承，不可初始化，但是可以被捕获到。

## 方法

| 签名 | 功能 |
|---|---|
| [`override printStackTrace(): Unit`](printstacktrace.md) | 向控制台打印堆栈信息。 |
