# Float32.isInf

[← extend Float32](extensions/extend-float32.md)

## 签名

```cangjie role=signature
public func isInf(): Bool
```

判断某个浮点数 Float32 是否为无穷数值。

## 契约

返回值：

- Bool - 如果 Float32 的值正无穷大或负无穷大，则返回 `true`；否则，返回 `false`。
