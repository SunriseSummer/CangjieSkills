# Float32.toBits

[← extend Float32](extensions/extend-float32-2.md)

## 签名

```cangjie role=signature
public func toBits(): UInt32
```

将指定的 Float32 数转换为以位表示的对应 UInt32 数。

## 契约

返回值：

- UInt32 - 转换结果，其值与 Float32 的位表示相同。
