# Float32.isNormal

[← extend Float32](extensions/extend-float32.md)

## 签名

```cangjie role=signature
public func isNormal(): Bool
```

判断某个浮点数 Float32 是否为常规数值。

## 契约

返回值：

- Bool - 如果 Float32 的值是正常的浮点数，返回 `true`；否则，返回 `false`。
