# Float32.isNaN

[← extend Float32](extensions/extend-float32.md)

## 签名

```cangjie role=signature
public func isNaN(): Bool
```

判断某个浮点数 Float32 是否为非数值。

## 契约

返回值：

- Bool - 如果 Float32 的值为非数值，则返回 `true`；否则，返回 `false`。
