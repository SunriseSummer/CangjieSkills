# Int16.position

[← extend Int16 <: Countable<Int16>](extensions/extend-int16-countable-int16.md)

## 签名

```cangjie role=signature
public func position(): Int64
```

获取当前 Int16 值的位置信息，即将该 Int16 转换为 Int64 值。

## 契约

返回值：

- Int64 - 当前 Int16 值的位置信息。
