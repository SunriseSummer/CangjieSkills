# Int16

[← std.core](../../index.md)

表示 16 位有符号整型，表示范围为 [-2^{15}, 2^{15} - 1]。

## 扩展实现

| 扩展声明 | 功能 |
|---|---|
| [`extend Int16`](extensions/extend-int16.md) | 拓展 16 位有符号整数以支持一些数学常数。 |
| [`extend Int16 <: Comparable<Int16>`](extensions/extend-int16-comparable-int16.md) | 为 Int16 类型扩展 Comparable<Int16> 接口，支持比较操作。 |
| [`extend Int16 <: Countable<Int16>`](extensions/extend-int16-countable-int16.md) | 为 Int16 类型扩展 Countable<Int16> 接口，支持计数操作。 |
| [`extend Int16 <: Hashable`](extensions/extend-int16-hashable.md) | 为 Int16 类型扩展 Hashable 接口，支持计算哈希值。 |
| [`extend Int16 <: ToString`](extensions/extend-int16-tostring.md) | 这里为 Int16 类型扩展 ToString 接口，实现向 String 类型的转换。 |
