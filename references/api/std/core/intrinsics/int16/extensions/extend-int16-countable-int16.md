# extend Int16 <: Countable<Int16>

[← Int16](../index.md)

`extend Int16 <: Countable<Int16>`

为 Int16 类型扩展 Countable<Int16> 接口，支持计数操作。

## 成员

| 签名 | 功能 |
|---|---|
| [`next(right: Int64): Int16`](../next.md) | 获取在数轴上当前 Int16 位置往右移动 `right` 后对应位置的 Int16 值。 |
| [`position(): Int64`](../position.md) | 获取当前 Int16 值的位置信息，即将该 Int16 转换为 Int64 值。 |
