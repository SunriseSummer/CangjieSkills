# extend UInt64 <: Hashable

[← UInt64](../index.md)

`extend UInt64 <: Hashable`

## 成员

| 签名 | 功能 |
|---|---|
| [`hashCode(): Int64`](../hashcode.md) | 获取哈希值。 |
