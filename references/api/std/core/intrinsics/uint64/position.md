# UInt64.position

[← extend UInt64 <: Countable<UInt64>](extensions/extend-uint64-countable-uint64.md)

## 签名

```cangjie role=signature
public func position(): Int64
```

获取当前 UInt64 值的位置信息，即将该 UInt64 转换为 Int64 值。

## 契约

返回值：

- Int64 - 当前 UInt64 值的位置信息。
