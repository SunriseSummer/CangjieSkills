# Int8.position

[← extend Int8 <: Countable<Int8>](extensions/extend-int8-countable-int8.md)

## 签名

```cangjie role=signature
public func position(): Int64
```

获取当前 Int8 值的位置信息，即将该 Int8 转换为 Int64 值。

## 契约

返回值：

- Int64 - 当前 Int8 值的位置信息。
