# Int8

[← std.core](../../index.md)

表示 8 位有符号整型，表示范围为 [-2^7, 2^7 - 1]。

## 扩展实现

| 扩展声明 | 功能 |
|---|---|
| [`extend Int8`](extensions/extend-int8.md) | 拓展 8 位有符号整数以支持一些数学常数。 |
| [`extend Int8 <: Comparable<Int8>`](extensions/extend-int8-comparable-int8.md) | 为 Int8 类型扩展 Comparable<Int8> 接口，支持比较操作。 |
| [`extend Int8 <: Countable<Int8>`](extensions/extend-int8-countable-int8.md) | 为 Int8 类型扩展 Countable<Int8> 接口，支持计数操作。 |
| [`extend Int8 <: Hashable`](extensions/extend-int8-hashable.md) | 为 Int8 类型扩展 Hashable 接口，支持计算哈希值。 |
| [`extend Int8 <: ToString`](extensions/extend-int8-tostring.md) | 这里为 Int8 类型扩展 ToString 接口，实现向 String 类型的转换。 |
