# extend UInt32 <: Comparable<UInt32>

[← UInt32](../index.md)

## 成员

| 签名 | 功能 |
|---|---|
| [`compare(rhs: UInt32): Ordering`](../compare.md) | 判断当前 UInt32 值与指定 UInt32 值的大小关系。 |
