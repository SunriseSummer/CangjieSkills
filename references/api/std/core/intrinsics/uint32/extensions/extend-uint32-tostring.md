# extend UInt32 <: ToString

[← UInt32](../index.md)

`extend UInt32 <: ToString`

这里为 UInt32 类型扩展 ToString 接口，实现向 String 类型的转换。

## 成员

| 签名 | 功能 |
|---|---|
| [`toString(): String`](../tostring.md) | 将 UInt32 值转换为可输出的字符串。 |
