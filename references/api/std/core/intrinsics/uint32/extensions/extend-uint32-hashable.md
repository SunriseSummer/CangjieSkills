# extend UInt32 <: Hashable

[← UInt32](../index.md)

`extend UInt32 <: Hashable`

## 成员

| 签名 | 功能 |
|---|---|
| [`hashCode(): Int64`](../hashcode.md) | 获取哈希值。 |
