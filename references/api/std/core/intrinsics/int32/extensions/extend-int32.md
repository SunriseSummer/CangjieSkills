# extend Int32

[← Int32](../index.md)

`extend Int32`

拓展 32 位有符号整数以支持一些数学常数。

## 成员

| 签名 | 功能 |
|---|---|
| [`static Max: Int32`](../prop-max.md) | 获取 32 位有符号整数的最大值。 |
| [`static Min: Int32`](../prop-min.md) | 获取 32 位有符号整数的最小值。 |
