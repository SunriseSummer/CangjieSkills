# Int32.position

[← extend Int32 <: Countable<Int32>](extensions/extend-int32-countable-int32.md)

## 签名

```cangjie role=signature
public func position(): Int64
```

获取当前 Int32 值的位置信息，即将该 Int32 转换为 Int64 值。

## 契约

返回值：

- Int64 - 当前 Int32 值的位置信息。
