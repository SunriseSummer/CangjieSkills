# Int32

[← std.core](../../index.md)

表示 32 位有符号整型，表示范围为 [-2^{31}, 2^{31} - 1]。

## 扩展实现

| 扩展声明 | 功能 |
|---|---|
| [`extend Int32`](extensions/extend-int32.md) | 拓展 32 位有符号整数以支持一些数学常数。 |
| [`extend Int32 <: Comparable<Int32>`](extensions/extend-int32-comparable-int32.md) | 为 Int32 类型扩展 Comparable<Int32> 接口，支持比较操作。 |
| [`extend Int32 <: Countable<Int32>`](extensions/extend-int32-countable-int32.md) | 为 Int32 类型扩展 Countable<Int32> 接口，支持计数操作。 |
| [`extend Int32 <: Hashable`](extensions/extend-int32-hashable.md) | 为 Int32 类型扩展 Hashable 接口，支持计算哈希值。 |
| [`extend Int32 <: ToString`](extensions/extend-int32-tostring.md) | 这里为 Int32 类型扩展 ToString 接口，实现向 String 类型的转换。 |
