# CString

[← std.core](../../index.md)

表示 C 风格字符串，在与 C 语言互操作的场景下使用。

## 扩展实现

| 扩展声明 | 功能 |
|---|---|
| [`extend CString <: ToString`](extensions/extend-cstring-tostring.md) | 为 CString 类型扩展一些字符串指针常用方法，包括判空、获取长度、判等、获取子串等。 |
