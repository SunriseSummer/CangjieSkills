# extend Unit <: Hashable

[← Unit](../index.md)

`extend Unit <: Hashable`

为 Unit 类型扩展 Hashable 接口，支持计算哈希值。

## 成员

| 签名 | 功能 |
|---|---|
| [`hashCode(): Int64`](../hashcode.md) | 获取哈希值，Unit 的哈希值为 0。 |
