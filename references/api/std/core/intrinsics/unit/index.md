# Unit

[← std.core](../../index.md)

表示仓颉语言中只关心副作用而不关心值的表达式的类型。

## 扩展实现

| 扩展声明 | 功能 |
|---|---|
| [`extend Unit <: Equatable<Unit>`](extensions/extend-unit-equatable-unit.md) | 为 Unit 类型扩展 Equatable<Unit> 接口。 |
| [`extend Unit <: Hashable`](extensions/extend-unit-hashable.md) | 为 Unit 类型扩展 Hashable 接口，支持计算哈希值。 |
| [`extend Unit <: ToString`](extensions/extend-unit-tostring.md) | 为 Unit 类型其扩展 ToString 接口，实现向 String 类型的转换。 |
