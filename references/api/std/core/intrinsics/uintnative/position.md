# UIntNative.position

[← extend UIntNative <: Countable](extensions/extend-uintnative-countable.md)

## 签名

```cangjie role=signature
public func position(): Int64
```

获取当前 UIntNative 值的位置信息，即将该 UIntNative 转换为 Int64 值。

## 契约

返回值：

- Int64 - 当前 UIntNative 值的位置信息。
