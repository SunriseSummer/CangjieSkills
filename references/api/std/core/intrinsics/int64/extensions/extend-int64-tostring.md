# extend Int64 <: ToString

[← Int64](../index.md)

`extend Int64 <: ToString`

这里为 Int64 类型扩展 ToString 接口，实现向 String 类型的转换。

## 成员

| 签名 | 功能 |
|---|---|
| [`toString(): String`](../tostring.md) | 将 Int64 值转换为可输出的字符串。 |
