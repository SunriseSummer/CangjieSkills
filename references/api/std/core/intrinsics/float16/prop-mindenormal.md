# Float16.MinDenormal

[← extend Float16](extensions/extend-float16.md)

## 签名

```cangjie role=signature
public static prop MinDenormal: Float16
```

获取半精度浮点数的最小次正规数。

## 契约

功能：获取半精度浮点数的最小次正规数。最小的正的次正规数是以 IEEE 双精度格式表示的最小正数。

类型：Float16
