# Float16.toBits

[← extend Float16](extensions/extend-float16-2.md)

## 签名

```cangjie role=signature
public func toBits(): UInt16
```

将指定的 Float16 数转换为以位表示的对应 UInt16 数。

## 契约

返回值：

- UInt16 - 转换结果，其值与 Float16 的位表示相同。
