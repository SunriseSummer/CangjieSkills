# Float16.fromBits

[← extend Float16](extensions/extend-float16-2.md)

## 签名

```cangjie role=signature
public static func fromBits(bits: UInt16): Float16
```

将指定的 UInt16 数转换为 Float16 数。

## 契约

参数：

- bits: UInt16 - 要转换的数字。

返回值：

- Float16 - 转换结果，其位与参数 bits 值相同。
