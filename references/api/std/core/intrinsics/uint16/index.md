# UInt16

[← std.core](../../index.md)

表示 16 位无符号整型，表示范围为 [0, 2^{16} - 1]。

## 扩展实现

| 扩展声明 | 功能 |
|---|---|
| [`extend UInt16`](extensions/extend-uint16.md) | 拓展 16 位无符号整数以支持一些数学常数。 |
| [`extend UInt16 <: Comparable<UInt16>`](extensions/extend-uint16-comparable-uint16.md) | 为 UInt16 类型扩展 Comparable<UInt16> 接口，支持比较操作。 |
| [`extend UInt16 <: Countable<UInt16>`](extensions/extend-uint16-countable-uint16.md) | 为 UInt16 类型扩展 Countable<UInt16> 接口，支持计数操作。 |
| [`extend UInt16 <: Hashable`](extensions/extend-uint16-hashable.md) | 为 UInt16 类型扩展 Hashable 接口，支持计算哈希值。 |
| [`extend UInt16 <: ToString`](extensions/extend-uint16-tostring.md) | 这里为 UInt16 类型扩展 ToString 接口，实现向 String 类型的转换。 |
