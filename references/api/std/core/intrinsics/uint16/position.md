# UInt16.position

[← extend UInt16 <: Countable<UInt16>](extensions/extend-uint16-countable-uint16.md)

## 签名

```cangjie role=signature
public func position(): Int64
```

获取当前 UInt16 值的位置信息，即将该 UInt16 转换为 Int64 值。

## 契约

返回值：

- Int64 - 当前 UInt16 值的位置信息。
