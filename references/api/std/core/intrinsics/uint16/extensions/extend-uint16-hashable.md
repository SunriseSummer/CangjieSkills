# extend UInt16 <: Hashable

[← UInt16](../index.md)

`extend UInt16 <: Hashable`

为 UInt16 类型扩展 Hashable 接口，支持计算哈希值。

## 成员

| 签名 | 功能 |
|---|---|
| [`hashCode(): Int64`](../hashcode.md) | 获取哈希值。 |
