# UInt8

[← std.core](../../index.md)

表示 8 位无符号整型，表示范围为 [0, 2^8 - 1]。

## 扩展实现

| 扩展声明 | 功能 |
|---|---|
| [`extend UInt8`](extensions/extend-uint8.md) | 拓展 8 位无符号整数以支持一些数学常数。 |
| [`extend UInt8 <: Comparable<UInt8>`](extensions/extend-uint8-comparable-uint8.md) | 为 UInt8 类型扩展 Comparable<UInt8> 接口，支持比较操作。 |
| [`extend UInt8 <: Countable<UInt8>`](extensions/extend-uint8-countable-uint8.md) | 为 UInt8 类型扩展 Countable<UInt8> 接口，支持计数操作。 |
| [`extend UInt8 <: Hashable`](extensions/extend-uint8-hashable.md) | 为 UInt8 类型扩展 Hashable 接口，支持计算哈希值。 |
| [`extend UInt8 <: ToString`](extensions/extend-uint8-tostring.md) | 这里为 UInt8 类型扩展 ToString 接口，实现向 String 类型的转换。 |
