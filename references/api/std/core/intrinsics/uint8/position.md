# UInt8.position

[← extend UInt8 <: Countable<UInt8>](extensions/extend-uint8-countable-uint8.md)

## 签名

```cangjie role=signature
public func position(): Int64
```

获取当前 UInt8 值的位置信息，即将该 UInt8 转换为 Int64 值。

## 契约

返回值：

- Int64 - 当前 UInt8 值的位置信息。
