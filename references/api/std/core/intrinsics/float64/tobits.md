# Float64.toBits

[← extend Float64](extensions/extend-float64-2.md)

## 签名

```cangjie role=signature
public func toBits(): UInt64
```

将指定的 Float64 数转换为以位表示的对应 UInt64 数。

## 契约

返回值：

- UInt64 - 转换结果，其值与 Float64 的位表示相同。
