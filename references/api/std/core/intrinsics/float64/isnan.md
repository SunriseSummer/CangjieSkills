# Float64.isNaN

[← extend Float64](extensions/extend-float64.md)

## 签名

```cangjie role=signature
public func isNaN(): Bool
```

判断某个浮点数 Float64 是否为非数值。

## 契约

返回值：

- Bool - 如果 Float64 的值为非数值，则返回 `true`；否则，返回 `false`。
