# String.toRuneArray

[← String](index.md)

## 签名

```cangjie role=signature
public func toRuneArray(): Array<Rune>
```

获取字符串的 Rune 数组。

## 契约

功能：获取字符串的 Rune 数组。如果原字符串为空字符串，则返回空数组。

返回值：

- Array\<Rune> - 字符串的 Rune 数组。
