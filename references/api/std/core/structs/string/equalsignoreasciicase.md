# String.equalsIgnoreAsciiCase

[← String](index.md)

## 签名

```cangjie role=signature
public func equalsIgnoreAsciiCase(that: String): Bool
```

判断当前字符串和指定字符串是否相等，忽略大小写。

## 契约

参数：

- that: String - 待比较的字符串。

返回值：

- Bool - 如果当前字符串与待比较字符串相等，返回 true，否则返回 false。
