# String.!=

[← String](index.md)

## 签名

```cangjie role=signature
public operator const func !=(right: String): Bool
```

判断两个字符串是否不相等。

## 契约

参数：

- right: String - 待比较的 String 实例。

返回值：

- Bool - 不相等返回 true，相等返回 false。
