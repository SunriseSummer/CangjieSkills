# extend Float64

[← Countable<T>](../index.md)

`extend Float64`

拓展了 Float64 类型作为左操作数和 Duration 类型作为右操作数的乘法运算。

## 成员

| 签名 | 功能 |
|---|---|
| [`operator *(r: Duration): Duration`](../operator-mul.md) | 实现 Float64 类型和 Duration 类型的乘法，即 Float64 * Duration 运算。 |
