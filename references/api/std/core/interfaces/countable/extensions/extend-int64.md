# extend Int64

[← Countable<T>](../index.md)

`extend Int64`

拓展了 Int64 类型作为左操作数和 Duration 类型作为右操作数的乘法运算。

## 成员

| 签名 | 功能 |
|---|---|
| [`operator *(r: Duration): Duration`](../operator-mul.md) | 实现 Int64 类型和 Duration 类型的乘法，即 Int64 * Duration 运算。 |
