# Countable<T>.next

[← Countable<T>](index.md)

## 签名

```cangjie role=signature
func next(right: Int64): T
```

获取当前实例向右移动 `right` 后对应位置的 `T` 类型实例。

## 契约

参数：

- right: Int64 - 往右数的个数。

返回值：

- T - 向右移动 `right` 后对应位置的 `T` 类型实例。
