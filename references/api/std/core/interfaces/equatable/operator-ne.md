# Equatable<T>.!=

[← Equatable<T>](index.md)

## 签名

```cangjie role=signature
operator func !=(rhs: T): Bool
```

判断两个实例是否不相等，该函数是此接口的一个默认实现函数。

## 契约

参数：

- rhs: T - 待比较的另一个实例。

返回值：

- Bool - 如果不相等，返回 true，否则返回 false。
