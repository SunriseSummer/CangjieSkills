# Any.isAsciiHex

[← extend Byte](extensions/extend-byte.md)

## 签名

```cangjie role=signature
public func isAsciiHex(): Bool
```

判断 Byte 是否是在 Ascii 十六进制数字范围内。

## 契约

返回值：

- Bool - 如果 Byte 在 Ascii 十六进制数字范围内返回 true，否则返回 false。
