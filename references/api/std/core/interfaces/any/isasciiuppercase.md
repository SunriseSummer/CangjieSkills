# Any.isAsciiUpperCase

[← extend Byte](extensions/extend-byte.md)

## 签名

```cangjie role=signature
public func isAsciiUpperCase(): Bool
```

判断 Byte 是否是在 Ascii 大写拉丁字母范围内。

## 契约

返回值：

- Bool - 如果 Byte 在 Ascii 大写拉丁字母范围内返回 true，否则返回 false。
