# Any

[← std.core](../../index.md)

`Any`

Any 是所有类型的父类型，所有 `interface` 都默认继承它，所有非 `interface` 类型都默认实现它。

## 扩展实现

| 扩展声明 | 功能 |
|---|---|
| [`extend Byte`](extensions/extend-byte.md) | 为 Byte 类型实现一系列扩展方法，主要为在 Ascii 字符集范围内的一些字符判断、转换等操作。 |
