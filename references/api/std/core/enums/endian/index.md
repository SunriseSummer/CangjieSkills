# Endian

[← std.core](../../index.md)

`Endian`

枚举类型 Endian 表示运行平台的端序，分为大端序和小端序。

## 枚举值

| 签名 | 功能 |
|---|---|
| [`Big`](value-big.md) | 表示大端序。 |
| [`Little`](value-little.md) | 表示小端序。 |

## 属性与字段

| 签名 | 功能 |
|---|---|
| [`static Platform: Endian`](prop-platform.md) | 获取所在运行平台的端序。 |
