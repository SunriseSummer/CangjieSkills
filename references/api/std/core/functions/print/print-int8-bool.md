# print(Int8, Bool)

[← print](index.md)

## 签名

```cangjie role=signature
public func print(i: Int8, flush!: Bool = false): Unit
```

向控制台输出 Int8 类型数据的字符串表达。

## 契约

参数：

- i: Int8 - 待输出的 Int8 类型数据。
- flush!: Bool - 是否清空缓存，true 清空，false 不清空，默认 false。
