# FloatingPoint<T>.isInf

[← FloatingPoint<T>](index.md)

## 签名

```cangjie role=signature
func isInf(): Bool
```

判断浮点数是否为无穷数值。

## 契约

返回值：

- Bool - 如果浮点数的值正无穷大或负无穷大，则返回 `true`；否则，返回 `false`。
