# gcd(UInt32, UInt32)

[← gcd](index.md)

## 签名

```cangjie role=signature
public func gcd(x: UInt32, y: UInt32): UInt32
```

求两个 32 位无符号整数的最大公约数。

## 契约

参数：

- x: UInt32 - 传入的需要计算最大公约数的第一个整数。
- y: UInt32 - 传入的需要计算最大公约数的第二个整数。

返回值：

- UInt32 - 返回两个整数的最大公约数。
