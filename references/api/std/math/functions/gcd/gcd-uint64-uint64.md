# gcd(UInt64, UInt64)

[← gcd](index.md)

## 签名

```cangjie role=signature
public func gcd(x: UInt64, y: UInt64): UInt64
```

求两个 64 位无符号整数的最大公约数。

## 契约

参数：

- x: UInt64 - 传入的需要计算最大公约数的第一个整数。
- y: UInt64 - 传入的需要计算最大公约数的第二个整数。

返回值：

- UInt64 - 返回两个整数的最大公约数。
