# gcd(UInt8, UInt8)

[← gcd](index.md)

## 签名

```cangjie role=signature
public func gcd(x: UInt8, y: UInt8): UInt8
```

求两个 8 位无符号整数的最大公约数。

## 契约

参数：

- x: UInt8 - 传入的需要计算最大公约数的第一个整数。
- y: UInt8 - 传入的需要计算最大公约数的第二个整数。

返回值：

- UInt8 - 返回两个整数的最大公约数。
