# gcd(UInt16, UInt16)

[← gcd](index.md)

## 签名

```cangjie role=signature
public func gcd(x: UInt16, y: UInt16): UInt16
```

求两个 16 位无符号整数的最大公约数。

## 契约

参数：

- x: UInt16 - 传入的需要计算最大公约数的第一个整数。
- y: UInt16 - 传入的需要计算最大公约数的第二个整数。

返回值：

- UInt16 - 返回两个整数的最大公约数。
