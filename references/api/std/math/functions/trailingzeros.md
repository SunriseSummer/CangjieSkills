## trailingZeros(Int16)

### 签名

```cangjie role=signature
public func trailingZeros(x: Int16): Int64
```

求 16 位有符号整数的二进制表达中的从最低位算起，连续位为 0 的个数。

### 契约

功能：求 16 位有符号整数的二进制表达中的从最低位算起，连续位为 0 的个数。如果最低位不是 0，则返回 0。

参数：

- x: Int16 - 需要求后置 0 的整数。

返回值：

- Int64 - 后置 0 的位数。
