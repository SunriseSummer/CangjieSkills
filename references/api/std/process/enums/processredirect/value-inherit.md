# ProcessRedirect.Inherit

[← ProcessRedirect](index.md)

## 签名

```cangjie role=signature
Inherit
```

构造一个标准流重定向枚举实例，表示子进程标准流将继承当前进程的标准流。

## 契约

功能：构造一个标准流重定向枚举实例，表示子进程标准流将继承当前进程的标准流。此模式下标准流属性不可读取或写入。
