# BigInt.init(Float64)

[← BigInt.init](index.md)

## 签名

```cangjie role=signature
public init(n: Float64)
```

通过双精度浮点数构建一个 BigInt 结构体。

## 契约

将丢弃浮点数的小数部分，即向零取整。

参数：

- n: Float64 - 单精度浮点数。

异常：

- IllegalArgumentException - 如果 n 为 `Inf` 或 `NaN`，则抛此异常。
