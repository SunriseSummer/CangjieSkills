# extend BigInt <: Formattable

[← BigInt](../index.md)

`extend BigInt <: Formattable`

为 BigInt 扩展 Formattable 接口，以实现将 BigInt 实例转换为格式化字符串。

## 成员

| 签名 | 功能 |
|---|---|
| [`format(fmt: String): String`](../format.md) | 根据格式化参数将当前 BigInt 类型实例格式化为对应格式的字符串。 |
