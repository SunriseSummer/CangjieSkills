[← Decimal.init](index.md)

通过 32 位无符号整数构建 Decimal 对象。

## 契约

功能：通过 32 位无符号整数构建 Decimal 对象。默认采用精度值为 0，即无限精度进行构建。

参数：

- val: UInt32 - 32 位无符号整数。
