[← Decimal.init](index.md)

public init(val: UIntNative)

通过 32 位或 64 位（具体长度与平台相关）无符号整数构建 Decimal 对象。

## 契约

功能：通过 32 位或 64 位（具体长度与平台相关）无符号整数构建 Decimal 对象。默认采用精度值为 0，即无限精度进行构建。

参数：

- val: UIntNative - 32 位或 64 位无符号整数。
