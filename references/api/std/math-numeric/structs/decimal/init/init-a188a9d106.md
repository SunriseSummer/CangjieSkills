# Decimal.init(BigInt)

[← Decimal.init](index.md)

## 签名

```cangjie role=signature
public init(val: BigInt)
```

通过有符号大整数 BigInt 构建 `Decimal` 结构体。

## 契约

功能：通过有符号大整数 BigInt 构建 `Decimal` 结构体。默认采用精度值为 0，即无限精度进行构建。

参数：

- val: BigInt - 有符号大整数值。
