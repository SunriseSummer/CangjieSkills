# Decimal.init(BigInt, Int32)

[← Decimal.init](index.md)

## 签名

```cangjie role=signature
public init(val: BigInt, scale: Int32)
```

通过有符号大整数 BigInt 和标度值构建 `Decimal` 结构体。

## 契约

功能：通过有符号大整数 BigInt 和标度值构建 `Decimal` 结构体。默认采用精度值为 0，即无限精度进行构建。

参数：

- val: BigInt - 有符号大整数值。
- scale: Int32 - 标度值。
