# Decimal.scaleUnit

[← Decimal](index.md)

## 签名

```cangjie role=signature
public func scaleUnit(): Decimal
```

对当前 Decimal 对象返回标度单位，即数值为 1 ，标度值与当前对象相等的 Decimal 对象。

## 契约

返回值：

- Decimal - 标度单位 Decimal 对象。
