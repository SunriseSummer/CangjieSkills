# GlobalFunctionInfo.==

[← GlobalFunctionInfo](index.md)

## 签名

```cangjie role=signature
public operator func ==(that: GlobalFunctionInfo): Bool
```

判断该全局函数信息与给定的另一个全局函数信息是否相等。

## 契约

参数：

- that: GlobalFunctionInfo - 被比较相等性的另一个全局函数信息。

返回值：

- Bool - 如果该全局函数信息与 `that` 相等则返回 `true`，否则返回 `false`。
