# ClassTypeInfo.isAbstract

[← ClassTypeInfo](index.md)

## 签名

```cangjie role=signature
public func isAbstract(): Bool
```

判断该 ClassTypeInfo 对应的 `class` 类型是否是抽象类。

## 契约

返回值：

- Bool - 如果该 ClassTypeInfo 对应的 `class` 类型是抽象类则返回 `true`，否则返回 `false`。
