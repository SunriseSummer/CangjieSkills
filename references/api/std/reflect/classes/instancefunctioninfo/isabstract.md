# InstanceFunctionInfo.isAbstract

[← InstanceFunctionInfo](index.md)

## 签名

```cangjie role=signature
public func isAbstract(): Bool
```

判断 InstanceFunctionInfo 所对应的实例成员函数是否拥有 `abstract` 语义。

## 契约

返回值：

- Bool - 如果该实例成员函数拥有 `abstract` 语义则返回 `true`，否则返回 `false`。
