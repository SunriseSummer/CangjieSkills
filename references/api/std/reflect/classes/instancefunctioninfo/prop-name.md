# InstanceFunctionInfo.name

[← InstanceFunctionInfo](index.md)

## 签名

```cangjie role=signature
public prop name: String
```

获取该 InstanceFunctionInfo 对应的实例成员函数的名称。

## 契约

> **注意：**
>
> - 构成重载的所有实例成员函数将拥有相同的名称。
> - 操作符重载函数的名称就是该操作符本身的符号内容，如"`+`"，"`*`"，"`[]`"。

类型：String
