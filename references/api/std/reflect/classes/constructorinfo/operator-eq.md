# ConstructorInfo.==

[← ConstructorInfo](index.md)

## 签名

```cangjie role=signature
public operator func ==(that: ConstructorInfo): Bool
```

判断该构造器信息与给定的另一个构造器信息是否相等。

## 契约

参数：

- that: ConstructorInfo - 被比较相等性的另一个构造器信息。

返回值：

- Bool - 如果该构造器信息与 `that` 相等则返回 `true`，否则返回 `false`。
