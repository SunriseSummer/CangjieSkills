# EnumConstructorInfo.==

[← EnumConstructorInfo](index.md)

## 签名

```cangjie role=signature
public operator func ==(other: EnumConstructorInfo): Bool
```

判断该构造子信息与另一个构造子信息是否相等。

## 注意
>
不支持平台：macOS、iOS、OpenHarmony、HarmonyOS。

## 参数

- other: EnumConstructorInfo - 另一个构造子信息。

## 返回值

- Bool - 相等返回 `true`，否则返回 `false`。
