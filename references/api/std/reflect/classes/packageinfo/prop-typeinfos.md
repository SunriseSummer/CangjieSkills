# PackageInfo.typeInfos

[← PackageInfo](index.md)

## 签名

```cangjie role=signature
public prop typeInfos: Collection<TypeInfo>
```

获取该 PackageInfo 对应的包中所有全局定义的 `public` 类型的类型信息，返回对应集合。
