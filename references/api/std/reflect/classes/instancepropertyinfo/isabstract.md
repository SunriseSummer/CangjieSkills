# InstancePropertyInfo.isAbstract

[← InstancePropertyInfo](index.md)

## 签名

```cangjie role=signature
public func isAbstract(): Bool
```

判断该 InstancePropertyInfo 对应的实例成员属性是否是抽象的。

## 契约

返回值：

- Bool - 如果该 InstancePropertyInfo 对应的实例成员属性是抽象的，则返回 `true`，否则返回 `false`。
