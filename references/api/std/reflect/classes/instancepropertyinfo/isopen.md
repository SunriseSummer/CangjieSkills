# InstancePropertyInfo.isOpen

[← InstancePropertyInfo](index.md)

## 签名

```cangjie role=signature
public func isOpen(): Bool
```

判断该 InstancePropertyInfo 对应的实例成员属性是否拥有 `open` 语义。

## 契约

返回值：

- Bool - 如果该 InstancePropertyInfo 对应的实例成员属性拥有 `open` 语义则返回 `true`，否则返回 `false`。
