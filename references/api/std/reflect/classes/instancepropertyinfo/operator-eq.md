# InstancePropertyInfo.==

[← InstancePropertyInfo](index.md)

## 签名

```cangjie role=signature
public operator func ==(that: InstancePropertyInfo): Bool
```

判断该实例成员属性信息与给定的另一个实例成员属性信息是否相等。

## 契约

参数：

- that: InstancePropertyInfo - 被比较相等性的另一个实例成员属性信息。

返回值：

- Bool - 如果该实例成员属性信息与 `that` 相等则返回 `true`，否则返回 `false`。
