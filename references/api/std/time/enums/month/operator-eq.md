# Month.==

[← Month](index.md)

## 签名

```cangjie role=signature
public operator func ==(r: Month): Bool
```

判断当前 Month 实例和 `r` 是否表示同一个月。

## 契约

参数：

- r: Month - Month 实例。

返回值：

- Bool - `true` 或 `false`。当前 Month 实例等于 `r` 时，返回 `true`；否则，返回 `false`。
