# Month.!=

[← Month](index.md)

## 签名

```cangjie role=signature
public operator func !=(r: Month): Bool
```

判断当前 Month 实例和 `r` 是否不为同一个月。

## 契约

参数：

- r: Month - Month 实例。

返回值：

- Bool - 当前 Month 实例是否不等于 `r`。
