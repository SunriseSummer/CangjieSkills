# DayOfWeek.toInteger

[← DayOfWeek](index.md)

## 签名

```cangjie role=signature
public func toInteger(): Int64
```

获取当前 DayOfWeek 实例的整数表示，周日表示为 0，周一至周六表示为 1 至 6。

## 契约

返回值：

- Int64 - 当前 DayOfWeek 实例的整数表示。
