# DateTimeFormat

[← std.time](../../index.md)

`DateTimeFormat`

提供时间格式的功能，用于解析和生成 DateTime 。

## 属性与字段

| 签名 | 功能 |
|---|---|
| [`RFC1123: String = "www, dd MMM yyyy HH:mm:ss z"`](field-rfc1123.md) | 提供 RFC1123 时间格式，时间字符串格式为 `www, dd MMM yyyy HH:mm:ss z`。 |
| [`RFC3339: String = "yyyy-MM-ddTHH:mm:ssOOOO"`](field-rfc3339.md) | 提供 RFC3339 时间格式，时间字符串格式为 `yyyy-MM-ddTHH:mm:ssOOOO`。 |
| [`RFC822: String = "ww dd MMM yy HH:mm:ss z"`](field-rfc822.md) | 提供 RFC822 时间格式，时间字符串格式为 `ww dd MMM yy HH:mm:ss z`。 |
| [`RFC850: String = "wwww, dd-MMM-yy HH:mm:ss z"`](field-rfc850.md) | 提供 RFC850 时间格式，时间字符串格式为 `wwww, ww-MMM-yy HH:mm:ss z`。 |
