# std.unittest.mock.mockmacro

[← std 包索引](../index.md)

mock 框架提供了用户所需的宏。

包路径：`std.unittest.mock.mockmacro`。在代码中只导入实际使用的类型或函数。

## 宏

| 声明 | 功能 |
|---|---|
| [`@Called`](macros/called.md) | 创建一个验证语句。 |
| [`@On`](macros/on.md) | 使用配置 API定义 mock/spy 对象成员的行为（或重新定义 spy 对象）。 |
