# OptionInfo

[← std.unittest.common](../../index.md)

`OptionInfo`

打印帮助页面时可以使用的选项的信息。

## 属性与字段

| 签名 | 功能 |
|---|---|
| [`description: ?String`](field-description.md) | 选项描述信息。 |
| [`name: String`](field-name.md) | 选项名称。 |
| [`types!: HashMap<String, ?String> = HashMap()`](field-types.md) | 从选项类型名称映射到值的含义。 |
| [`userDefined: Bool`](field-userdefined.md) | 选项是否已被定义。 |
