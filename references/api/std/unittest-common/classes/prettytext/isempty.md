# PrettyText.isEmpty

[← PrettyText](index.md)

## 签名

```cangjie role=signature
public func isEmpty(): Bool
```

返回当前构造器是否为空，即未有值传入给构造器。

## 契约

返回值：

- Bool - 未有内容传入时返回 `true` ，否则返回 `false` 。
