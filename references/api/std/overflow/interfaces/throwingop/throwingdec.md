## func throwingDec()

### 签名

```cangjie role=signature
func throwingDec(): T
```

使用抛出异常策略的自减运算。

### 契约

当运算出现溢出时，抛出异常，否则返回运算结果。

返回值：

- T - 自减运算结果。

异常：

- OverflowException - 当自减运算出现溢出时，抛出异常。
