## func throwingNeg()

### 签名

```cangjie role=signature
func throwingNeg(): T
```

使用抛出异常策略的负号运算。

### 契约

当运算出现溢出时，抛出异常，否则返回运算结果。

返回值：

- T - 负号运算结果。

异常：

- OverflowException - 当负号运算出现溢出时，抛出异常。
