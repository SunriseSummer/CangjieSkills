# DiagReportLevel

[← std.ast](../../index.md)

`DiagReportLevel`

表示报错接口的信息等级，支持 `ERROR` 和 `WARNING` 两种等级。

## 枚举值

| 签名 | 功能 |
|---|---|
| [`ERROR`](value-error.md) | 构造一个表示 ERROR 的枚举实例。 |
| [`WARNING`](value-warning.md) | 构造一个表示 WARNING 的枚举实例。 |

## 方法

| 签名 | 功能 |
|---|---|
| [`level(): Int32`](level.md) | 返回枚举值对应的整型。 |
