# Tokens.remove

[← Tokens](index.md)

## 签名

```cangjie role=signature
public func remove(index: Int64): Tokens
```

## 契约

- index: Int64 - 被删除的 Token 的索引。

返回值：

- Tokens - 删除指定位置的 Token 后的 Tokens 对象。
