[← Tokens](index.md)

## 签名

```cangjie role=signature
public func concat(tokens: Tokens): Tokens
```

将当前的 Tokens 与传入的 Tokens 进行拼接。

## 契约

参数：

- tokens: Tokens - 待拼接的 Tokens 对象。

返回值：

- Tokens - 拼接后的 Tokens。
