# MacroMessage.hasItem

[← MacroMessage](index.md)

## 签名

```cangjie role=signature
public func hasItem(key: String): Bool
```

检查是否有 key 值对应的相关信息。

## 契约

参数：

- key: String - 用于检索的关键字名字。

返回值：

- Bool - 若存在 key 值对应的相关信息，返回 true；反之，返回 false。
