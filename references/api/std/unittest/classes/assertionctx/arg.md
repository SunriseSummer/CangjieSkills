# AssertionCtx.arg

[← AssertionCtx](index.md)

## 签名

```cangjie role=signature
public func arg(key: String): String
```

返回表示原始传递的标识符的参数值的字符串表达，与参数列表中的标识符匹配。

## 契约

参数：

- key: String - 函数参数列表中的标识符。

返回值：

- String - 对应标识符的参数值字符串表达。
