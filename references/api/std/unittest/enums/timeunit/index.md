# TimeUnit

[← std.unittest](../../index.md)

`TimeUnit <: ToString`

可以在 TimeNow 构造函数中使用的时间单位。

## 枚举值

| 签名 | 功能 |
|---|---|
| [`Micros`](value-micros.md) | 单位为微秒。 |
| [`Millis`](value-millis.md) | 单位为毫秒。 |
| [`Nanos`](value-nanos.md) | 单位为纳秒。 |
| [`Seconds`](value-seconds.md) | 单位为秒。 |

## 方法

| 签名 | 功能 |
|---|---|
| [`toString(): String`](tostring.md) | 将时间转换为字符串。 |
