# ArrayList<T>.none

[← ArrayList<T>](index.md)

## 签名

```cangjie role=signature
public func none(predicate: (T) -> Bool): Bool
```

判断 ArrayList 中所有元素是否都不满足条件。

## 注意
>
不支持平台：OpenHarmony。

## 参数

- predicate: (T) -> Bool - 给定的条件。

## 返回值

- Bool - 当前 ArrayList 中元素是否都不满足条件。
