# ArrayList<T>.intersperse

[← ArrayList<T>](index.md)

## 签名

```cangjie role=signature
public func intersperse(separator: T): ArrayList<T>
```

返回每两个元素之间插入一个给定的新元素后的新 ArrayList 。

## 注意
>
不支持平台：OpenHarmony。

## 参数

- separator: T - 给定的元素。

## 返回值

- ArrayList<T> - 返回一个新 ArrayList。
