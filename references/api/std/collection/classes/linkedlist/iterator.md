# LinkedList<T>.iterator

[← LinkedList<T>](index.md)

## 签名

```cangjie role=signature
public func iterator(): Iterator<T>
```

返回当前集合中元素的迭代器，其顺序是从链表的第一个节点到链表的最后一个节点。

## 契约

返回值：

- Iterator\<T> - 当前集合中元素的迭代器。
