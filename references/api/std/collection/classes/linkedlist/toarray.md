# LinkedList<T>.toArray

[← LinkedList<T>](index.md)

## 签名

```cangjie role=signature
public func toArray(): Array<T>
```

返回一个数组，数组包含该链表中的所有元素，并且顺序与链表的顺序相同。

## 契约

返回值：

- Array\<T> - T 类型数组。
