# LinkedList<T>.addLast

[← LinkedList<T>](index.md)

## 签名

```cangjie role=signature
public func addLast(element: T): LinkedListNode<T>
```

在链表的尾部位置添加一个元素，并且返回该元素的节点。

## 契约

参数：

- element: T - 要添加到链表中的元素。

返回值：

- LinkedListNode\<T> - 指向该元素的节点。
