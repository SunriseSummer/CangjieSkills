# extend<T> LinkedList<T> <: ToString where T <: ToString

[← LinkedList<T>](../index.md)

`extend<T> LinkedList<T> <: ToString where T <: ToString`

## 成员

| 签名 | 功能 |
|---|---|
| [`toString(): String`](../tostring.md) | 将当前 LinkedList<T> 实例转换为字符串。 |
