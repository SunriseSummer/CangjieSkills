# HashSet<T>.filter

[← HashSet<T>](index.md)

## 签名

```cangjie role=signature
public func filter(predicate: (T) -> Bool): HashSet<T>
```

返回一个满足筛选条件的元素的新 HashSet<T>。

## 注意
>
不支持平台：OpenHarmony。

## 参数

- predicate: (T) -> Bool - 给定的条件。

## 返回值

- HashSet<T> - 返回一个满足筛选条件的元素的新 HashSet。
