# TreeSet<T>.any

[← TreeSet<T>](index.md)

## 签名

```cangjie role=signature
public func any(predicate: (T) -> Bool): Bool
```

判断 TreeSet 是否存在任意一个满足条件的元素。

## 注意
>
不支持平台：OpenHarmony。

## 参数

- predicate: (T) -> Bool - 给定的条件。

## 返回值

- Bool - 是否存在任意满足条件的元素。
