# LinkedListNode<T>

[← std.collection](../../index.md)

`LinkedListNode<T>`

LinkedListNode 是 LinkedList 上的节点。

## 属性与字段

| 签名 | 功能 |
|---|---|
| [`next: Option<LinkedListNode<T>>`](prop-next.md) | 获取当前节点的下一个节点，如果没有则返回 None。 |
| [`prev: Option<LinkedListNode<T>>`](prop-prev.md) | 获取当前节点的前一个节点，如果没有则返回 None。 |
| [`mut value: T`](prop-value.md) | 获取或者修改元素的值。 |
