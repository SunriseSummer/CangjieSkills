# Deque<T>.last

[← Deque<T>](index.md)

## 签名

```cangjie role=signature
prop last: ?T
```

访问双端队列尾部元素，该操作不会删除尾部元素。

## 契约

功能：访问双端队列尾部元素，该操作不会删除尾部元素。如果双端队列为空，返回 None。
