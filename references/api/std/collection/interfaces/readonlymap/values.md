# ReadOnlyMap<K, V>.values

[← ReadOnlyMap<K, V>](index.md)

## 签名

```cangjie role=signature
func values(): Collection<V>
```

返回 ReadOnlyMap 中所有的 value，并将所有 value 存储在一个 Collection<V> 容器中。

## 契约

返回值：

- Collection\<V> - 保存所有返回的 value。
