# Path.Separator

[← Path](index.md)

## 签名

```cangjie role=signature
public static const Separator: String = PATH_SEPARATOR
```

获取路径分隔符，用于分隔多级目录。

## 契约

Windows 系统中分隔符为 "\\"，非 Windows 系统中为 "/"。

类型：String
