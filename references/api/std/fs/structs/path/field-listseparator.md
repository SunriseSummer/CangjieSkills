# Path.ListSeparator

[← Path](index.md)

## 签名

```cangjie role=signature
public static const ListSeparator: String = PATH_LISTSEPARATOR
```

获取路径列表分隔符，用于分隔路径列表中的不同路径。

## 契约

Windows 系统中路径列表分隔符为 ";"，非 Windows 系统中为 ":"。

类型：String
