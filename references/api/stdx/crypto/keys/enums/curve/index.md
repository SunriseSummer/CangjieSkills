# Curve

[← stdx.crypto.keys](../../index.md)

`Curve`

## 枚举值

| 签名 | 功能 |
|---|---|
| [`BP256`](value-bp256.md) | 使用 Brainpool P-256 椭圆曲线初始化 Curve 实例。 |
| [`BP320`](value-bp320.md) | 使用 Brainpool P-320 椭圆曲线初始化 Curve 实例。 |
| [`BP384`](value-bp384.md) | 使用 Brainpool P-384 椭圆曲线初始化 Curve 实例。 |
| [`BP512`](value-bp512.md) | 使用 Brainpool P-512 椭圆曲线初始化 Curve 实例。 |
| [`P224`](value-p224.md) | 使用 NIST P-224 椭圆曲线初始化 Curve 实例。 |
| [`P256`](value-p256.md) | 使用 NIST P-256 椭圆曲线初始化 Curve 实例。 |
| [`P384`](value-p384.md) | 使用 NIST P-384 椭圆曲线初始化 Curve 实例。 |
| [`P521`](value-p521.md) | 使用 NIST P-521 椭圆曲线初始化 Curve 实例。 |
