# stdx.crypto.kit

[← stdx 包索引](../../index.md)

提供 `CryptoKit` 默认实现，包括安全随机数生成及 DER、PEM 解码能力。

包路径：`stdx.crypto.kit`。在代码中只导入实际使用的类型或函数。

## 类

| 声明 | 功能 |
|---|---|
| [`DefaultCryptoKit`](classes/defaultcryptokit/index.md) | CryptoKit 的默认实现。提供随机数生成器及解码 DER、PEM 的能力。 |
