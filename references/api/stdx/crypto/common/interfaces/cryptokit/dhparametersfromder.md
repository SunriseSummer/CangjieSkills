# CryptoKit.dhParametersFromDer

[← CryptoKit](index.md)

## 签名

```cangjie role=signature
func dhParametersFromDer(encoded: DerBlob): DHParameters
```

将 DH 密钥参数从 DER 格式解码。

## 参数

- encoded: DerBlob - 待解码的 DerBlob 对象。

## 返回值

- DHParameters - 解码得到的 DH 密钥参数。
