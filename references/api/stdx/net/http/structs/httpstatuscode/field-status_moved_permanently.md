# HttpStatusCode.STATUS_MOVED_PERMANENTLY

[← HttpStatusCode](index.md)

## 签名

```cangjie role=signature
public static const STATUS_MOVED_PERMANENTLY: UInt16 = 301
```

永久移动。

## 契约

类型：UInt16

> **说明：**
>
> 请求的资源已被永久的移动到新 URI，返回信息会包括新的 URI，浏览器会自动定向到新 URI。
