# HttpStatusCode.STATUS_TEAPOT

[← HttpStatusCode](index.md)

## 签名

```cangjie role=signature
public static const STATUS_TEAPOT: UInt16 = 418
```

服务端无法处理请求，一个愚弄客户端的状态码，被称为“我是茶壶”错误码，不应被认真对待。
