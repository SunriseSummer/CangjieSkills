# HttpStatusCode.STATUS_UNSUPPORTED_MEDIA_TYPE

[← HttpStatusCode](index.md)

## 签名

```cangjie role=signature
public static const STATUS_UNSUPPORTED_MEDIA_TYPE: UInt16 = 415
```

服务器无法处理请求附带的媒体格式。

## 契约

类型：UInt16

> **说明：**
>
> 对于当前请求的函数和所请求的资源，请求中提交的实体并不是服务器中所支持的格式。
