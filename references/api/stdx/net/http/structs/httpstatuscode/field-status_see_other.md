# HttpStatusCode.STATUS_SEE_OTHER

[← HttpStatusCode](index.md)

```cangjie role=signature
public static const STATUS_SEE_OTHER: UInt16 = 303
```

对应当前请求的响应可以在另一个 URL 上被找到，而且客户端应当采用 GET 的方式访问那个资源。
