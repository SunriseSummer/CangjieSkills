# Client.initialWindowSize

[← Client](index.md)

## 签名

```cangjie role=signature
public prop initialWindowSize: UInt32
```

获取客户端 HTTP/2 流控窗口初始值，默认值为 65535 ，取值范围为 0 至 2^31 - 1。

## 契约

类型：UInt32
