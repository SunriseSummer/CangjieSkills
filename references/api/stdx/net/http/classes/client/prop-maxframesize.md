# Client.maxFrameSize

[← Client](index.md)

## 签名

```cangjie role=signature
public prop maxFrameSize: UInt32
```

获取客户端 HTTP/2 初始最大帧大小。

## 契约

功能：获取客户端 HTTP/2 初始最大帧大小。默认值为 16384. 取值范围为 2^14 至 2^24 - 1。

类型：UInt32
