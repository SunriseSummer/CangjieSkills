# HttpResponse.status

[← HttpResponse](index.md)

## 签名

```cangjie role=signature
public prop status: UInt16
```

获取响应的状态码，默认值为 200。

## 契约

功能：获取响应的状态码，默认值为 200。状态码由 100~599 的三位数字组成，状态码所反映的具体信息可参考 RFC 9110。

类型：UInt16
