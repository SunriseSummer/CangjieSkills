# URL.decodeComponent

[← URL](index.md)

## 签名

```cangjie role=signature
static func decodeComponent(component: String): String
```

对经过 `URL` 编码（也就是 `%` 编码）的字符串进行解码操作，将编码后的字符串还原成原始的字符串。

## 参数

- component: String - 待解码的字符串。

## 返回值

- String - 解码后的字符串。
