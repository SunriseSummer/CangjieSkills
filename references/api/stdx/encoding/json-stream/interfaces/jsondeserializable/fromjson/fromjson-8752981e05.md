# JsonDeserializable<T>.static func fromJson(JsonReader)

[← JsonDeserializable<T>.fromJson](index.md)

## 签名

```cangjie role=signature
static func fromJson(r: JsonReader): T
```

从参数 `r` 指定的 JsonReader 实例中读取一个 `T` 类型对象。

## 契约

参数：

- r: JsonReader - 读取反序列化结果的 JsonReader 实例。

返回值：

- T - `T` 类型的实例。

异常：

- IllegalStateException - 如果输入流的 JSON 数据不符合格式，抛出异常。
