# JsonToken.Name

[← JsonToken](index.md)

## 签名

```cangjie role=signature
Name
```

表示 object 中的 name。

## 契约

功能：表示 object 中的 name。如果 JsonReader.peek() 返回的是该类型，可以使用 JsonReader.readName() 读取。
