# JsonString.toJsonStringWithoutEscaping

[← JsonString](index.md)

## 签名

```cangjie role=signature
public func toJsonStringWithoutEscaping(): String
```

将 JsonString 转换为 JSON 格式的 (带有空格换行符) 字符串，不对 html 特殊字符 `&` 转义。

## 返回值

- String - 转换后的 JSON 格式字符串。
