# JsonException

[← stdx.encoding.json](../../index.md)

`JsonException <: Exception`

JSON 包的异常类，用于 JsonValue 类型使用时出现异常的场景。

## 构造函数

| 签名 | 功能 |
|---|---|
| [`init()`](init.md) | 构造一个不包含任何异常提示信息的 JsonException 实例。 |
| [`init(message: String)`](init.md) | 根据指定的异常提示信息构造 JsonException 实例。 |
