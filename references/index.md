# 仓颉 1.0.5 知识库

从最窄入口开始。每个父页都可作为速查终点；只有当前信息不足时才进入下一层。

| 入口 | 何时使用 | 下一层提供什么 |
|---|---|---|
| [语言特性](language/index.md) | 查询语法、静态/运行时语义、合法组合与常见诊断。 | 特性族 → 规则表 → 单规则叶子。 |
| [API 参考](api/index.md) | 查询 std/stdx 包、类型、接口、函数、宏、属性与重载。 | 库 → 包 → 类型成员表 → 成员契约。 |
| [应用示例](examples/index.md) | 需要典型场景、完整工程、资源管理或端到端最优实践。 | 场景分类 → 示例列表 → 完整可运行示例。 |
| [工具链](tools/index.md) | 使用编译、项目、编辑器、检查、调试、覆盖率、性能和产物诊断工具。 | 工具 → 命令/配置表 → 单命令或配置叶子。 |

## 阅读停止规则

- 索引表已经给出足够的名称和范围：停止。
- 类型/主题页的签名或规则表已经消除歧义：停止。
- 需要参数、返回值、异常、边界条件或代码：只打开对应叶子。
- 查询无结果：缩短或限域查询，再从最窄相关索引选择叶子；仍有缺口时用当前工具链构造最小实验并明确记录。
