# 流式计算 SHA-256

[← 数据摘要](index.md)

用 stdx SHA256 分段 write、finish，并在复用前 reset。

## 典型示例

摘要对象可分段 `write`，`finish` 返回固定长度字节；十六进制编码便于记录和比对摘要值。

```cangjie cjtest=run id=examples.digests.sha256.api.stdx.sha256.run form=unit requires=stdx timeout=60s
package stdx_sha256_example

import stdx.crypto.digest.*
import stdx.encoding.hex.*

main(): Unit {
    let hasher = SHA256()
    hasher.write("abc".toArray())
    println(toHexString(hasher.finish()))
}
```
