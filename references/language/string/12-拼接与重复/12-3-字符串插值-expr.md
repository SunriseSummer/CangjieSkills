# 12.3 字符串插值 `"${expr}"`

[← 12. 拼接与重复](index.md)

`let name = "Cangjie"`：字符串插值 "${expr}"。

```cangjie cjtest=syntax id=syntax-d1a1153f43-1 form=stmt
let name = "Cangjie"
let age = 3
let s = "Name: ${name}, Age: ${age}" // "Name: Cangjie, Age: 3"
```
