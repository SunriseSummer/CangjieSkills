# 14.1 按字节索引

[← 14. 下标访问与切片](index.md)

```cangjie cjtest=syntax id=syntax-24bad700fb-1 form=stmt
let s = "Hello"
let b: Byte = s[0]         // 72 (H 的 UTF-8 编码)
let opt = s.get(10)         // None（安全访问，不抛异常）
```

> **注意**：`s[i]` 返回的是 `Byte`（UTF-8 编码字节），对于多字节字符（如中文），单个索引不能获取完整字符。
