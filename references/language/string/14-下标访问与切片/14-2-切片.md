# 14.2 切片

[← 14. 下标访问与切片](index.md)

```cangjie cjtest=syntax id=syntax-4e2d30c462-1 form=stmt
let s = "Hello World"
let sub = s[0..5]   // "Hello"
let sub2 = s[6..11] // "World"
```

> **注意**：切片范围基于字节索引，确保不要在多字节字符中间切断。
