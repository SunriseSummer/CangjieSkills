# 13.1 转为字节数组

[← 13. 转换](index.md)

`func toArray(): Array<Byte>      // 返回 UTF-8 字节数组（拷贝）`：转为字节数组。

```cangjie cjtest=syntax id=syntax-4fecc6ba0c-1 form=unit
func toArray(): Array<Byte>      // 返回 UTF-8 字节数组（拷贝）
func rawData(): Array<Byte>      // 返回内部原始数据引用（unsafe）
```

```cangjie cjtest=syntax id=syntax-4fecc6ba0c-2 form=stmt
let bytes = "Hi".toArray()   // [72, 105]
```
