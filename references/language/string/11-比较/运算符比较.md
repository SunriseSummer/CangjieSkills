# 运算符比较

[← 11. 比较](index.md)

`"abc" == "abc"  // true`：运算符比较。

```cangjie cjtest=syntax id=syntax-a3f31f649c-1 form=stmt
"abc" == "abc"  // true
"abc" != "def"  // true
"abc" < "abd"   // true（字典序）
"abc" <= "abc"  // true
"abd" > "abc"   // true
"abd" >= "abc"  // true
```
