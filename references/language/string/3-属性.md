# 3. 属性

[← String](index.md)

`let s = "Hello"`：属性。

| 属性 | 类型 | 说明 |
|------|------|------|
| `size` | `Int64` | UTF-8 编码字节长度（**不是字符数**） |

```cangjie cjtest=syntax id=syntax-16db245e46-1 form=stmt
let s = "Hello"
println(s.size)     // 5

let s2 = "你好"
println(s2.size)    // 6（每个汉字 3 字节 UTF-8）
```
