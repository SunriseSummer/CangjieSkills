# 2. 构造

[← String](index.md)

`let s1 = ""`：构造。

```cangjie cjtest=syntax id=syntax-0f9148dda7-1 form=stmt
// 空字符串
let s1 = ""
let s2 = String()
let s3 = String.empty           // 静态常量

// 字符串字面量
let s4 = "Hello, 仓颉!"

// 多行字符串（三引号）
let s5 = """
    第一行
    第二行
    """

// 从 Rune 数组构造
let runes: Array<Rune> = [r'H', r'i']
let s6 = String(runes)          // "Hi"

// 从 Rune 集合构造
let s7 = String(runes)              // 与 Rune 数组构造相同

// 从 UTF-8 字节数组构造
let bytes: Array<UInt8> = [72, 101, 108, 108, 111]
let s8 = String.fromUtf8(bytes) // "Hello"（会校验 UTF-8 合法性）
```
