# 4.1 元组解构

[← 4. 迭代进阶](index.md)

元素类型为元组时可在 `for-in` 变量处直接解构；`HashMap<K, V>` 迭代元素是 `(K, V)`，典型写法为 `for ((key, value) in map)`，且顺序不稳定。

- 对元素为元组的集合，可直接解构：
```cangjie cjtest=syntax id=syntax-8c23ded023-1 form=stmt
let points = [(1, 2), (3, 4), (5, 6)]
for ((x, y) in points) {
    println("x=${x}, y=${y}")
}
```
- HashMap 迭代天然使用元组解构：
```cangjie cjtest=syntax id=syntax-8c23ded023-2 form=unit
import std.collection.*

main() {
    let map = HashMap<String, Int64>([("a", 1), ("b", 2)])
    for ((key, value) in map) {
        println("${key}: ${value}")
    }
}
```
