# 1.3 迭代变量规则

[← 1. for-in 基本语法](index.md)

- 迭代变量 `item` **不可变**（`let` 绑定），不能在循环体中重新赋值
- 若循环体中不使用迭代变量，可用通配符 `_` 占位避免警告：
  ```cangjie cjtest=syntax id=syntax-0a40ac0787-1 form=stmt
  for (_ in 0..3) {
      println("hello")
  }
  ```
