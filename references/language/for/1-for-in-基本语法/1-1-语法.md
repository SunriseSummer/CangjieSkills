# 1.1 语法

[← 1. for-in 基本语法](index.md)

```cangjie cjtest=syntax id=syntax-8563ca3db6-1 form=stmt
for (item in [1, 2, 3]) {
    println(item)
}
```
- 迭代对象须实现 `Iterable<T>` 接口
- `sequence` 表达式**仅在首次迭代前求值一次**
- 循环表达式类型为 `Unit`，值为 `()`
