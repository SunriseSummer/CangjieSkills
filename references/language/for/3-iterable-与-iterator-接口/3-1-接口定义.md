# 3.1 接口定义

[← 3. Iterable 与 Iterator 接口](index.md)

实现 `Iterable<T>.iterator()` 即可用于 `for-in`；返回的 `Iterator<T>` 通过 `next()` 逐项产生 `Some`，结束时返回 `None`。

```cangjie cjtest=syntax id=syntax-607f06cae6-1 form=unit
interface Iterable<T> {
    func iterator(): Iterator<T>
}

interface Iterator<T> <: Iterable<T> {
    mut func next(): Option<T>
}
```
- `Iterator` 自身扩展 `Iterable`，可直接用于 for-in
- `next()` 返回 `Some(value)` 表示有元素，`None` 表示迭代结束
- 接口中的 `mut func next()` 允许值类型实现修改自身；`class` 实现可用普通 `func next()` 修改实例字段，`struct` 实现若改写字段则必须保留 `mut`

## 已验证示例

自定义容器实现 `Iterable<T>.iterator()`，迭代器实现 `Iterator<T>.next()`；`for-in` 会持续取值直至返回 `None`。

```cangjie cjtest=run id=language.custom-iterable.run form=unit timeout=20s
package custom_iterable_example

class CountdownIterator <: Iterator<Int64> {
    var current: Int64

    public init(start: Int64) {
        current = start
    }

    public func next(): ?Int64 {
        if (current <= 0) {
            return None
        }
        let value = current
        current -= 1
        return Some(value)
    }
}

class Countdown <: Iterable<Int64> {
    let start: Int64

    public init(start: Int64) {
        this.start = start
    }

    public func iterator(): Iterator<Int64> {
        return CountdownIterator(start)
    }
}

main(): Unit {
    for (value in Countdown(3)) {
        println(value)
    }
}
```

```text cjtest=expect for=language.custom-iterable.run stream=stdout match=exact
3
2
1
```
