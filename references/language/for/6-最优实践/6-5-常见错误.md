# 6.5 常见错误

[← 6. 最优实践](index.md)

避免在循环体中误用不可变循环变量、越界区间或不能产生迭代器的对象；根据诊断修正迭代源而不是强制转换。

```cangjie cjtest=syntax id=syntax-1de40b34ef-1 form=stmt
// ❌ 错误：试图修改迭代变量
for (i in 0..5) {
    // i = i + 1  // 编译错误，迭代变量不可变
}

// ❌ 错误：step 为 0
// for (i in 0..10 : 0) { }  // 运行时错误

// ❌ 错误：半开区间边界混淆
for (i in 0..5) { print(i) }   // 01234，不包含 5
for (i in 0..=5) { print(i) }  // 012345，包含 5
```
