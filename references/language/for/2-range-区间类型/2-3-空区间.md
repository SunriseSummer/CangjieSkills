# 2.3 空区间

[← 2. Range 区间类型](index.md)

- `step > 0 && start >= end`（半开）或 `step > 0 && start > end`（闭）→ 空区间，循环体不执行
- `step < 0 && start <= end`（半开）或 `step < 0 && start < end`（闭）→ 空区间
