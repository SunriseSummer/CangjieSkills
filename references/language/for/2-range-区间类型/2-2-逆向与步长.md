# 2.2 逆向与步长

[← 2. Range 区间类型](index.md)

`Range` 可指定非单位步长；使用负步长时起点必须大于终点，才能产生逆序序列。

- 负步长实现逆序迭代：
```cangjie cjtest=syntax id=syntax-bed964ca2b-1 form=stmt
for (i in 5..0 : -1) { print(i) }  // 输出：54321
for (i in 10..0 : -3) { print(i) } // 输出：10741
```
