# 4.3 遮蔽与重载

[← 4. 包导入](index.md)

- 导入的名称被同名本地声明遮蔽（除非构成函数重载，此时适用重载解析）
```cangjie cjtest=syntax id=syntax-74567e0df1-1 form=unit
// package pkga
package pkga
public struct R {}
public func f(a: Int32) {}
public func f(a: Bool) {}
```
```cangjie cjtest=syntax id=syntax-74567e0df1-2 form=unit
// package pkgb
package pkgb
import pkga.*

struct R {}                 // 本地 R 遮蔽导入的 R
func f(a: Int32) {}         // 本地 f(Int32) 遮蔽导入的同签名函数

func bar() {
    R()     // 使用本地 R
    f(1)    // 调用本地 f(Int32)
    f(true) // 调用导入的 f(Bool)，构成重载
}
```
