# 2.4 组织名限定包

[← 2. 包声明](index.md)

仓颉 1.1.3 支持为模块配置组织名。`cjpm.toml` 中设置 `organization` 后，本模块的包声明以及其他模块对它的导入都必须带 `组织名::` 前缀；组织名必须是合法标识符，且不能是 `default`。

```toml cjtest=project id=language.package.organization-qualified file=cjpm.toml command=build timeout=60s
[package]
cjc-version = "1.1.3"
name = "ledger"
organization = "acme"
version = "1.0.0"
output-type = "static"
```

仓颉源码 `src/ledger.cj`：

```cangjie cjtest=file project=language.package.organization-qualified file=src/ledger.cj
package acme::ledger

public func encode(): Unit {}
```

子包声明可继续写作 `package acme::ledger.codec`，使用方则导入 `acme::ledger.codec.encode`。组织名属于模块身份，不是普通包名片段；构建产物的模块名和目录名会带 `@acme` 后缀。不要只改清单而保留无组织名的 `package ledger...`，也不要给 `std.*`、`stdx.*` 添加组织前缀。
