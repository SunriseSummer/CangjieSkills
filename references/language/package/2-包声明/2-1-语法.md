# 2.1 语法

[← 2. 包声明](index.md)

- 使用 `package pkg1.sub1` 声明，须与相对于 `src/` 的目录路径匹配
- 须为文件中第一个非空/非注释行
- 同一包中所有文件须有相同的包声明
- 目录名须与包名匹配
- `src/` 根目录的文件如果没有包声明，则默认为 `default` 包
- 子包不能与顶层声明同名
- Windows 上包名仅限 ASCII
