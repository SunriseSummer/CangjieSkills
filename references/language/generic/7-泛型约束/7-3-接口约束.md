# 7.3 接口约束

[← 7. 泛型约束](index.md)

`where T <: Interface1 & Interface2` 要求类型实参同时实现多个接口，并允许泛型实现调用这些接口公开的成员。

- 约束类型参数须实现某个接口：
```cangjie cjtest=syntax id=syntax-1950838926-1 form=unit
func genericPrint<T>(a: T) where T <: ToString {
    println(a)
}
```

## 已验证示例

多个接口约束以 `&` 组合，使泛型实现只能调用显式声明的能力；缺少任一能力的类型实参会在调用点被编译器拒绝。

```cangjie cjtest=run id=language.generic-constraint.run form=unit timeout=20s
package generic_constraint_example

interface Named {
    func name(): String
}

interface Scored {
    func score(): Int64
}

class Entry <: Named & Scored {
    public func name(): String { "Ada" }
    public func score(): Int64 { 95 }
}

func render<T>(value: T): String where T <: Named & Scored {
    return "${value.name()}:${value.score()}"
}

main(): Unit {
    println(render(Entry()))
}
```

```text cjtest=expect for=language.generic-constraint.run stream=stdout match=exact
Ada:95
```

`NameOnly` 缺少 `Scored` 能力，不能作为这里的类型实参：

```cangjie cjtest=compile id=language.generic-constraint.error form=unit exit=1 timeout=20s
package generic_constraint_error

interface Named {
    func name(): String
}

interface Scored {
    func score(): Int64
}

class NameOnly <: Named {
    public func name(): String { "Ada" }
}

func render<T>(value: T): String where T <: Named & Scored {
    return "${value.name()}:${value.score()}"
}

main(): Unit {
    render(NameOnly())
}
```

```text cjtest=expect for=language.generic-constraint.error stream=stderr match=contains
unable to infer generic argument of this function
```
