# 7. 泛型约束

[← 泛型](../index.md)

| 细粒度主题 | 摘要 |
|---|---|
| [7.1 目的](7-1-目的.md) | 约束指定类型参数须具备的操作/能力 |
| [7.2 语法](7-2-语法.md) | 使用 `where` 关键字，放在声明体之前 |
| [7.3 接口约束](7-3-接口约束.md) | `where T <: Interface1 & Interface2` 要求类型实参同时实现多个接口，并允许泛型实现调用这些接口公开的成员。 |
| [7.4 类约束](7-4-类约束.md) | 约束类型参数须为某个类的子类型。 |
| [7.5 规则](7-5-规则.md) | 泛型约束写在 `where` 子句中，约束目标只能是具体类或接口；多个接口约束使用 `&` 组合。 |
