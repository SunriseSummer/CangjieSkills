# 8.2 型变 — 用户自定义类型不变

[← 8. 泛型子类型关系](index.md)

| 型变 | 条件 |
|------|------|
| **不变** | `T(A) <: T(B)` ⟺ `A = B` |
| **协变** | `T(A) <: T(B)` ⟺ `A <: B` |
| **逆变** | `T(A) <: T(B)` ⟺ `B <: A` |

- 所有用户自定义泛型类型在所有类型参数上**不变**
