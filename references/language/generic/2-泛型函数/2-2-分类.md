# 2.2 分类

[← 2. 泛型函数](index.md)

### (a) 全局泛型函数
```cangjie cjtest=syntax id=syntax-8db7830248-1 form=unit
func id<T>(a: T): T { return a }
```

### (b) 局部泛型函数
- 泛型函数可嵌套在其他函数内定义

### (c) 泛型成员函数
- `class`、`struct`、`enum` 可有泛型成员函数
- 约束用 `where` 指定：
```cangjie cjtest=syntax id=syntax-8db7830248-2 form=unit
class A {
    func foo<T>(a: T): Unit where T <: ToString { println("${a}") }
}
```

### (d) 扩展中的泛型函数
- 扩展可为已有类型添加泛型成员函数

### (e) 静态泛型函数
- `interface`、`class`、`struct`、`enum`、`extend` 可定义静态泛型函数
