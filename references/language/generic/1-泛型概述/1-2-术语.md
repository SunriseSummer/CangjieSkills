# 1.2 术语

[← 1. 泛型概述](index.md)

速查`类型形参`：须在使用处指定的类型；`类型变元`：在体内引用类型形参的标识符；`类型实参`：使用泛型声明时提供的具体类型；另含更多表项。

| 术语 | 含义 |
|------|------|
| **类型形参** | 须在使用处指定的类型。使用标识符在体内引用 |
| **类型变元** | 在体内引用类型形参的标识符 |
| **类型实参** | 使用泛型声明时提供的具体类型 |
| **类型构造器** | 接受零个或多个类型作为参数以产生具体类型的类型 |
