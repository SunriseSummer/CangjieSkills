# 泛型

[← 语言特性](../index.md)

泛型函数和类型、where 约束、子类型关系与型变。

| 规则/任务 | 摘要 |
|---|---|
| [1. 泛型概述](1-泛型概述/index.md) | 泛型 = 参数化类型 — 声明时未知类型，使用时指定 |
| [2. 泛型函数](2-泛型函数/index.md) | 函数名后在 `<>` 中声明一个或多个类型参数 |
| [3. 泛型类](3-泛型类/index.md) | 泛型类的静态成员变量/属性在所有实例化之间共享内存 |
| [4. 泛型接口](4-泛型接口/index.md) | 泛型接口在接口名后声明类型参数，可继承其他接口；实现类型必须为参数选择具体类型并满足对应成员契约。 |
| [5. 泛型结构体](5-泛型结构体/index.md) | 泛型结构体用类型参数复用值类型实现；实例化时需显式给出或由构造参数推断实际类型。 |
| [6. 泛型枚举](6-泛型枚举/index.md) | 枚举构造函数可携带泛型类型的载荷 |
| [7. 泛型约束](7-泛型约束/index.md) | 在 `where` 子句中用类或接口限制类型参数；多个接口以 `&` 连接，泛型实现因而可以安全调用这些能力。 |
| [8. 泛型子类型关系](8-泛型子类型关系/index.md) | 若 `class C<Z> <: I<Z, Z>`，则 `C<Bool> <: I<Bool, Bool>`、`C<D> <: I<D, D>` 等 |
| [9. 完整特性矩阵](9-完整特性矩阵.md) | 速查`类型参数`：✅；`where` 约束：✅；`泛型成员函数`：—；另含更多表项。 |
