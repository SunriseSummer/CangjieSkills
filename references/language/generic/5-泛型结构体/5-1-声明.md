# 5.1 声明

[← 5. 泛型结构体](index.md)

泛型结构体在名称后声明类型参数，成员可使用这些参数描述字段和函数签名。

- 语法与泛型类相同：
```cangjie cjtest=syntax id=syntax-1c7ad722d5-1 form=unit
struct Pair<T, U> {
    let x: T
    let y: U
    public init(a: T, b: U) { x = a; y = b }
}
```
