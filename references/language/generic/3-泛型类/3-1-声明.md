# 3.1 声明

[← 3. 泛型类](index.md)

- 类可以有多个类型参数和约束：
```cangjie cjtest=syntax id=syntax-20687a8ccd-1 form=unit
open class Node<K, V> where K <: Hashable & Equatable<K> {
    var key: Option<K> = Option<K>.None
    var value: Option<V> = Option<V>.None
}
```
