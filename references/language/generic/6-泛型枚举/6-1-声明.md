# 6.1 声明

[← 6. 泛型枚举](index.md)

- 枚举构造函数可携带泛型类型的载荷
- 典型例子是 `Option<T>`：
```cangjie cjtest=syntax id=syntax-a588a17233-1 form=unit
public enum Option<T> {
      Some(T)
    | None
}
```
