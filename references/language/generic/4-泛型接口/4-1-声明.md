# 4.1 声明

[← 4. 泛型接口](index.md)

使用 `interface Name<T>` 声明泛型接口；父接口可引用同一类型参数，成员签名也可用它描述参数和返回值。

- 接口可声明类型参数用于成员函数签名：
```cangjie cjtest=syntax id=syntax-95557ffad9-1 form=unit
public interface Iterable<E> {
    func iterator(): Iterator<E>
}
```
- 泛型接口可继承其他泛型接口
