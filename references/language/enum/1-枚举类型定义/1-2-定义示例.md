# 1.2 定义示例

[← 1. 枚举类型定义](index.md)

枚举构造器写在 `enum` 体内，以 `|` 分隔；构造器既可无参数，也可携带不同类型的负载。

下面的完整程序同时演示无参构造器、有参构造器、递归定义和枚举成员函数：

```cangjie cjtest=run id=language.enum.definition.run form=unit timeout=30s
package enum_definition_example

enum Direction {
    | Up | Down | Left | Right
}

enum Expr {
    | Num(Int64)
    | Add(Expr, Expr)
}

enum TrafficLight {
    | Red | Yellow | Green

    public func label(): String {
        return match (this) {
            case Red => "stop"
            case Yellow => "wait"
            case Green => "go"
        }
    }
}

func evaluate(expr: Expr): Int64 {
    return match (expr) {
        case Num(value) => value
        case Add(left, right) => evaluate(left) + evaluate(right)
    }
}

main(): Unit {
    let direction = Direction.Left
    match (direction) {
        case Left => println("left")
        case _ => println("other")
    }

    let expression = Add(Num(2), Num(3))
    println(evaluate(expression))
    println(TrafficLight.Green.label())
}
```

```text cjtest=expect for=language.enum.definition.run stream=stdout match=exact
left
5
go
```
