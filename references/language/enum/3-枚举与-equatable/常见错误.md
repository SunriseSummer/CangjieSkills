# 常见错误

[← 3. 枚举与 Equatable](index.md)

枚举默认不支持 `==`；只声明 `Equatable<T>` 但未派生或实现判等操作符仍会编译失败。

```cangjie cjtest=syntax id=syntax-3d1b7c2dd4-1 form=unit
// ❌ 错误：枚举默认不支持 == 比较
enum Status {
    | Active | Inactive
}
// if (Status.Active == Status.Inactive) { }  // 编译错误
```

仅在声明中写 `enum Status <: Equatable<Status>` 仍不够；没有使用 `@Derive` 时，必须实现接口要求的判等操作符。
