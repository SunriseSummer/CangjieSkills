# 手动实现自定义相等语义

[← 3. 枚举与 Equatable](index.md)

当判等规则不是简单的逐字段比较时，手动实现 `Equatable`。二元操作符的左操作数是 `this`，函数只声明右操作数参数。

```cangjie cjtest=syntax id=syntax-b98d6b9774-1 form=unit
enum Switch <: Equatable<Switch> {
    | On | Off

    public operator func ==(other: Switch): Bool {
        match ((this, other)) {
            case (On, On) | (Off, Off) => true
            case _ => false
        }
    }

    public operator func !=(other: Switch): Bool {
        !(this == other)
    }
}
```
