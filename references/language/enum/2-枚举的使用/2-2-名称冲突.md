# 2.2 名称冲突

[← 2. 枚举的使用](index.md)

- 若构造器名与作用域中的变量、函数或类名冲突，须用枚举类型名限定
```cangjie cjtest=syntax id=syntax-fa729e16ed-1 form=unit
let Red = 1                           // 变量名与构造器同名

enum RGBColor {
    | Red | Green(UInt8) | Blue(UInt8)
}

let r1 = Red                          // 选择变量 Red，而非构造器
let r2 = RGBColor.Red                 // 正确：通过类型名访问构造器
```
