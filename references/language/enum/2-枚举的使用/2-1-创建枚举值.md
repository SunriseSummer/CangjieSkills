# 2.1 创建枚举值

[← 2. 枚举的使用](index.md)

- 通过 `TypeName.Constructor` 或直接使用构造器名创建实例
```cangjie cjtest=syntax id=syntax-0354f6e19a-1 form=unit
enum RGBColor {
    | Red | Green | Blue(UInt8)
}

main() {
    let r = RGBColor.Red   // 类型名限定
    let g = Green           // 直接使用构造器名
    let b = Blue(100)       // 有参构造器
}
```
