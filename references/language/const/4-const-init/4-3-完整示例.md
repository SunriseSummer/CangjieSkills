# 4.3 完整示例

[← 4. const init](index.md)

组合使用 `const init` 与 `const` 变量，在编译期构造结构体值并读取其成员。

```cangjie cjtest=syntax id=syntax-87b26195dd-1 form=unit
struct Point {
    const Point(let x: Float64, let y: Float64) {}
}

const func distance(a: Point, b: Point) {
    let dx = a.x - b.x
    let dy = a.y - b.y
    (dx ** 2 + dy ** 2) ** 0.5
}

main() {
    const a = Point(3.0, 0.0)
    const b = Point(0.0, 4.0)
    const d = distance(a, b)
    println(d) // 输出 5.000000
}
```
