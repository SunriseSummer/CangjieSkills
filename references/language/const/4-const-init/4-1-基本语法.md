# 4.1 基本语法

[← 4. const init](index.md)

使用 `const init` 声明可在编译期求值的构造函数；函数体只能包含常量求值允许的操作。

```cangjie cjtest=syntax id=syntax-1c57d7f63f-1 form=unit
struct Point {
    const Point(let x: Float64, let y: Float64) {}
}
```
