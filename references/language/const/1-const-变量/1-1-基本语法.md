# 1.1 基本语法

[← 1. const 变量](index.md)

```cangjie cjtest=syntax id=syntax-737809d495-1 form=stmt
const G = 6.674e-11
```
- 使用 `const` 修饰符声明，表示编译时常量，深度不可变
- 不能省略初始化器
- 可用于全局、局部或静态成员（不可在扩展中）
