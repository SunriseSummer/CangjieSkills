# 1. 定义、触发与恢复

[← 效应处理器](index.md)

Effect Handlers 需要 stdx 1.1.3.1 的 `stdx.effect`，并且两个编译选项缺一不可：`--experimental` 开放实验能力，`--enable-eh` 启用效应处理器。cjpm 项目可在清单中配置：

```toml cjtest=project id=language.effect-handler.basic file=cjpm.toml command=run timeout=60s requires=stdx
[package]
cjc-version = "1.1.3"
name = "effect_handler_basic"
version = "0.1.0"
output-type = "executable"
compile-option = "--experimental --enable-eh"
```

效应类继承 `Command<Res>`，其中 `Res` 是 `perform` 表达式的结果类型。handler 可读取命令对象字段，并且每次 `resume with value` 都从对应 `perform` 之后继续执行。

```cangjie cjtest=file project=language.effect-handler.basic file=src/main.cj
package effect_handler_basic

import stdx.effect.Command

class AskNumber <: Command<Int64> {
    let key: String
    public init(key: String) { this.key = key }
}

func calculate(): Int64 {
    let tens = perform AskNumber("tens")
    let ones = perform AskNumber("ones")
    tens * 10 + ones
}

main(): Unit {
    try {
        println(calculate())
    } handle(command: AskNumber) {
        if (command.key == "tens") {
            resume with 4
        } else {
            resume with 2
        }
    }
}
```

预期标准输出：

```text cjtest=expect for=language.effect-handler.basic stream=stdout match=exact
42
```

修改实验选项后先执行 `cjpm clean`，避免复用不兼容的中间产物。
