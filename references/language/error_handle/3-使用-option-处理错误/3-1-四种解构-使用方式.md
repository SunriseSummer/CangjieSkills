# 3.1 四种解构/使用方式

[← 3. 使用 Option 处理错误](index.md)

### (a) 模式匹配
```cangjie cjtest=syntax id=syntax-38fb5387b4-1 form=stmt
let p: ?Int64 = Some(42)
let result = match (p) {
    case Some(x) => "${x}"
    case None => "none"
}
println(result)  // "42"
```

实际开发中，为简化编码，建议优先使用 if-let 或 while-let 语法糖

### (b) 合并运算符 `??`
- `e1 ?? e2` — 若 `e1` 为 `Some(v)` 返回解包值，否则返回 `e2`

### (c) 问号运算符 `?`（可选链）
- 配合 `.`、`()`、`[]`、`{}`（尾随 Lambda）使用
- `e?.b` → 若 `e == Some(v)` 则 `Some(v.b)`，否则 `None`
- 支持**多级链式调用**：`a?.b.c?.d` — 首个 `None` 处短路
- 支持可选链上的**赋值**：`c1?.item = 200`（`None` 时为空操作）

### (d) `getOrThrow()` 函数
- `Some(v)` 时返回解包值
- `None` 时抛出 `NoneValueException`
