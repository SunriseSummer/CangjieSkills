# 1.1 两种基础异常类型

[← 1. 异常层次与定义](index.md)

- **`Error`** — 内部系统/资源耗尽错误。应用程序**不应**抛出或继承 `Error`。仅用于安全终止程序
- **`Exception`** — 逻辑错误、IO 错误、数组越界等。这些**须**被捕获处理。开发者**可以**继承 `Exception` 创建自定义异常
