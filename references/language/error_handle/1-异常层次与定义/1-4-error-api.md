# 1.4 `Error` API

[← 1. 异常层次与定义](index.md)

速查`属性`：`open prop message: String`；`方法`：`open func toString(): String`；`方法`：`func printStackTrace(): Unit`。

| 类型 | 签名 | 说明 |
|------|------|------|
| 属性 | `open prop message: String` | 详细消息 |
| 方法 | `open func toString(): String` | 类型名 + 消息 |
| 方法 | `func printStackTrace(): Unit` | 堆栈跟踪到 stderr |
