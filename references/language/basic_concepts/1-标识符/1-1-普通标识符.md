# 1.1 普通标识符

[← 1. 标识符](index.md)

- 以 `XID_Start` 字符（包括中英文字母）开头，后跟 `XID_Continue` 字符；或以 `_` 开头后跟至少一个 `XID_Continue` 字符
- 不能是仓颉关键字
- 使用 Unicode 15.0.0 标准，NFC 规范化
- 示例：`abc`、`_abc`、`仓颉`
