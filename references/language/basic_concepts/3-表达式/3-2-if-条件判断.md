# 3.2 if 条件判断

[← 3. 表达式](index.md)

- 语法：`if (cond) { exprs1 } else { exprs2 }`，`cond` 是 `Bool` 类型表达式
- 支持 `else if` 链式使用
- 用作值时：有 `else` 时类型由上下文或各分支最小公共父类型决定，值为所执行分支最后一个表达式的值，无 `else` 时类型始终为 `Unit`
- 条件表达式可以用 `let pattern <- expr` 做模式匹配，详见[模式匹配](../../pattern_match/index.md)
