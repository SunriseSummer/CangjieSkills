# 4. 函数（基本概念）

[← 基本概念](index.md)

- 使用 `func name(params): ReturnType { exprs }` 定义
- 参数以逗号分隔，格式为 `name: Type`
- 函数体 exprs 最后一个表达式默认作为返回值（可以省略 return），但一般情况下建议写 return
- 详见[函数](../function/index.md)
