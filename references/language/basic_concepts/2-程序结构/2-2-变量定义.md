# 2.2 变量定义

[← 2. 程序结构](index.md)

- 语法：`修饰符 名称: 类型 = 值`
- 修饰符：
  - `let`：不可变，只能赋值一次
  - `var`：可变，可多次赋值
  - `const`：编译时常量
- 类型标注可省略（当可推断时）
- 全局/静态变量须初始化
- 局部变量可延迟初始化，但使用前必须赋值

## 已验证反例

`let` 绑定不可重新赋值；以下完整程序应由 1.1.3 编译器拒绝。

```cangjie cjtest=compile id=language-let-reassignment-invalid exit=1
package example

main(): Int64 {
    let answer = 41
    answer = 42
    return answer
}
```

```text cjtest=expect for=language-let-reassignment-invalid stream=stderr match=contains
cannot assign to immutable value
```
