# 7.1 重载规则

[← 7. 函数重载](index.md)

- 同名、**不同参数数量或类型** → 有效重载
- **泛型函数**：对齐类型参数名后，若非泛型部分不同 → 重载；否则 → 重定义错误。类型变量约束**不参与**判断
- **构造函数**：同一类中不同参数的构造函数 → 重载
- **主构造函数与 `init`**：不同参数 → 重载
- 不同作用域（均可见）中的同名函数 → 重载
- **子类与父类**同名函数不同参数类型 → 重载
