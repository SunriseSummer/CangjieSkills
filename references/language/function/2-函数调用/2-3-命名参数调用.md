# 2.3 命名参数调用

[← 2. 函数调用](index.md)

- 只有定义中写成 `paramName!: T` 的形参才能使用 `paramName: value` 调用；普通的 `paramName: T` 是位置参数，调用时不能添加名称标签
- 调用命名参数时不写 `!`：定义 `add(a!: Int64, b!: Int64)`，调用 `add(b: y, a: x)`
- **命名实参的顺序可以与定义顺序不同**

## 已验证示例

```cangjie cjtest=run id=language.named-arguments form=unit timeout=20s
package named_arguments

func format(a!: Int64, b!: Int64): String {
    return "${a}:${b}"
}

main(): Unit {
    println(format(b: 2, a: 1))
}
```

```text cjtest=expect for=language.named-arguments stream=stdout match=exact
1:2
```

## 已验证反例

普通形参 `maxSplits: Int64` 没有 `!`，因此只能按位置传递；以下调用应由 1.1.3 编译器拒绝。

```cangjie cjtest=compile id=language.positional-argument-invalid exit=1
package positional_argument_invalid

func splitLike(separator: String, maxSplits: Int64): Unit {}

main(): Unit {
    splitLike(",", maxSplits: 2)
}
```

```text cjtest=expect for=language.positional-argument-invalid stream=stderr match=contains
invalid named arguments prefix
```
