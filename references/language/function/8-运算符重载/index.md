# 8. 运算符重载

[← 函数与 Lambda](../index.md)

| 细粒度主题 | 摘要 |
|---|---|
| [8.1 语法](8-1-语法.md) | 在 `func` 前使用 `operator` 修饰符 |
| [8.2 可重载的运算符](8-2-可重载的运算符.md) | 可重载 `()`、`[]`、一元 `!`/`-`、幂和算术、移位、关系及位运算符；不能定义列表之外的新运算符。 |
| [8.3 索引运算符 `[]`](8-3-索引运算符.md) | 索引取值重载只含位置参数；索引赋值重载还必须有且只有一个名为 `value`、无默认值的命名参数，并返回 `Unit`。 |
| [8.4 函数调用运算符 `()`](8-4-函数调用运算符.md) | `operator func ()(params): ReturnType` — 任意参数/返回类型 |
| [8.5 复合赋值](8-5-复合赋值.md) | 重载二元运算符（关系运算除外）时自动启用对应复合赋值版本（`+=`、`-=` 等），前提是返回类型与左操作数类型匹配或为其子类型 |
| [8.6 限制](8-6-限制.md) | 不能创建自定义运算符（仅限列出的运算符） |
