# 8.3 索引运算符 `[]`

[← 8. 运算符重载](index.md)

索引取值重载只含位置参数；索引赋值重载还必须有且只有一个名为 `value`、无默认值的命名参数，并返回 `Unit`。

- **取值形式**：`operator func [](args...): ReturnType` — 仅非命名参数
- **赋值形式**：`operator func [](args..., value!: T): Unit` — 须有唯一命名参数 `value!`，无默认值，返回 `Unit`
- 可仅重载取值或赋值中的一个

## 已验证示例

索引取值重载只接收位置参数；赋值重载额外声明一个名为 `value` 的命名参数，调用时仍写作普通下标赋值。

```cangjie cjtest=run id=language.index-operator.run form=unit timeout=20s
package index_operator_example

class Scores {
    let values = [10, 20, 30]

    public operator func [](index: Int64): Int64 {
        return values[index]
    }

    public operator func [](index: Int64, value!: Int64): Unit {
        values[index] = value
    }
}

main(): Unit {
    let scores = Scores()
    scores[1] = 99
    println(scores[1])
}
```

```text cjtest=expect for=language.index-operator.run stream=stdout match=exact
99
```
