# 函数与 Lambda

[← 语言特性](../index.md)

函数调用、命名和默认参数、闭包、重载、运算符、管道与变长参数。

| 规则/任务 | 摘要 |
|---|---|
| [1. 函数定义](1-函数定义/index.md) | 函数使用 `func name(parameters): ReturnType { body }` 声明；参数写明类型，返回类型可显式给出或在可推断时省略。 |
| [2. 函数调用](2-函数调用/index.md) | 调用函数：`f(arg1, arg2)` |
| [3. 函数类型 / 一等公民](3-函数类型-一等公民/index.md) | `(ParamType1, ParamType2, ...) -> ReturnType` |
| [4. Lambda 表达式](4-lambda-表达式/index.md) | `=>` 分隔参数和函数体，不可省略（尾随 Lambda 除外） |
| [5. 闭包](5-闭包/index.md) | 闭包 = 函数/Lambda + 从其定义（词法）作用域捕获的变量 |
| [6. 嵌套函数](6-嵌套函数.md) | 嵌套函数定义在外围函数体内，仅在该作用域可见；它能访问外围参数和变量，并可作为函数值返回。 |
| [7. 函数重载](7-函数重载/index.md) | 同名、不同参数数量或类型 → 有效重载 |
| [8. 运算符重载](8-运算符重载/index.md) | `()`、`[]`、`!`、`-`（一元）、``、`*`、`/`、`%`、`+`、`-`（二元）、`<<`、`>>`、`<`、`<=`、`>`、`>=`、`==`、`!=`、`&`、`^`、`\|` |
| [9. 函数调用语法糖](9-函数调用语法糖/index.md) | 在尾随 Lambda 位置，`=>` 可省略 |
