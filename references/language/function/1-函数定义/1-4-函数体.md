# 1.4 函数体

[← 1. 函数定义](index.md)

- 包含变量定义、表达式、以及可选的嵌套函数定义
- **`return expr`**：终止执行，返回 `expr`（须匹配返回类型）
- **`return`**：等价于 `return ()`，须要求 `Unit` 返回类型
- **`return` 表达式的类型为 `Nothing`**
- **函数体类型** = 最后一项的类型：表达式 → 该表达式类型；变量定义/函数声明/空 → `Unit`
