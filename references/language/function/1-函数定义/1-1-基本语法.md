# 1.1 基本语法

[← 1. 函数定义](index.md)

函数以 `func` 开头，依次声明名称、参数列表、可选返回类型和函数体；函数体最后一个表达式可作为返回值。

```cangjie cjtest=syntax id=syntax-42d5419be4-1 form=unit
func add(a: Int64, b: Int64): Int64 {
    a + b
}
```
- 关键字 `func` 开头
- 参数在 `()` 内，逗号分隔
- 返回类型在参数列表后的 `:` 之后（可选，编译器可推断）
- 函数体在 `{}` 内
