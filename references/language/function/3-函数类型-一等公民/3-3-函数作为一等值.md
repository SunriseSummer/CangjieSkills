# 3.3 函数作为一等值

[← 3. 函数类型 / 一等公民](index.md)

- 函数可**赋给变量**、**作为参数传递**、**从函数返回**
- 函数名本身是该函数类型的表达式
- 若函数名**重载**且有歧义，直接赋给无类型标注的变量会报错。显式类型标注可消除歧义：
  ```cangjie cjtest=syntax id=syntax-784d0a9420-1 form=stmt
  func add(a: Int64, b: Int64): Int64 { a + b }
  var plus: (Int64, Int64) -> Int64 = add  // 消除歧义
  println(plus(1, 2))  // 3
  ```
