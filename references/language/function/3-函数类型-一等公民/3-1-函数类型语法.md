# 3.1 函数类型语法

[← 3. 函数类型 / 一等公民](index.md)

- `(ParamType1, ParamType2, ...) -> ReturnType`
- `->` **右结合**
- 示例：
  - `() -> Unit` — 无参，返回 Unit
  - `(Int64, Int64) -> Int64` — 两个 Int64 参数，返回 Int64
  - `() -> (Int64, Int64) -> Int64` — 返回一个函数
