# 1.7 访问修饰符

[← 1. 结构体定义](index.md)

速查`private`：仅在结构体定义内；`internal`（默认）：当前包及子包；`protected`：当前模块；另含更多表项。

| 修饰符 | 可见性 |
|--------|--------|
| `private` | 仅在结构体定义内 |
| `internal`（默认） | 当前包及子包 |
| `protected` | 当前模块 |
| `public` | 全局可见 |
