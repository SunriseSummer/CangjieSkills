# 1.8 禁止递归结构体

[← 1. 结构体定义](index.md)

- 直接和间接递归均**不合法**（编译错误）：
```cangjie cjtest=syntax id=syntax-4161cad3b3-1 form=unit
struct R1 { let other: R1 }         // 错误：自引用
struct R2 { let other: R3 }         // 错误：相互引用
struct R3 { let other: R2 }
```
