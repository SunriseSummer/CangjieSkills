# 2.4 Quote 转义规则

[← 2. Token 与 Tokens 类型](index.md)

- `quote` 中未匹配的括号须用 `\` 转义：`\(` 或 `\)`
- `$` 作为字面 token（非插值）须转义：`\$`
- 输入中的 `@` 须转义：`\@`
