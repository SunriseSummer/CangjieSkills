# 2.2 Tokens 类型

[← 2. Token 与 Tokens 类型](index.md)

- `Tokens` 是 `Token` 对象的序列
- 构造函数：`Tokens()`、`Tokens(tks: Array<Token>)`、`Tokens(tks: ArrayList<Token>)`
- 操作：`size`、`get(index)`、`[]` 索引、`+` 拼接、`dump()` 调试输出、`toString()` 代码字符串
