# 1.1 核心概念

[← 1. 宏概述](index.md)

- 宏是特殊函数，输入和输出均为**程序片段**（非值）
- 使用 `@` 前缀调用：`@macroName(...)`
- 宏接收 `Tokens` 输入，转换后返回新的 `Tokens`，在编译时替换调用处
- 须声明在专用的**宏包**中：`macro package <name>`
- 宏实现按实际使用精确导入 `std.ast` 类型与函数；`quote` 是关键字，不是可导入符号
