# 3.1 项目结构

[← 3. 使用 cjpm 构建（推荐）](index.md)

代码展示 `my_project/` 的典型用法。

```text
my_project/
├── cjpm.toml              # 主项目配置
├── src/
│   └── main.cj            # 调用宏的代码
└── macros/                 # 宏模块
    ├── cjpm.toml           # 宏模块配置
    └── src/
        └── my_macros.cj    # 宏定义
```
