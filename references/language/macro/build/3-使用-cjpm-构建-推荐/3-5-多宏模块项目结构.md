# 3.5 多宏模块项目结构

[← 3. 使用 cjpm 构建（推荐）](index.md)

当项目包含多个宏模块时，可以组织为：

```text
my_project/
├── cjpm.toml
├── src/
│   └── main.cj
├── macro_a/
│   ├── cjpm.toml          # compile-option = "--compile-macro"
│   └── src/
│       └── macro_a.cj
└── macro_b/
    ├── cjpm.toml          # compile-option = "--compile-macro"
    └── src/
        └── macro_b.cj
```

主项目 `cjpm.toml`：

```toml
[dependencies]
macro_a = { path = "./macro_a" }
macro_b = { path = "./macro_b" }
```
