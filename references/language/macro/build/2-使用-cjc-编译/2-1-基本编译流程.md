# 2.1 基本编译流程

[← 2. 使用 cjc 编译](index.md)

命令：`cjc macros/m.cj --compile-macro --output-dir ./target`。

```shell
# 步骤 1：编译宏包
cjc macros/m.cj --compile-macro --output-dir ./target

# 步骤 2：编译调用包并链接宏包
cjc src/demo.cj -o demo --import-path ./target
```
