# 2.3 不同平台的注意事项

[← 2. 使用 cjc 编译](index.md)

速查`Linux`：`.so`；`macOS`：`.dylib`；`Windows`：`.dll`。

| 平台 | 动态库扩展名 | 示例 |
|------|-------------|------|
| Linux | `.so` | `cjc B.cj --output-type=dylib -o libB.so` |
| macOS | `.dylib` | `cjc B.cj --output-type=dylib -o libB.dylib` |
| Windows | `.dll` | `cjc B.cj --output-type=dylib -o B.dll` |
