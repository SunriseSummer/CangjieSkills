# 2.2 多模块场景

[← 2. 使用 cjc 编译](index.md)

当宏包依赖其他非宏包时，须按依赖顺序编译：

```shell
cjc A.cj --compile-macro                    # 编译宏包
cjc B.cj --output-type=dylib -o libB.so     # 编译依赖库（Linux）
cjc C.cj --compile-macro -L. -lB            # 编译带依赖的宏包
cjc main.cj -o main -L. -lB                 # 编译主程序
```
