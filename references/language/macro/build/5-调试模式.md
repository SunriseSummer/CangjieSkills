# 5. 调试模式

[← 宏包编译构建](index.md)

- `--debug-macro` 生成 `.macrocall` 临时文件显示完全展开的宏代码
- 用于开发阶段排查宏展开结果是否符合预期

```shell
# cjc 直接使用
cjc src/demo.cj --debug-macro --import-path ./target

# cjpm 中通过 compile-option 使用
# cjpm.toml
[package]
compile-option = "--debug-macro"
```
