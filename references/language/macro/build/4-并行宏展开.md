# 4. 并行宏展开

[← 宏包编译构建](index.md)

- 使用 `--parallel-macro-expansion` 标志启用并行宏展开
- **警告**：使用全局变量的宏在并行展开时不安全
- 可通过 `cjpm.toml` 中 `compile-option` 添加：

```toml
[package]
compile-option = "--parallel-macro-expansion"
```
