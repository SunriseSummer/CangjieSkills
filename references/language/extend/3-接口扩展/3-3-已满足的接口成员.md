# 3.3 已满足的接口成员

[← 3. 接口扩展](index.md)

若既有类型已经包含接口要求的公开成员，空扩展体即可建立接口关系；不得在扩展中重复定义同签名成员。

若类型已有所需成员，扩展体可为空：
```cangjie cjtest=syntax id=syntax-9aa13e86bc-1 form=unit
interface Sizeable {
    prop size: Int64
}

extend<T> Array<T> <: Sizeable {}  // Array 已有 prop size

main() {
    let a: Sizeable = Array<Int64>()
    println(a.size)  // 输出：0
}
```
**不能**重新实现已存在的成员

## 已验证示例

若既有类型已经具备接口要求的公开成员，接口扩展体可以为空；扩展后该类型可按接口统一使用。

```cangjie cjtest=run id=language.interface-extension.run form=unit timeout=20s
package interface_extension_example

interface Sizeable {
    prop size: Int64
}

extend<T> Array<T> <: Sizeable {}

func printSize(value: Sizeable): Unit {
    println(value.size)
}

main(): Unit {
    printSize([10, 20, 30])
}
```

```text cjtest=expect for=language.interface-extension.run stream=stdout match=exact
3
```
