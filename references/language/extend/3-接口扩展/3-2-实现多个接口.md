# 3.2 实现多个接口

[← 3. 接口扩展](index.md)

使用 `&` 在一个扩展中实现多个接口：
```cangjie cjtest=syntax id=syntax-55cd569420-1 form=unit
interface I1 { func f1(): Unit }
interface I2 { func f2(): Unit }
interface I3 { func f3(): Unit }
class Foo {}

extend Foo <: I1 & I2 & I3 {
    public func f1(): Unit {}
    public func f2(): Unit {}
    public func f3(): Unit {}
}
```
