# 3.1 基本语法

[← 3. 接口扩展](index.md)

接口扩展使用 `extend Type <: Interface` 为既有类型补充接口实现，并必须实现接口尚未提供默认实现的成员。

```cangjie cjtest=syntax id=syntax-c96b6a41ee-1 form=unit
interface PrintSizeable {
    func printSize(): Unit
}

extend<T> Array<T> <: PrintSizeable {
    public func printSize() {
        println("The size is ${this.size}")
    }
}

main() {
    let a: PrintSizeable = Array<Int64>()
    a.printSize()  // 输出：The size is 0
}
```
