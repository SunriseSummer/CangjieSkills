# 3. 接口扩展

[← 扩展](../index.md)

| 细粒度主题 | 摘要 |
|---|---|
| [3.1 基本语法](3-1-基本语法.md) | 接口扩展使用 `extend Type <: Interface` 为既有类型补充接口实现，并必须实现接口尚未提供默认实现的成员。 |
| [3.2 实现多个接口](3-2-实现多个接口.md) | 使用 `&` 在一个扩展中实现多个接口。 |
| [3.3 已满足的接口成员](3-3-已满足的接口成员.md) | 若既有类型已经包含接口要求的公开成员，空扩展体即可建立接口关系；不得在扩展中重复定义同签名成员。 |
| [3.4 接口继承与检查顺序](3-4-接口继承与检查顺序.md) | 同一类型的接口扩展存在父子接口关系时先检查父接口、再检查子接口；子接口默认实现可覆盖先继承的同签名实现，顺序无法确定时编译报错。 |
| [3.5 接口扩展中的泛型约束](3-5-接口扩展中的泛型约束.md) | 泛型接口扩展可用 `where` 同时约束被扩展类型的多个类型参数，约束满足时才获得接口能力。 |
