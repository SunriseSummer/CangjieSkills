# 4.9 泛型扩展可见性规则

[← 4. 访问规则](index.md)

泛型扩展只有在类型参数和 `where` 约束等价时才互相可见；约束不同的扩展不能直接访问彼此成员。

- **相同约束** → 互相可见
- **子集约束** → 较宽松扩展的成员对较严格扩展可见，反之不可
- **无关约束** → 互相不可见
```cangjie cjtest=syntax id=syntax-4f53730b0a-1 form=unit
open class A {}
class B <: A {}
class E<X> {}

interface I1 { func f1(): Unit }
interface I2 { func f2(): Unit }

extend<X> E<X> <: I1 where X <: B {   // 扩展 1（更严格）
    public func f1(): Unit {
        f2()  // OK: 较宽松扩展的成员可见
    }
}

extend<X> E<X> <: I2 where X <: A {   // 扩展 2（更宽松）
    public func f2(): Unit {
        // f1()  // ❌ Error: 较严格扩展的成员不可见
    }
}
```
