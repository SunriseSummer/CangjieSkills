# 4.7 不能遮蔽

[← 4. 访问规则](index.md)

- 扩展**不能**重定义类型上已有的成员
- 扩展**不能**重定义同一类型的另一个扩展中的成员
```cangjie cjtest=syntax id=syntax-dd84a6c731-1 form=unit
class A {
    func f() {}
}
extend A {
    func f() {}  // ❌ Error: 不能遮蔽已有成员
}

// 两个扩展之间也不能遮蔽
extend A {
    func g() {}
}
extend A {
    func g() {}  // ❌ Error
}
```
