# 4.4 孤儿规则

[← 4. 访问规则](index.md)

不能为**接口和类型均来自不同包**的情况实现接口。扩展须与被扩展类型或接口（含接口继承链上的所有接口）在**同一个包**中。
```cangjie cjtest=syntax id=syntax-f6e258f236-1 form=unit
// package a
public class Foo {}
```
```cangjie cjtest=syntax id=syntax-f6e258f236-2 form=unit
// package b
public interface Bar {}
```
```cangjie cjtest=syntax id=syntax-f6e258f236-3 form=unit
// package c
import a.Foo
import b.Bar
extend Foo <: Bar {}  // ❌ Error: 孤儿扩展
// 须在 package a 或 package b 中为 Foo 实现 Bar
```
