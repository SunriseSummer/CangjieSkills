# 4.2 成员级修饰符

[← 4. 访问规则](index.md)

允许：`static`、`public`、`protected`、`internal`、`private`、`mut`

| 修饰符 | 作用域 |
|--------|--------|
| `private` | 仅在扩展块内 |
| `internal` | 当前包及子包（默认） |
| `protected` | 当前模块 |
| `public` | 全局可见 |
| `static` | 仅通过类型名访问 |
| `mut` | 结构体扩展中的可变函数 |

**不允许**用于扩展成员的修饰符：`open`、`override`、`redef`
