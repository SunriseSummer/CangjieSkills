# 4.1 扩展级修饰符

[← 4. 访问规则](index.md)

扩展声明本身不接受访问修饰符；扩展成员的可见性由成员声明和被扩展类型的访问规则共同决定。

- **扩展本身不能有修饰符**
```cangjie cjtest=syntax id=syntax-ac71f6823e-1 form=stmt
public class A {}
public extend A {}  // ❌ Error: 扩展前不能有修饰符
```
