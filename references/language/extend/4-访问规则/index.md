# 4. 访问规则

[← 扩展](../index.md)

| 细粒度主题 | 摘要 |
|---|---|
| [4.1 扩展级修饰符](4-1-扩展级修饰符.md) | 扩展声明本身不接受访问修饰符；扩展成员的可见性由成员声明和被扩展类型的访问规则共同决定。 |
| [4.2 成员级修饰符](4-2-成员级修饰符.md) | 允许：`static`、`public`、`protected`、`internal`、`private`、`mut` |
| [4.3 扩展 struct 的 `mut` 函数](4-3-扩展-struct-的-mut-函数.md) | 扩展结构体时，修改实例状态的成员必须声明为 `mut func`；普通函数不能改写结构体字段。 |
| [4.4 孤儿规则](4-4-孤儿规则.md) | 不能为接口和类型均来自不同包的情况实现接口。 |
| [4.5 `this` 和 `super`](4-5-this-和-super.md) | 扩展实例成员可以使用 `this`（可省略） |
| [4.6 不能访问 `private` 成员](4-6-不能访问-private-成员.md) | 扩展不能读写被扩展类型的 `private` 成员。 |
| [4.7 不能遮蔽](4-7-不能遮蔽.md) | 扩展不能重定义类型上已有的成员 |
| [4.8 跨扩展可见性（同一包）](4-8-跨扩展可见性-同一包.md) | 同一包中允许同一类型的多个扩展 |
| [4.9 泛型扩展可见性规则](4-9-泛型扩展可见性规则.md) | 泛型扩展只有在类型参数和 `where` 约束等价时才互相可见；约束不同的扩展不能直接访问彼此成员。 |
| [4.10 导出规则](4-10-导出规则.md) | 与被扩展类型同包时，当类型和所有泛型约束均为导出类型时导出 |
| [4.11 导入规则](4-11-导入规则.md) | 扩展隐式导入 — 无需显式 `import` 扩展本身 |
