# 1. 扩展概述

[← 扩展](../index.md)

| 细粒度主题 | 摘要 |
|---|---|
| [1.1 目的](1-1-目的.md) | 扩展为当前包中任何可见类型添加新功能 — 函数、元组和接口除外。 |
| [1.2 可添加的内容](1-2-可添加的内容.md) | 扩展可增加实例函数、静态函数、计算属性和运算符函数，但不能为既有类型增加存储字段。 |
| [1.3 不能做的事](1-3-不能做的事.md) | 扩展不能增加存储字段，不能扩展函数、元组或接口类型，也不能绕过原类型的可见性规则访问私有实现。 |
| [1.4 两个类别](1-4-两个类别.md) | 直接扩展：不涉及接口 — 仅添加函数/属性 |
