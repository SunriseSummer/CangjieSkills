# 2.1 基本语法与示例

[← 2. 直接扩展](index.md)

使用 `extend Type` 为现有类型增加实例成员；新增成员通过普通的点调用访问，但扩展不会增加实例字段。

```cangjie cjtest=syntax id=syntax-1b40cfd20b-1 form=unit
extend String {
    public func printSize() {
        println("the size is ${this.size}")
    }
}

main() {
    let a = "123"
    a.printSize()  // 输出：the size is 3
}
```

## 已验证示例

扩展成员像普通实例函数一样调用；它只复用 `String` 已有状态，不向类型增加字段。

```cangjie cjtest=run id=language.direct-extension.run form=unit timeout=20s
package direct_extension_example

extend String {
    public func wrapped(): String {
        return "[${this}]"
    }
}

main(): Unit {
    println("Cangjie".wrapped())
}
```

```text cjtest=expect for=language.direct-extension.run stream=stdout match=exact
[Cangjie]
```
