# 2.2 为类型添加属性和运算符

[← 2. 直接扩展](index.md)

直接扩展可以增加计算属性和运算符函数；声明语法与类型体内的对应成员一致。

```cangjie cjtest=syntax id=syntax-7df0e4ac2c-1 form=unit
class Boo {
    var boo: Int64 = 2
}

extend Boo {
    public prop x: Int64 {     // 添加成员属性
        get() { 123 }
    }

    public operator func -(): Int64 { // 添加运算符重载
        -x
    }
}
```
