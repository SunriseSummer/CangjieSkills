# 2. 直接扩展

[← 扩展](../index.md)

| 细粒度主题 | 摘要 |
|---|---|
| [2.1 基本语法与示例](2-1-基本语法与示例.md) | 使用 `extend Type` 为现有类型增加实例成员；新增成员通过普通的点调用访问，但扩展不会增加实例字段。 |
| [2.2 为类型添加属性和运算符](2-2-为类型添加属性和运算符.md) | 直接扩展可以增加计算属性和运算符函数；声明语法与类型体内的对应成员一致。 |
| [2.3 扩展泛型类型 — 两种形式](2-3-扩展泛型类型-两种形式.md) | `extend Foo<Int64>` 只扩展一个具体实例化类型；`extend<T> Foo<T>` 为所有满足条件的实例化类型提供成员。 |
| [2.4 扩展中的额外泛型约束](2-4-扩展中的额外泛型约束.md) | 在泛型扩展后添加 `where` 约束，可让扩展成员只对满足接口约束的类型实参可用。 |
