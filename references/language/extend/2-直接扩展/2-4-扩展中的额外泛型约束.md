# 2.4 扩展中的额外泛型约束

[← 2. 直接扩展](index.md)

在泛型扩展后添加 `where` 约束，可让扩展成员只对满足接口约束的类型实参可用。

- 可添加 `where` 子句限制扩展成员的可用条件：
```cangjie cjtest=syntax id=syntax-33b98f7420-1 form=unit
class Pair<T1, T2> {
    var first: T1
    var second: T2
    public init(a: T1, b: T2) {
        first = a
        second = b
    }
}

interface Eq<T> {
    func equals(other: T): Bool
}

// 仅当 T1、T2 支持判等时，Pair 才有 equals 方法
extend<T1, T2> Pair<T1, T2> where T1 <: Eq<T1>, T2 <: Eq<T2> {
    public func equals(other: Pair<T1, T2>): Bool {
        first.equals(other.first) && second.equals(other.second)
    }
}
```
