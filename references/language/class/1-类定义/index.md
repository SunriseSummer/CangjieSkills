# 1. 类定义

[← 类](../index.md)

| 细粒度主题 | 摘要 |
|---|---|
| [1.1 基本语法](1-1-基本语法.md) | 使用 `class ClassName { ... }` 声明，仅可在顶层作用域定义 |
| [1.2 抽象类](1-2-抽象类.md) | 用 `abstract class` 声明抽象类；抽象函数直接写无函数体的 `public`/`protected func`，不写 `abstract func`，非抽象子类必须实现。 |
| [1.3 成员变量](1-3-成员变量.md) | 实例成员：使用 `let`/`var` 定义，通过对象访问。 |
| [1.4 静态初始化器](1-4-静态初始化器.md) | `static init() { ... }` — 每个类最多一个，须初始化所有未初始化的静态成员 |
| [1.5 构造函数](1-5-构造函数.md) | `init(params) { ... }` — 须初始化所有未初始化的实例成员变量 |
| [1.6 终结器（`~init`）](1-6-终结器-init.md) | `~init() { ... }` — 在垃圾回收时触发，用于释放系统资源 |
| [1.7 成员函数](1-7-成员函数.md) | 实例函数：通过对象访问，可使用 `this` |
| [1.8 访问修饰符（4 级）](1-8-访问修饰符-4-级.md) | 速查`private`：仅在类定义内；`internal`（默认）：当前包及子包；`protected`：当前模块及子类；另含更多表项。 |
| [1.9 `This` 类型](1-9-this-类型.md) | 在类内部，`This` 是当前类类型的占位符，仅可用作实例方法返回类型 |
