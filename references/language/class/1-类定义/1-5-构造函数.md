# 1.5 构造函数

[← 1. 类定义](index.md)

### 普通构造函数
- `init(params) { ... }` — 须初始化所有未初始化的实例成员变量
- 多个构造函数须构成有效重载

### 主构造函数
- `ClassName(let x: T, var y: T) {}` — 参数名前缀 `let`/`var` 同时定义成员变量
- 每个类最多一个

### 执行顺序
1. 构造函数外成员默认值初始化
2. 隐式/显式 `super()` 调用
3. 构造函数体

### 自动生成构造函数
- 若无自定义构造函数且所有实例成员有初始值，则自动生成无参 `public init()`
