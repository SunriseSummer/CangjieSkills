# 1.2 抽象类

[← 1. 类定义](index.md)

用 `abstract class` 声明抽象类；抽象函数直接写无函数体的 `public`/`protected func`，不写 `abstract func`，非抽象子类必须实现。

- `abstract class` — 可声明抽象函数（无函数体），不能实例化
- 抽象函数直接写无函数体的 `func` 声明；不要写不存在的 `abstract func`
- 抽象函数不能为 `private`；非抽象子类须实现所有抽象函数
- 抽象类定义时 `open` 修饰符可选
- `sealed abstract class` — 仅同包内可继承，隐含 `public`/`open` 语义

```cangjie cjtest=compile id=language.class.abstract-function form=unit timeout=20s
package abstract_function_example

abstract class Shape {
    public func area(): Float64
}

class Square <: Shape {
    let side: Float64

    public init(side: Float64) {
        this.side = side
    }

    public override func area(): Float64 {
        return side * side
    }
}

main(): Unit {
    let shape: Shape = Square(3.0)
    println(shape.area())
}
```
