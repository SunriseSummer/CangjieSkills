# 1.6 终结器（`~init`）

[← 1. 类定义](index.md)

- `~init() { ... }` — 在垃圾回收时触发，用于释放系统资源
- 无参数、无返回类型、无泛型类型参数、无修饰符、不可显式调用
- 带终结器的类不能为 `open`。每个类最多一个。不能在扩展中定义
- 触发时机不确定；可能在任意线程上运行
- 终结器向外抛出未捕获异常属于未定义行为
- 未完整初始化的对象（初始化时抛异常）的终结器不会执行
