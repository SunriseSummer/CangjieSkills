# 1.8 访问修饰符（4 级）

[← 1. 类定义](index.md)

速查`private`：仅在类定义内；`internal`（默认）：当前包及子包；`protected`：当前模块及子类；另含更多表项。

| 修饰符 | 可见性 |
|--------|--------|
| `private` | 仅在类定义内 |
| `internal`（默认） | 当前包及子包 |
| `protected` | 当前模块及子类 |
| `public` | 全局可见 |
