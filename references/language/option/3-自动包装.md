# 3. 自动包装

[← Option](index.md)

当上下文期望 `Option<T>` 时，可直接传 `T` 类型的值，编译器自动用 `Some` 包装（**不是**类型转换）：
```cangjie cjtest=syntax id=syntax-bb413487a4-1 form=stmt
let a: Option<Int64> = 100     // 自动包装为 Some(100)
let b: ?Int64 = 100            // 同上
let c: Option<String> = "hi"   // 自动包装为 Some("hi")
```
