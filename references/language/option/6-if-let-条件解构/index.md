# 6. if-let 条件解构

[← Option](../index.md)

| 细粒度主题 | 摘要 |
|---|---|
| [概述与共同规则](overview.md) | 在 `if` 条件中使用 `let` 模式匹配语法糖，成功匹配时进入 `if` 分支，绑定的变量仅在 `if` 分支内可用。 |
| [6.1 基本用法](6-1-基本用法.md) | `if-let` 在值匹配 `Some` 时解构并进入分支，可把判空与取值合并为一次模式匹配。 |
| [6.2 多条件组合（`&&`）](6-2-多条件组合.md) | 用 `&&` 连接多个 `let` 模式或与布尔表达式混合。 |
| [6.3 或条件（`\|\|`）](6-3-或条件.md) | 用 `\|\|` 连接时，模式中不能有变量绑定，只能使用通配符 `_` |
