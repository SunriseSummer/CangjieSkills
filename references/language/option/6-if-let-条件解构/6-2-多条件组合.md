# 6.2 多条件组合（`&&`）

[← 6. if-let 条件解构](index.md)

用 `&&` 连接多个 `let` 模式或与布尔表达式混合：
```cangjie cjtest=syntax id=syntax-628dacc204-1 form=unit
main() {
    let a = Some(3)
    let d = Some(1)

    // 两个 let 模式同时匹配
    if (let Some(e) <- a && let Some(f) <- d) {
        println("${e} ${f}")   // 输出: 3 1
    }

    // let 模式 + 布尔条件
    if (let Some(f) <- d && f > 0) {
        println(f)   // 输出: 1
    }
}
```
