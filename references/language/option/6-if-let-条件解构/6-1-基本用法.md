# 6.1 基本用法

[← 6. if-let 条件解构](index.md)

`if-let` 在值匹配 `Some` 时解构并进入分支，可把判空与取值合并为一次模式匹配。

```cangjie cjtest=syntax id=syntax-b60c05876c-1 form=unit
main() {
    let opt: ?Int64 = 42
    // print 42
    if (let Some(v) <- opt) {
        println(v)
    } else {
        println("invalid")
    }
}
```
