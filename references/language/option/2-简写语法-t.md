# 2. 简写语法 `?T`

[← Option](index.md)

- `?Ty` 等价于 `Option<Ty>`
```cangjie cjtest=syntax id=syntax-0a6200755e-1 form=stmt
let a: ?Int64 = Some(100)     // 等价于 Option<Int64>
let b: ?String = None          // 等价于 Option<String>
```
