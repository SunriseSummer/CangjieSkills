# 1. 定义

[← Option](index.md)

```cangjie cjtest=syntax id=syntax-a5e030803b-1 form=unit
enum Option<T> {
    | Some(T)
    | None
}
```
- `Some(v)` 表示有值，`None` 表示无值
- `Option` 是泛型枚举，`T` 不同则 `Option` 类型不同（如 `Option<Int64>`、`Option<String>`）
