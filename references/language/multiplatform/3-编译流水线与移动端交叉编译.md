# 3. 编译流水线与移动端交叉编译

[← 跨平台开发](index.md)

直接调用 `cjc` 编译跨平台包时，先把公共部分输出为 CHIR，再把该 CHIR 和公共 CJO 一并交给平台部分：

```bash
cjc --experimental common/common.cj --output-type=chir --output-dir ./common
cjc --experimental specific/windows.cj common/platform_demo.chir \
  --common-part-cjo=./common/platform_demo.cjo --output-type=dylib --output-dir ./specific
```

Android 目标使用 `--target=aarch64-linux-android<API>`（最低 API 26），并提供 NDK 的 `--sysroot` 与 builtins 库目录。iOS 只支持静态库，使用 `--target=aarch64-apple-ios<version> --output-type=staticlib`；模拟器目标为 `aarch64-apple-ios-simulator` 或 `x86_64-apple-ios-simulator`。这些目标需要对应的交叉编译 SDK、Android NDK 或 Xcode，不能仅靠桌面 SDK 验证运行结果。
