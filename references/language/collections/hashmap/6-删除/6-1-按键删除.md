# 6.1 按键删除

[← 6. 删除](index.md)

```cangjie cjtest=syntax id=syntax-c2ee8f08ed-1 form=unit
func remove(key: K): Option<V>
```

- 返回被删除的值；键不存在返回 `None`

```cangjie cjtest=syntax id=syntax-c2ee8f08ed-2 form=stmt
let map = HashMap<String, Int64>([("a", 1), ("b", 2)])
let removed = map.remove("a")   // Some(1)
let nothing = map.remove("xyz") // None
```
