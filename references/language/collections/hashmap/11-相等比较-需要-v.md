# 11. 相等比较（需要 V <: Equatable<V>）

[← HashMap 类型](index.md)

`let a = HashMap<String, Int64>([("x", 1), ("y", 2)])`：相等比较（需要 V <: Equatable<V>）。

```cangjie cjtest=syntax id=syntax-39c3a341c5-1 form=stmt
let a = HashMap<String, Int64>([("x", 1), ("y", 2)])
let b = HashMap<String, Int64>([("y", 2), ("x", 1)])
let c = HashMap<String, Int64>([("x", 1), ("y", 3)])

println(a == b)  // true（键值对完全相同，不关心顺序）
println(a != c)  // true
```
