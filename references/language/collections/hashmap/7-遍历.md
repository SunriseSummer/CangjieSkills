# 7. 遍历

[← HashMap 类型](index.md)

`HashMap<K, V>` 迭代元素是 `(K, V)`；用 `for ((key, value) in map)` 直接解构键值，遍历顺序不稳定，业务逻辑不得依赖输出次序。

```cangjie cjtest=syntax id=syntax-415990b34f-1 form=unit
func iterator(): HashMapIterator<K, V>
```

```cangjie cjtest=syntax id=syntax-415990b34f-2 form=stmt
let map = HashMap<String, Int64>([("a", 1), ("b", 2), ("c", 3)])

// for-in 解构遍历（推荐）
for ((k, v) in map) {
    println("${k}: ${v}")
}

// 仅遍历键
for (k in map.keys()) {
    println(k)
}

// 仅遍历值
for (v in map.values()) {
    println(v)
}
```

> **注意**：遍历顺序不保证。如需有序遍历，考虑使用 `TreeMap<K, V>`。
