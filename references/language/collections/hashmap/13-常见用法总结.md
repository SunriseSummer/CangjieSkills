# 13. 常见用法总结

[← HashMap 类型](index.md)

典型 `HashMap` 流程包括安全取值、词频统计、键值遍历、批量构造、条件删除和覆盖式合并。

```cangjie cjtest=compile id=verified-c2bed36989-1
package hashmap_summary_example

import std.collection.*

main(): Int64 {
    let counts = HashMap<String, Int64>()
    for (word in ["red", "blue", "red"]) {
        counts[word] = (counts.get(word) ?? 0) + 1
    }

    // add(all:) 合并键值对；同名键使用新值覆盖。
    counts.add(all: [("blue", 3), ("green", 1)])
    counts.removeIf { key, value => key == "green" && value == 1 }

    if (let Some(redCount) <- counts.get("red")) {
        println("red=${redCount}")
    }
    println("blue=${counts["blue"]}")
    println("has green: ${counts.contains("green")}")
    return 0
}
```
