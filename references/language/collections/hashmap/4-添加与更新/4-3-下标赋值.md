# 4.3 下标赋值

[← 4. 添加与更新](index.md)

`map["key"] = value   // 键存在则更新，不存在则新增`：下标赋值。

```cangjie cjtest=syntax id=syntax-51cba7ddf8-1 form=stmt
map["key"] = value   // 键存在则更新，不存在则新增
```

```cangjie cjtest=syntax id=syntax-51cba7ddf8-2 form=stmt
let map = HashMap<String, Int64>()
map["x"] = 10   // 新增
map["x"] = 20   // 更新
```
