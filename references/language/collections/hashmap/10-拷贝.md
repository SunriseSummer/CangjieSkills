# 10. 拷贝

[← HashMap 类型](index.md)

`func clone(): HashMap<K, V>`：拷贝。

```cangjie cjtest=syntax id=syntax-b644d1e7f9-1 form=unit
func clone(): HashMap<K, V>
```

```cangjie cjtest=syntax id=syntax-b644d1e7f9-2 form=stmt
let map = HashMap<String, Int64>([("a", 1)])
let copy = map.clone()
copy["a"] = 999
println(map["a"])  // 1（不受影响）
```
