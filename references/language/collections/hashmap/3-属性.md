# 3. 属性

[← HashMap 类型](index.md)

`let map = HashMap<String, Int64>([("a", 1), ("b", 2)])`：属性。

| 属性 | 类型 | 说明 |
|------|------|------|
| `size` | `Int64` | 键值对个数 |
| `capacity` | `Int64` | 当前内部容量 |

```cangjie cjtest=syntax id=syntax-86367838ad-1 form=stmt
let map = HashMap<String, Int64>([("a", 1), ("b", 2)])
println(map.size)      // 2
println(map.capacity)  // >= 2
```
