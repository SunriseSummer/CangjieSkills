# 12. 相等比较

[← HashSet](index.md)

`let a = HashSet<Int64>([1, 2, 3])`：相等比较。

```cangjie cjtest=syntax id=syntax-a25df8ccd4-1 form=stmt
let a = HashSet<Int64>([1, 2, 3])
let b = HashSet<Int64>([3, 2, 1])
let c = HashSet<Int64>([1, 2, 4])

println(a == b)  // true（元素完全相同，不关心顺序）
println(a != c)  // true
```
