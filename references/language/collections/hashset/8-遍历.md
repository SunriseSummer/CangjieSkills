# 8. 遍历

[← HashSet](index.md)

`HashSet` 可直接用于 `for-in` 遍历，但元素顺序不稳定，不能把迭代顺序当作排序结果。

```cangjie cjtest=syntax id=syntax-e7ccceee6c-1 form=unit
func iterator(): Iterator<T>
```

```cangjie cjtest=syntax id=syntax-e7ccceee6c-2 form=stmt
let set = HashSet<String>(["apple", "banana", "orange"])

// for-in 遍历（推荐）
for (item in set) {
    println(item)
}
```

> **注意**：遍历顺序不保证。
