# 3. 属性

[← HashSet](index.md)

`let set = HashSet<Int64>([1, 2, 3])`：属性。

| 属性 | 类型 | 说明 |
|------|------|------|
| `size` | `Int64` | 元素个数 |
| `capacity` | `Int64` | 当前内部容量（不一定等于 size） |

```cangjie cjtest=syntax id=syntax-457a97b5ad-1 form=stmt
let set = HashSet<Int64>([1, 2, 3])
println(set.size)      // 3
println(set.capacity)  // >= 3
```
