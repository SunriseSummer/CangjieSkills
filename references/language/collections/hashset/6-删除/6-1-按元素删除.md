# 6.1 按元素删除

[← 6. 删除](index.md)

```cangjie cjtest=syntax id=syntax-069c9f6521-1 form=unit
func remove(element: T): Bool
```

- 元素存在：移除成功，返回 `true`
- 元素不存在：返回 `false`

```cangjie cjtest=syntax id=syntax-069c9f6521-2 form=stmt
let set = HashSet<String>(["apple", "banana", "orange"])
println(set.remove("apple"))   // true
println(set.remove("grape"))   // false（不存在）
```
