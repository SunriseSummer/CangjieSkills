# 7.4 子集判断

[← 7. 集合运算](index.md)

`func subsetOf(other: ReadOnlySet<T>): Bool`：子集判断。

```cangjie cjtest=syntax id=syntax-69488056eb-1 form=unit
func subsetOf(other: ReadOnlySet<T>): Bool
```

```cangjie cjtest=syntax id=syntax-69488056eb-2 form=stmt
let a = HashSet<Int64>([1, 2])
let b = HashSet<Int64>([1, 2, 3, 4])
println(a.subsetOf(b))  // true
println(b.subsetOf(a))  // false
```
