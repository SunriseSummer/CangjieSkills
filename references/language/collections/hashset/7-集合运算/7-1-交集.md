# 7.1 交集 `&`

[← 7. 集合运算](index.md)

`operator func &(other: ReadOnlySet<T>): HashSet<T>`：交集 &。

```cangjie cjtest=syntax id=syntax-d32f2e7108-1 form=member
operator func &(other: ReadOnlySet<T>): HashSet<T>
```

```cangjie cjtest=syntax id=syntax-d32f2e7108-2 form=stmt
let a = HashSet<Int64>([1, 2, 3, 4])
let b = HashSet<Int64>([3, 4, 5, 6])
let intersection = a & b  // {3, 4}
```
