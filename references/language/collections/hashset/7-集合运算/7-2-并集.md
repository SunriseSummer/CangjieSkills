# 7.2 并集 `|`

[← 7. 集合运算](index.md)

`operator func |(other: ReadOnlySet<T>): HashSet<T>`：并集 |。

```cangjie cjtest=syntax id=syntax-3297168570-1 form=member
operator func |(other: ReadOnlySet<T>): HashSet<T>
```

```cangjie cjtest=syntax id=syntax-3297168570-2 form=stmt
let a = HashSet<Int64>([1, 2, 3])
let b = HashSet<Int64>([3, 4, 5])
let union = a | b  // {1, 2, 3, 4, 5}
```
