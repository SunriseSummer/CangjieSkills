# 14. 常见用法总结

[← HashSet](index.md)

典型 `HashSet` 流程包括去重、成员检查、交并差运算、条件过滤、子集判断和批量更新。

```cangjie cjtest=compile id=verified-c371ccd4b2-1
package hashset_summary_example

import std.collection.*

main(): Int64 {
    let frontend = HashSet<String>(["HTML", "CSS", "JavaScript"])
    let backend = HashSet<String>(["JavaScript", "SQL"])
    let common = frontend & backend
    let allSkills = frontend | backend
    let frontendOnly = frontend - backend

    let filtered = allSkills.clone()
    filtered.removeIf { skill => skill == "SQL" }
    let required = HashSet<String>(["HTML", "CSS"])

    println("common has JavaScript: ${common.contains("JavaScript")}")
    println("frontend-only has CSS: ${frontendOnly.contains("CSS")}")
    println("required granted: ${required.subsetOf(filtered)}")
    println("filtered size: ${filtered.size}")
    return 0
}
```
