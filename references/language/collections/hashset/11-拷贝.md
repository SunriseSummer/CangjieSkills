# 11. 拷贝

[← HashSet](index.md)

`func clone(): HashSet<T>`：拷贝。

```cangjie cjtest=syntax id=syntax-fe5938b5ba-1 form=unit
func clone(): HashSet<T>
```

```cangjie cjtest=syntax id=syntax-fe5938b5ba-2 form=stmt
let set = HashSet<Int64>([1, 2, 3])
let copy = set.clone()
copy.add(4)
println(set.size)  // 3（不受影响）
```
