# 5.1 尾部追加

[← 5. 添加元素](index.md)

`func add(element: T): Unit`：尾部追加。

```cangjie cjtest=syntax id=syntax-0e0716f15d-1 form=unit
func add(element: T): Unit
func add(all!: Collection<T>): Unit
```

```cangjie cjtest=syntax id=syntax-0e0716f15d-2 form=stmt
let list = ArrayList<Int64>()
list.add(1)                          // [1]
list.add(2)                          // [1, 2]
list.add(all: [3, 4, 5])            // [1, 2, 3, 4, 5]
let other = ArrayList<Int64>([6, 7])
list.add(all: other)                 // [1, 2, 3, 4, 5, 6, 7]
```
