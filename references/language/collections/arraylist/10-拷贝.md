# 10. 拷贝

[← ArrayList 类型](index.md)

`func clone(): ArrayList<T>`：拷贝。

```cangjie cjtest=syntax id=syntax-6c439abe12-1 form=unit
func clone(): ArrayList<T>
```

```cangjie cjtest=syntax id=syntax-6c439abe12-2 form=stmt
let list = ArrayList<Int64>([1, 2, 3])
let copy = list.clone()
copy[0] = 999
println(list[0])  // 1（不受影响，浅拷贝但各自独立存储）
```
