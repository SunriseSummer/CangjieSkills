# 3. 属性

[← ArrayList 类型](index.md)

`let list = ArrayList<Int64>([10, 20, 30])`：属性。

| 属性 | 类型 | 说明 |
|------|------|------|
| `size` | `Int64` | 元素个数 |
| `capacity` | `Int64` | 当前容量 |
| `first` | `?T` | 首元素，空时为 `None` |
| `last` | `?T` | 尾元素，空时为 `None` |

```cangjie cjtest=syntax id=syntax-d22813b2f7-1 form=stmt
let list = ArrayList<Int64>([10, 20, 30])
println(list.size)      // 3
println(list.capacity)  // >= 3
println(list.first)     // Some(10)
println(list.last)      // Some(30)
```
