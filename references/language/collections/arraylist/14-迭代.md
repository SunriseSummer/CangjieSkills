# 14. 迭代

[← ArrayList 类型](index.md)

`func iterator(): Iterator<T>`：迭代。

```cangjie role=signature
func iterator(): Iterator<T>
```

```cangjie cjtest=run id=language.arraylist.iteration.run form=unit timeout=30s
package arraylist_iteration_example

import std.collection.*

main(): Unit {
    let list = ArrayList<String>(["a", "b", "c"])

    for (item in list) {
        print(item)
    }
    println()

    var iterator = list.iterator()
    while (let Some(item) <- iterator.next()) {
        print(item)
    }
    println()
}
```
