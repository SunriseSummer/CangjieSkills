# 4.1 下标访问

[← 4. 元素访问](index.md)

```cangjie cjtest=syntax id=syntax-39ef203b23-1 form=stmt
let list = ArrayList<Int64>([10, 20, 30])
let v = list[0]    // 10
list[1] = 99       // [10, 99, 30]
```

- 索引从 `0` 开始，类型为 `Int64`
- 越界抛出 `IndexOutOfBoundsException`
