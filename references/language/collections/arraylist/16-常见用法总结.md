# 16. 常见用法总结

[← ArrayList 类型](index.md)

典型 `ArrayList` 流程包括动态收集、批量添加、安全访问、条件删除、排序转换和容量预分配。

```cangjie cjtest=run id=language.arraylist.summary.run form=unit timeout=30s
package arraylist_summary_example

import std.collection.*
import std.sort.*

main(): Unit {
    // 预分配容量后批量添加，避免已知规模下的反复扩容。
    let values = ArrayList<Int64>(8)
    values.add(all: [3, -1, 2])
    values.add(all: [5, 4])

    values.removeIf { value => value < 0 }
    sort(values)

    if (let Some(first) <- values.get(0)) {
        println("first=${first}")
    }

    for (index in 0..values.size) {
        values[index] = values[index] * 2
    }
    let array = values.toArray()
    println(array)
}
```
