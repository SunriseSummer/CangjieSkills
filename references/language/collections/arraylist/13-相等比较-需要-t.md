# 13. 相等比较（需要 T <: Equatable<T>）

[← ArrayList 类型](index.md)

`let a = ArrayList<Int64>([1, 2, 3])`：相等比较（需要 T <: Equatable<T>）。

```cangjie cjtest=syntax id=syntax-efd1f9a1b2-1 form=stmt
let a = ArrayList<Int64>([1, 2, 3])
let b = ArrayList<Int64>([1, 2, 3])
let c = ArrayList<Int64>([1, 2, 4])
println(a == b)  // true
println(a != c)  // true
```
