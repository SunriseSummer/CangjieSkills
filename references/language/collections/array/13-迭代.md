# 13. 迭代

[← Array 类型](index.md)

`func iterator(): Iterator<T>`：迭代。

```cangjie cjtest=syntax id=syntax-fb14bd3423-1 form=unit
func iterator(): Iterator<T>
func isEmpty(): Bool
func toArray(): Array<T>
```

```cangjie cjtest=syntax id=syntax-fb14bd3423-2 form=stmt
let arr = [10, 20, 30]

// for-in 遍历
for (v in arr) {
    println(v)
}

// 使用迭代器
var it = arr.iterator()
while (true) {
    match (it.next()) {
        case Some(v) => println(v)
        case None => break
    }
}
```
