# 5.2 范围赋值

[← 5. 切片与分割](index.md)

`var arr = [0, 1, 2, 3, 4, 5]`：范围赋值。

```cangjie cjtest=syntax id=syntax-cc7e838a4d-1 form=stmt
var arr = [0, 1, 2, 3, 4, 5]
arr[1..3] = [10, 11]   // [0, 10, 11, 3, 4, 5]
```
