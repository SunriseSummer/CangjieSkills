# 5.1 范围下标切片

[← 5. 切片与分割](index.md)

```cangjie cjtest=syntax id=syntax-a36e66c414-1 form=stmt
let arr = [0, 1, 2, 3, 4, 5]
let sub = arr[1..4]    // [1, 2, 3]（引用，非拷贝）
let sub2 = arr[2..=4]  // [2, 3, 4]（闭区间）
```

> **注意**：范围下标返回的是原数组的引用切片，修改会反映到原数组。
