# 11. 相等比较（需要 T <: Equatable<T>）

[← Array 类型](index.md)

`let a = [1, 2, 3]`：相等比较（需要 T <: Equatable<T>）。

```cangjie cjtest=syntax id=syntax-32d1c3662e-1 form=stmt
let a = [1, 2, 3]
let b = [1, 2, 3]
let c = [1, 2, 4]
println(a == b)  // true
println(a != c)  // true
```
