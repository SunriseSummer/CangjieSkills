# 4.1 下标访问

[← 4. 元素访问与修改](index.md)

```cangjie cjtest=syntax id=syntax-6ba7a119d1-1 form=stmt
let arr = [10, 20, 30]
let v = arr[0]   // 10
arr[2] = 99      // [10, 20, 99]
```

- 索引从 `0` 开始，类型为 `Int64`
- 越界抛出 `IndexOutOfBoundsException`
