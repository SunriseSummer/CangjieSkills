# 构造函数签名

[← 2. 构造](index.md)

| 构造函数 | 说明 |
|----------|------|
| `init()` | 创建空数组 |
| `init(size: Int64, repeat!: T)` | 创建指定大小数组，所有元素为 `repeat` 值 |
| `init(size: Int64, initElement: (Int64) -> T)` | 创建指定大小数组，元素由函数生成 |

- `size < 0` 时抛出 `NegativeArraySizeException`
