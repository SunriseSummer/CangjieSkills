# 2.1 常量模式

[← 2. 模式类型](index.md)

常量模式匹配同类型字面量，可用 `|` 合并多个常量；区间不是模式，范围判断应绑定值并使用 `where` 守卫。

- 整数、浮点、字符、布尔、字符串字面量（无插值）和 `Unit` 字面量
- 须与匹配目标**同类型**，值相等时匹配
- 多个常量可用 `|` 组合
- `Rune` 值可用 `Rune` 字面量或单字符字符串字面量匹配
- `Byte` 值可用 ASCII 字符串字面量匹配
- 区间不是模式，不能写 `case r'0'..r':'`；判断范围时绑定值并加 `where` 守卫，或使用无匹配值的 `match`

```cangjie cjtest=syntax id=syntax-e628214019-1 form=stmt
let score = 80
let level = match (score) {
    case 0 | 10 | 20 | 30 | 40 | 50 => "D"
    case 60 => "C"
    case 70 | 80 => "B"
    case 90 | 100 => "A"
    case _ => "invalid"
}
println(level) // B
```

```cangjie cjtest=compile id=verified-e628214019-2
package range_guard_example

func classify(value: Rune): String {
    match (value) {
        case ch where ch >= r'0' && ch <= r'9' => "digit"
        case _ => "other"
    }
}

main(): Unit {
    println(classify(r'7'))
}
```
