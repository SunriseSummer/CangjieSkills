# 2. 模式类型

[← 模式匹配](../index.md)

| 细粒度主题 | 摘要 |
|---|---|
| [2.1 常量模式](2-1-常量模式.md) | 常量模式匹配同类型字面量，可用 `\|` 合并多个常量；区间不是模式，范围判断应绑定值并使用 `where` 守卫。 |
| [2.2 通配符模式（`_`）](2-2-通配符模式.md) | 匹配任意值，通常用作最后一个 case 兜底。 |
| [2.3 绑定模式（`id`）](2-3-绑定模式-id.md) | 匹配任意值并绑定到不可变变量 `id`，作用域到该 case 结束 |
| [2.4 元组模式](2-4-元组模式.md) | `(p_1, p_2, ..., p_n)`（`n ≥ 2`），每个位置匹配时整体匹配。 |
| [2.5 类型模式](2-5-类型模式.md) | `_: Type`（无绑定）或 `id: Type`（有绑定），检查运行时类型是否为 `Type` 的子类型，匹配时转换并可选绑定。 |
| [2.6 枚举模式](2-6-枚举模式.md) | `C`（无参）或 `C(p_1, ..., p_n)`（有参），类型前缀可省略 |
| [2.7 模式嵌套](2-7-模式嵌套.md) | 元组和枚举模式可任意深度嵌套。 |
