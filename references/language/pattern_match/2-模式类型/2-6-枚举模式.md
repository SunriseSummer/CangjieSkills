# 2.6 枚举模式

[← 2. 模式类型](index.md)

- `C`（无参）或 `C(p_1, ..., p_n)`（有参），类型前缀可省略
- 构造器名匹配且嵌套模式匹配时整体匹配
- 须覆盖所有构造器或用 `_`；含绑定变量时不能用 `|`

```cangjie cjtest=syntax id=syntax-fcf65712bc-1 form=unit
enum TimeUnit {
    | Year(UInt64) | Month(UInt64)
}

main() {
    let r = match (Year(2)) {
        case Year(n) => "${n * 12} months"   // 匹配
        case Month(n) => "${n} months"
    }
    println(r)  // "24 months"
}
```
