# 2.4 元组模式

[← 2. 模式类型](index.md)

`(p_1, p_2, ..., p_n)`（`n ≥ 2`），每个位置匹配时整体匹配。同一模式内不允许重复绑定名。

```cangjie cjtest=syntax id=syntax-94cbbe71b7-1 form=stmt
let result = match (("Alice", 24)) {
    case ("Bob", age) => "Bob is ${age}"
    case ("Alice", age) => "Alice is ${age}"  // 匹配
    case (_, _) => "someone"
}
println(result)  // "Alice is 24"
```
