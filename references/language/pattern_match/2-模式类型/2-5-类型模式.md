# 2.5 类型模式

[← 2. 模式类型](index.md)

`_: Type`（无绑定）或 `id: Type`（有绑定），检查运行时类型是否为 `Type` 的子类型，匹配时转换并可选绑定。

```cangjie cjtest=syntax id=syntax-0e9178549e-1 form=unit
open class Base {
    var a: Int64
    public init() { a = 10 }
}
class Derived <: Base {
    public init() { a = 20 }
}

main() {
    let r = match (Derived()) {
        case b: Base => b.a    // 匹配：Derived 是 Base 子类型，r = 20
        case _ => 0
    }
    println(r)  // 20
}
```
