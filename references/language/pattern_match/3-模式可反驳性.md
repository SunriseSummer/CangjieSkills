# 3. 模式可反驳性

[← 模式匹配](index.md)

速查`常量`：始终可反驳；通配符 `_`：始终不可反驳；绑定 `id`：始终不可反驳；另含更多表项。

| 模式 | 可反驳性 | 规则 |
|------|----------|------|
| 常量 | 始终**可反驳** | 可能不匹配 |
| 通配符 `_` | 始终**不可反驳** | 总匹配 |
| 绑定 `id` | 始终**不可反驳** | 总匹配 |
| 类型 `id: Type` | 始终**可反驳** | 运行时类型可能不匹配 |
| 元组 `(p1,...,pn)` | **所有** pi 不可反驳时不可反驳 | 一个可反驳 → 整体可反驳 |
| 枚举 `C(p1,...,pn)` | 仅一个有参构造器**且**所有 pi 不可反驳时不可反驳 | 多构造器 → 始终可反驳 |
