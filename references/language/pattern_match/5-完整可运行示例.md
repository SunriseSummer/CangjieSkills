# 5. 完整可运行示例

[← 模式匹配](index.md)

用带负载枚举表示不同图形，通过 `match` 解构参数并计算面积，再用无匹配值的 `match` 按条件分类。

```cangjie cjtest=syntax id=syntax-3c66f6b17a-1 form=unit
enum Shape {
    | Circle(Float64)
    | Rect(Float64, Float64)
    | Triangle(Float64, Float64)
}

main() {
    let shapes = [Circle(5.0), Rect(3.0, 4.0), Triangle(3.0, 6.0)]

    for (shape in shapes) {
        let area = match (shape) {
            case Circle(r) => 3.14159 * r * r
            case Rect(w, h) => w * h
            case Triangle(b, h) => b * h / 2.0
        }
        match {
            case area > 50.0 => println("Large: ${area}")
            case area > 10.0 => println("Medium: ${area}")
            case _ => println("Small: ${area}")
        }
    }
}
```
