# 2.4 实现规则

[← 2. 接口实现](index.md)

- **函数**：名称、参数列表、返回类型须相同。例外：若接口返回类型为 `class`，实现者可返回其子类
- **`mut` 函数**：接口中声明的 `mut` 函数，`class` 实现时**忽略** `mut` 修饰（class 实例成员函数始终可修改实例状态），`struct` 实现时**须**匹配 `mut` 修饰符
- **属性**：`mut` 修饰符须匹配；类型须相同
- 实现时函数或属性定义前的 `override`/`redef` 修饰符可选（无论接口中是否有默认实现）
