# 2.5 返回子类型示例

[← 2. 接口实现](index.md)

重写接口或父类型成员时，返回类型可以协变为声明返回类型的子类型。

```cangjie cjtest=syntax id=syntax-9d6e6ca91b-1 form=unit
open class Base {}
class Sub <: Base {}

interface I {
    func f(): Base
}

class C <: I {
    public func f(): Sub {  // 允许返回 Base 的子类型
        Sub()
    }
}
```
