# 接口

[← 语言特性](../index.md)

接口声明、实现与继承、默认实现、泛型成员、属性和菱形继承。

| 规则/任务 | 摘要 |
|---|---|
| [1. 接口定义](1-接口定义/index.md) | `interface I { ... }` — 定义抽象类型，不包含数据，定义类型的行为 |
| [2. 接口实现](2-接口实现/index.md) | `class Foo <: I { ... }` — 须实现 `I` 的所有成员。 |
| [3. 接口继承](3-接口继承/index.md) | 接口可继承一个或多个接口（不能继承类）：`interface I3 <: I1 & I2 { ... }` |
| [4. 默认实现](4-默认实现/index.md) | 接口可为实例成员和静态成员提供默认实现，从而复用行为并减少实现类型的样板代码。 |
| [5. 泛型成员](5-泛型成员.md) | 接口可定义具有 `open` 语义的泛型实例/静态函数 |
| [6. `Any` 类型](6-any-类型.md) | 内置接口：`interface Any {}` |
| [7. 属性（prop）在接口中的使用](7-属性-prop-在接口中的使用/index.md) | 接口可声明无实现的抽象属性，也可给出默认 getter/setter；实现类型须提供与声明兼容的属性能力。 |
| [8. 接口成员访问修饰符](8-接口成员访问修饰符.md) | 接口成员默认 `public`，不可声明额外的访问修饰符 |
