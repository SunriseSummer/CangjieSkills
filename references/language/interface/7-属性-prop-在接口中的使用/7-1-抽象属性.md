# 7.1 抽象属性

[← 7. 属性（prop）在接口中的使用](index.md)

- 在接口中可声明抽象属性（无实现）
- 实现类型须提供实现
```cangjie cjtest=syntax id=syntax-f8d49ddafc-1 form=unit
interface HasName {
    prop name: String
    mut prop id: Int64
}

class User <: HasName {
    var _id: Int64 = 0
    public prop name: String {
        get() { "User" }
    }
    public mut prop id: Int64 {
        get() { _id }
        set(v) { _id = v }
    }
}
```
