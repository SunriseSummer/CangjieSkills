# 8. 接口成员访问修饰符

[← 接口](index.md)

- 接口成员默认 `public`，不可声明额外的访问修饰符
- 实现类型中对应成员**须**使用 `public`
```cangjie cjtest=syntax id=syntax-7a51a3b4f4-1 form=unit
interface I {
    func f(): Unit
}

// 以下代码编译会报错：实现接口成员须使用 public
// open class C <: I {
//     protected func f() {}  // ❌ Error: 须为 public
// }

open class C <: I {
    public func f() {}  // ✅ 正确: public 修饰
}
```
