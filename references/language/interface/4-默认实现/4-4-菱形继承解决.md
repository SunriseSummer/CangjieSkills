# 4.4 菱形继承解决

[← 4. 默认实现](index.md)

- 若多个继承接口提供同一成员的冲突默认实现，实现者**须**提供自己的实现
```cangjie cjtest=syntax id=syntax-20124a8e20-1 form=unit
interface SayHi {
    func say(): String { "hi" }
}
interface SayHello {
    func say(): String { "hello" }
}

// 两个接口都有 say 的默认实现，产生冲突
class Foo <: SayHi & SayHello {
    public func say(): String { "Foo" }  // 须自行实现，否则编译错误
}
```
