# 4.1 实例成员默认实现

[← 4. 默认实现](index.md)

接口成员可带默认函数体；实现类型只需覆盖没有默认实现的成员，或按需替换默认行为。

- 接口成员可有默认实现
- 实现类型可继承默认实现，也可提供自己的实现
```cangjie cjtest=syntax id=syntax-e34867eac7-1 form=unit
interface SayHi {
    func say(): String { "hi" }
}

class A <: SayHi {}  // 继承默认实现

class B <: SayHi {
    public func say(): String { "hi, B" }  // 覆盖默认实现
}
```
