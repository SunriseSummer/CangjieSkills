# 1.1 线程模型

[← 1. 并发概述](index.md)

并发任务运行在抢占式线程模型上；共享可变状态必须通过锁、原子类型等同步机制保护。

- 仓颉使用**抢占式线程模型**
- 两种线程概念：**语言线程**和**原生线程**
- 仓颉线程是**用户空间轻量级线程**，采用 **M:N 线程模型** — M 个语言线程调度到 N 个原生（OS）线程上，M ≠ N 是可能的
- 每个原生线程选择一个就绪的仓颉线程执行。若仓颉线程阻塞（如等待互斥锁），原生线程挂起它并选择下一个就绪线程
