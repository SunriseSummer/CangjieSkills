# 3.1 定义

[← 3. 型变规则（Variance）](index.md)

设 `A`、`B` 为类型，`T` 为类型构造器（含一个类型参数 `X`）：

| 型变 | 条件 | 说明 |
|------|------|------|
| **不型变**（invariant） | `T<A> <: T<B>` 当且仅当 `A = B` | 用户定义的泛型类型默认行为 |
| **协变**（covariant） | `T<A> <: T<B>` 当且仅当 `A <: B` | 内建元组类型对每个元素协变 |
| **逆变**（contravariant） | `T<A> <: T<B>` 当且仅当 `B <: A` | 内建函数类型在参数处逆变 |
