# 3.2 仓颉中的规则

[← 3. 型变规则（Variance）](index.md)

- **用户自定义泛型类型**：在所有类型变元处**不型变**
  - 例：给定 `interface I<X>` 和 `D <: C`，`I<D> <: I<C>` **不成立**
  - 仅当 `A = B` 时，`I<A> <: I<B>` 才成立
- **内建元组类型**：对每个元素类型**协变**
- **内建函数类型**：入参类型处**逆变**，返回类型处**协变**

> **注意**：`class` 以外的类型实现接口，该类型和该接口之间的子类型关系不能作为协变和逆变的依据。
