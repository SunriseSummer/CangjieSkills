# 4.2 数值转换

[← 4. 类型转换](index.md)

- `T(e)` 其中 `T` 和 `e` 为任意数值类型（`Int8`/`Int16`/`Int32`/`Int64`/`IntNative`/`UInt8`/`UInt16`/`UInt32`/`UInt64`/`UIntNative`/`Float16`/`Float32`/`Float64`）
- 可能溢出：编译时检测 → 错误；运行时 → 异常
