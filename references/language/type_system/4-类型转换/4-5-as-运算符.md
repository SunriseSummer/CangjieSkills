# 4.5 `as` 运算符

[← 4. 类型转换](index.md)

- `e as T` → `Option<T>`。运行时类型是子类型时返回 `Some(e)`，否则返回 `None`
- 安全向下转型机制 — 无异常，仅返回 `Option`
```cangjie cjtest=syntax id=syntax-80e0d1fd4b-1 form=unit
open class Base {}
class Derived <: Base {}

main() {
    let b: Base = Derived()
    println((b as Derived).isSome())   // true
    println((b as String).isSome())    // false
}
```
