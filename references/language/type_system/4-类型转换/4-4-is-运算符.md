# 4.4 `is` 运算符

[← 4. 类型转换](index.md)

- `e is T` → `Bool`。当 `e` 的**运行时类型**是 `T` 的子类型时返回 `true`
```cangjie cjtest=syntax id=syntax-62ed8e4088-1 form=unit
open class Base {}
class Derived <: Base {}

main() {
    let b: Base = Derived()
    println(b is Derived)  // true
    println(b is Base)     // true
}
```
