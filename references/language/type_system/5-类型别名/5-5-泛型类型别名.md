# 5.5 泛型类型别名

[← 5. 类型别名](index.md)

泛型类型别名可声明类型参数，并把参数传递给被别名的复合或泛型类型。

- 类型别名可声明类型参数
- **不能**对别名类型参数使用 `where` 约束
```cangjie cjtest=syntax id=syntax-7c4ff56896-1 form=unit
import std.collection.*
type IntList = ArrayList<Int64>
```
