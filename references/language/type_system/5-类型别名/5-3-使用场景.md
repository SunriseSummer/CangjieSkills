# 5.3 使用场景

[← 5. 类型别名](index.md)

1. **作为类型**：`var a: A = B()` 其中 `type A = B`
2. **作为构造函数**（当别名指向 class/struct 时）：`A()` 构造 `B`
3. **访问静态成员**：`A.foo()`、`A.b`
4. **访问枚举构造函数**：`Time.Day` 其中 `type Time = TimeUnit`
