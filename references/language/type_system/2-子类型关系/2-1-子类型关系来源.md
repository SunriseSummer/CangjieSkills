# 2.1 子类型关系来源

[← 2. 子类型关系](index.md)

1. **类继承**：`class Sub <: Super {}` → `Sub <: Super`
2. **接口实现**（含扩展实现）：类型实现接口后成为接口的子类型
3. **元组类型**（协变，逐元素）：`(C2, C4) <: (C1, C3)` 若 `C2 <: C1` 且 `C4 <: C3`
4. **函数类型**（参数逆变，返回协变）：`(U1) -> S2 <: (U2) -> S1` 当且仅当 `U2 <: U1` 且 `S2 <: S1`
5. **恒真关系**：
   - `T <: T`（自反性）
   - `Nothing <: T` 对所有 `T` 成立
   - `T <: Any` 对所有 `T` 成立
   - `C <: Object` 对任何 `class C` 成立
6. **传递性**：若 `A <: B` 且 `B <: C`，则 `A <: C`
