# 类型系统

[← 语言特性](../index.md)

子类型、函数和元组型变、is/as、数值转换、基础类型关系与别名。

| 规则/任务 | 摘要 |
|---|---|
| [1. 类型系统概述](1-类型系统概述.md) | 仓颉是静态类型语言，支持子类型多态 |
| [2. 子类型关系](2-子类型关系/index.md) | 类继承：`class Sub <: Super {}` → `Sub <: Super` |
| [3. 型变规则（Variance）](3-型变规则-variance/index.md) | 注意：`class` 以外的类型实现接口，该类型和该接口之间的子类型关系不能作为协变和逆变的依据。 |
| [4. 类型转换](4-类型转换/index.md) | 仓颉无隐式类型转换（子类型到父类型不被视为"转换"） |
| [5. 类型别名](5-类型别名/index.md) | `type` 为既有类型提供替代名称，可简化复杂类型签名，但不会创建名义上不同的新类型。 |
