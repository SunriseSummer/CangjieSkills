# 2.4 安全编译建议

[← 2. 使用 cjc 直接编译](index.md)

`cjpm build` 只链接 `[ffi.c]` 指向的现成库，不会替代 C 源码编译。每次修改本机 C 源码后，都要先独立运行 Clang；使用 `-Wall -Wextra -Werror` 把未使用变量、可疑转换等警告纳入验收，再运行 `cjpm build/test/run`。不要用关闭告警的选项掩盖问题。

编译 C 代码时还应启用栈保护选项，防止缓冲区溢出攻击：

```shell
# 推荐选项（二选一）
clang -fstack-protector-all ...    # 全部函数开启栈保护
clang -fstack-protector-strong ... # 对含局部数组/地址操作的函数开启栈保护
```
