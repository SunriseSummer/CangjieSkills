# 3.6 链接安全加固选项

[← 3. 基于 cjpm 项目编译（推荐）](index.md)

对于需要安全加固的项目，建议在 `link-option` 中添加链接器安全标志：

```toml
[package]
  link-option = "-z noexecstack -z relro -z now"
```

| 选项 | 说明 |
|------|------|
| `-z noexecstack` | 禁止栈上执行代码，防止栈溢出攻击 |
| `-z relro` | 设置 GOT 为只读，防止 GOT 覆写攻击 |
| `-z now` | 立即绑定所有符号，配合 relro 使用 |
