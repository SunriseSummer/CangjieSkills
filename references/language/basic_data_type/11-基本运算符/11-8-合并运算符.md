# 11.8 合并运算符 `??`

[← 11. 基本运算符](index.md)

- 用于 `Option<T>` 解包
- `e1 ?? e2`：若 `e1` 为 `Some(v)` → `v`（短路，`e2` 不求值）；若 `None` → `e2`
- **`??` 的优先级很低（16），低于比较运算符（`==`/`!=` 为 10，`<`/`>` 为 9）**，混合使用时须加括号：

```cangjie cjtest=syntax id=syntax-2e9ebae185-1 form=stmt
let opt: ?Int64 = 42
let value = 10

// ❌ 错误：?? 优先级低于 !=，实际解析为 opt ?? (default != value)
// if (opt ?? default != value) { println("not equal") }

// ✅ 正确：使用括号明确优先级
if ((opt ?? 0) != value) { println("not equal") }
```
