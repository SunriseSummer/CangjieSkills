# 11.2 算术运算符

[← 11. 基本运算符](index.md)

| 运算符 | 说明 | 操作数类型 |
|--------|------|------------|
| `-`（一元） | 取负 | 数值类型 |
| `+` | 加（也用于字符串拼接） | 相同数值类型 |
| `-` | 减 | 相同数值类型 |
| `*` | 乘 | 相同数值类型 |
| `/` | 除（整数除法向零截断） | 相同数值类型 |
| `%` | 取模 `a - b*(a/b)` | 仅整数 |
| `**` | 幂 | `Int64^UInt64→Int64`，`Float64^(Int64\|Float64)→Float64` |

- 溢出会被检测并报错（运行时错误）
