# 11.5 逻辑运算符

[← 11. 基本运算符](index.md)

速查`!`：非（一元前缀）；`&&`：与；`||`：或。

| 运算符 | 说明 | 短路求值 |
|--------|------|----------|
| `!` | 非（一元前缀） | 不适用 |
| `&&` | 与 | 是：`false && x` → `false` |
| `\|\|` | 或 | 是：`true \|\| x` → `true` |
