# 11.1 赋值运算符 `=`

[← 11. 基本运算符](index.md)

- 先计算右侧，再计算左侧，然后赋值
- 赋值表达式的类型为 `Unit`（值为 `()`）
- **不支持链式赋值**：`a = b = 0` 是语法错误
- **多元赋值**：`(a, b) = (1, 2)`；`(a, b) = (b, a)` 用于交换；`_` 忽略
