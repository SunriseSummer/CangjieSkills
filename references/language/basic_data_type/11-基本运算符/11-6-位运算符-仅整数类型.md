# 11.6 位运算符（仅整数类型）

[← 11. 基本运算符](index.md)

| 运算符 | 说明 |
|--------|------|
| `!`（一元） | 按位取反 |
| `<<` | 左移（低位补 0） |
| `>>` | 右移（无符号补 0；有符号正数补 0，负数补 1） |
| `&` | 按位与 |
| `^` | 按位异或 |
| `\|` | 按位或 |

- 移位量须为非负且小于操作数位宽
