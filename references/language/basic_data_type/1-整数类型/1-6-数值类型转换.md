# 1.6 数值类型转换

[← 1. 整数类型](index.md)

- 仓颉使用**类型构造函数**语法进行数值转换，没有 `.toInt64()` 等方法：
  ```cangjie cjtest=syntax id=syntax-00bd671b6a-1 form=stmt
  let a: Int32 = 42
  let n = Int64(a)               // 将 Int32 转换为 Int64
  let u = UInt32(r'A')           // 将 Rune 转换为 UInt32 → 65
  let f = Float64(n)             // 将整数转换为 Float64
  let r = Rune(65)               // 将整数转换为 Rune → 'A'
  ```
- 字符串解析为数值使用 `parse` 静态方法（需导入 `std.convert.*`）：
  ```cangjie cjtest=syntax id=syntax-00bd671b6a-2 form=unit
  import std.convert.*
  let n = Int64.parse("42")       // 解析失败抛异常
  let f = Float64.parse("3.14")   // 解析失败抛异常
  ```
