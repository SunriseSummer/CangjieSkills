# 1.1 类型列表

[← 1. 整数类型](index.md)

- **有符号整数**：`Int8`、`Int16`、`Int32`、`Int64`、`IntNative`
- **无符号整数**：`UInt8`、`UInt16`、`UInt32`、`UInt64`、`UIntNative`
- 有符号 N 位范围：−2^(N−1) ~ 2^(N−1)−1；无符号 N 位范围：0 ~ 2^N−1
- `IntNative`/`UIntNative` 为平台相关宽度
- 默认整数类型为 `Int64`（无上下文时字面量默认推断为 `Int64`）
