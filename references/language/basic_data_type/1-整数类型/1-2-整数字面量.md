# 1.2 整数字面量

[← 1. 整数类型](index.md)

- **二进制**：`0b` 或 `0B` 前缀，例如 `0b00011000`
- **八进制**：`0o` 或 `0O` 前缀，例如 `0o30`
- **十进制**：无前缀，例如 `24`
- **十六进制**：`0x` 或 `0X` 前缀，例如 `0x18`
- 允许使用下划线 `_` 分隔：`0b0001_1000`
- 超出范围的值会导致编译错误
