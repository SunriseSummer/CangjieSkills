# 1.3 整数字面量后缀

[← 1. 整数类型](index.md)

| 后缀 | 类型 | 后缀 | 类型 |
|------|------|------|------|
| `i8` | Int8 | `u8` | UInt8 |
| `i16` | Int16 | `u16` | UInt16 |
| `i32` | Int32 | `u32` | UInt32 |
| `i64` | Int64 | `u64` | UInt64 |

示例：`100i8`、`0x10u64`、`0o432i32`
