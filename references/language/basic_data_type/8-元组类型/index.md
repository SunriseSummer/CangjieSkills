# 8. 元组类型

[← 基本数据类型](../index.md)

| 细粒度主题 | 摘要 |
|---|---|
| [概述与共同规则](overview.md) | 类型写作 `(T1, T2, ..., TN)`，值写作 `(e1, e2, ..., eN)`，最少 2 个元素；长度固定、元素不可写，但 `var` 元组变量可整体重新赋值 |
| [8.1 元素访问](8-1-元素访问.md) | 以从零开始的编译期整数字面量访问元组元素，如 `pair[0]`；不支持 `.0`/`.1` 字段语法，动态索引和越界索引都会编译失败。 |
| [8.2 具名类型参数](8-2-具名类型参数.md) | `(name: String, price: Int64)` — 所有参数须全部具名或全部不具名 |
| [8.3 元组相等性](8-3-元组相等性.md) | `==`/`!=` 仅在所有元素类型都支持 `==`/`!=` 时可用 |
| [8.4 多元赋值](8-4-多元赋值.md) | `(a, b) = (1, 2)` — 并行赋值 |
