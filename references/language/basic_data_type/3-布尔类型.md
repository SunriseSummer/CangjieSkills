# 3. 布尔类型

[← 基本数据类型](index.md)

`Bool` 只有 `true` 和 `false` 两个值，用于条件表达式及逻辑运算。

- 类型：`Bool`
- 字面量：`true`、`false`
- 支持运算符：
  - 逻辑运算：`!`（非）、`&&`（与）、`||`（或）
  - 关系运算：`==`、`!=`
  - 复合赋值：`&&=`、`||=`
