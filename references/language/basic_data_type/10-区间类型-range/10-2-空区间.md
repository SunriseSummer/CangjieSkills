# 10.2 空区间

[← 10. 区间类型（Range）](index.md)

- `start..end : step` 为空：当 `step > 0 && start >= end` 或 `step < 0 && start <= end`
- `start..=end : step` 为空：当 `step > 0 && start > end` 或 `step < 0 && start < end`
