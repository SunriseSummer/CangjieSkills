# 10.1 区间字面量

[← 10. 区间类型（Range）](index.md)

- **半开区间**（左闭右开）：`start..end : step` — 不包含 `end`
- **闭区间**（左闭右闭）：`start..=end : step` — 包含 `end`
- `step` 省略时默认为 1；`step` 不能为 0
