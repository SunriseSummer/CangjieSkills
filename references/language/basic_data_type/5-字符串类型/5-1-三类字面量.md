# 5.1 三类字面量

[← 5. 字符串类型](index.md)

1. **单行字符串**：用 `'...'` 或 `"..."` 包围。不可含未转义的匹配引号或单独的 `\`。须在一行内。
2. **多行字符串**：用 `"""..."""` 或 `'''...'''` 包围。内容从第一个换行后开始。可跨行。支持转义。
3. **多行原始字符串**：`#"..."#`、`##'...'##` 等。起止 `#` 数量须匹配。**不进行转义处理**。
