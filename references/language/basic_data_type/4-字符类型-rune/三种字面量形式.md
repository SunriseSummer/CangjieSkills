# 三种字面量形式

[← 4. 字符类型（Rune）](index.md)

Rune 字面量写作 `r'a'`、`r"b"`、转义形式或 `r'\u{4f60}'`；前缀 `r` 不能省略。

1. **单字符**：`r'a'`、`r"b"`
2. **转义字符**：`r'\\'`、`r'\n'`、`r'\t'`
3. **Unicode 字符**：`r'\u{4f60}'`（1~8 位十六进制）
