# 文本行 SHA-256 清单

创建仓颉 1.1.3 可执行项目 `sha256_lines`。程序读取第一个命令行参数指定的 UTF-8 文本文件，逐行使用 `stdx.crypto.digest.SHA256` 计算摘要，输出小写十六进制的 `<摘要>  <原文本>`；空文件输出为空。

要求：

- 先建立 `cjpm.toml`，然后通过当前 Skill 的 `setup_stdx.py` 配置依赖；不得手写或猜测 stdx 二进制路径。
- 摘要计算、十六进制编码、文件/命令行适配分层实现。
- 将已给定且不可修改的 `sha256_lines_test.cj` 逐字节复制到项目 `src/`；它覆盖空行、ASCII、中文、多行顺序及公开 SHA-256 向量，可按需另行补充测试。
- 执行 `cjpm test`，并对临时文本文件实际执行 `cjpm run -- <file>`。
